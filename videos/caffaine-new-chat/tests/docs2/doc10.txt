# 企業總部辦公室搬遷計畫書（Master Plan）

## 一、 計畫概述與目標

### 1.1 計畫背景
隨著公司業務規模擴展、團隊人數持續成長，現有辦公室已不敷使用，不僅動線受限，會議室與協作空間亦嚴重不足。為提供同仁更優質、安全、舒適的工作環境，並提升整體營運效能與企業形象，公司決議於 **202X年Q3** 進行辦公室全面搬遷。新辦公室將坐落於交通便利、設施完善之核心商辦大樓，為公司下一個十年發展奠定穩固基石。

### 1.2 搬遷核心目標
*   **業務營運零中斷（Zero Downtime）：** 確保搬遷期間對客戶服務、對外溝通及核心系統運作的影響降至最低。
*   **資產安全無損：** 妥善保護公司所有硬體設備、機密檔案、財產及同仁私人物品，達成「零遺失、零損壞」。
*   **無縫辦公體驗：** 確保新址於搬遷完成後的第一個工作日早晨，水、電、網路、門禁、通訊及 IT 設備完全就緒，同仁可立即開工。
*   **文化與空間升級：** 藉由空間重整與新裝潢，優化跨部門協作動線，落實綠色辦公與環保永續理念。

## 二、 組織架構與職責分工

為確保搬遷專案順利執行，成立「辦公室搬遷專案委員會」，由營運長（COO）擔任最高指導，下設專案總召集人，並由各部門指派專責代表組成跨部門工作小組。

```
                    【搬遷專案最高指導】營運長 (COO)
                               │
                       【專案總召集人】
                               │
       ┌───────────────────────┼───────────────────────┐
       ▼                       ▼                       ▼
【IT與通訊組】           【行政與總務組】         【溝通與安全組】
 (網路/伺服器/設備)      (合約/搬家公司/裝潢)     (時程公告/安控/宣導)
```

### 2.1 職責分工明細表

| 工作小組 | 負責部門 | 核心職責 |
| :--- | :--- | :--- |
| **行政與總務組** | 行政部 / 採購部 | 1. 統籌搬遷預算與時程。<br>2. 遴選並管理搬家公司、裝潢包商。<br>3. 新舊辦公室租約交接、水電與物業管理對接。<br>4. 新辦公室辦公家具採購與定位。 |
| **IT與通訊組** | 資訊部 (IT) | 1. 規劃新舊址網路架構、伺服器搬遷與不斷電系統。<br>2. 處理員工電腦、印表機、電話等設備之拆卸與重新安裝。<br>3. 確保資安防護與通訊不斷訊。 |
| **溝通與安全組** | 人資部 /福委會 / 總務安控 | 1. 擬定搬遷手冊，對內進行全員進度宣導與Q&A。<br>2. 規劃新辦公室門禁卡發放、座位表與動線指引。<br>3. 負責搬遷當日現場安全管制與緊急應變處理。 |

## 三、 搬遷時程規畫（Timeline）

整個搬遷專案預計歷時 6 個月，劃分為四個主要階段：

### 3.1 第一階段：前期籌備與規劃期（T-6 個月 至 T-3 個月）
*   **空間設計與裝潢：** 完成新辦公室平面配置圖（Space Planning）、室內裝潢設計與施工發包。
*   **供應商招標：** 評選並簽署專業搬家公司合約、辦公家具供應商合約及清潔公司合約。
*   **預算審查：** 提報整體搬遷預算（含裝潢、搬運、網路佈線、臨時租金等）並經財務委員會核准。
*   **成立專案小組：** 召開第一次籌備會議，確認各組任務與細部時程。

### 3.2 第二階段：細部執行與前置準備期（T-2 個月 至 T-1 個月）
*   **座位編排與公告：** 公布新辦公室座位分配圖，各部門進行內部盤點與動線規劃。
*   **資產盤點與清理：** 進行全面性的「大掃除」，淘汰老舊不符使用之辦公設備與過期紙本文件（依資料保存年限銷毀）。
*   **IT 壓力測試：** 針對新辦公室之機房佈線、網速、Wi-Fi 覆蓋率進行前期測試。
*   **發放搬遷手冊：** 派發《員工搬遷指南》，舉辦全員說明會，說明打包原則與注意事項。

### 3.3 第三階段：執行期——黃金週末（T-Day 當週週末）
*   **周五下班前：** 同仁完成個人私人物品打包、貼妥標籤；IT 進行伺服器最後備份與關機。
*   **週六（搬運日）：** 搬家公司進駐舊址進行大型家具與箱子裝載，運送至新址並依標籤定位。
*   **週日（安裝日）：** IT 團隊進駐新址進行伺服器、網路與電腦設備上線測試；清潔公司進行全面細部清潔。
*   **週日傍晚：** 專案小組進行總驗收，確保各項設施運作正常。

### 3.4 第四階段：後續優化期（T+1 週 至 T+1 個月）
*   **正式啟用日（Monday）：** 同仁正常於新址打卡上班，專案小組設置「快速求助台（Helpdesk）」即時排除狀況。
*   **缺失改善：** 收集同仁反饋，微調空調溫度、照明、茶水間設施及網路連線微調。
*   **舊址點交：** 完成舊辦公室清潔復原，辦理退租與押金返還手續。
*   **專案結案：** 召開檢討會，核銷專案經費並歸檔。

## 四、 舊址退租與新址點交規範

### 4.1 舊辦公室退租程序
1.  **原狀恢復評估：** 邀請舊房東進行聯合堪驗，確認需恢復原狀之範圍（如隔間拆除、地毯復原、牆面油漆等）。
2.  **合約終止確認：** 確認租約到期日與水、電、瓦斯、管理費結算至搬遷完成日。
3.  **設備拆除清點：** 屬於公司資產之燈具、門禁設備、冷氣等，依合約規定決定拆遷或留作折舊補償。

### 4.2 新辦公室點交程序
1.  **硬體驗收：** 檢查消防設施、逃生動線、空調系統、電梯載重限制及電力負載是否符合辦公需求。
2.  **空間驗收：** 裝潢工程驗收，針對油漆瑕疵、木作收邊、門窗開關、衛浴設備進行缺失列管與限期改善。
3.  **鑰匙與門禁移交：** 取得大樓物業管理委員會發給之磁卡、鑰匙、停車位權益證明及裝潢施工證。

## 五、 IT、通訊與資安搬遷計畫

辦公室搬遷中，技術設備與資料的安全最具挑戰性，IT 組必須嚴格執行以下規範：

### 5.1 伺服器與核心系統轉移
*   **完整備份：** 搬遷前 3 天，所有重要資料庫、雲端伺服器映象檔（Image）進行雙重完整備份（On-site & Off-site）。
*   **排程中斷通知：** 若有需停機維護之系統，應於搬遷前 1 週發送公告給全體同仁及外部合作夥伴。
*   **精密設備保護：** 伺服器及網路交換器（Switch）需使用抗靜電泡棉包覆，並由 IT 專人監督裝箱與運送，嚴禁重摔。

### 5.2 辦公室網路與通訊架構
*   **雙迴路備援：** 新辦公室網路需在搬遷前完成雙 ISP（中華電信及其他備援業者）佈線測試。
*   **Wi-Fi 覆蓋率：** 依新辦公室坪數與隔間，重新計算 AP（無線基地台）點位，確保無死角。
*   **總機系統轉接：** 確保公司總機號碼（VoIP）在新址無縫接軌，外部客戶撥打時不受影響。

### 5.3 資安防護準則
*   **實體安全：** 搬遷過程中，任何儲存機密資料的硬碟、磁帶或實體文件，皆須由專人（至少兩人同行）押運，不可假手不知名之外包人員。
*   **紙本文件管制：** 機密合約與財務報表等紙本，務必裝入上鎖之專用檔案箱中，並貼上封條。

## 六、 員工指引與行政規範

搬遷成功與否，高度依賴全體同仁的配合。行政與溝通組將落實以下執行細節：

### 6.1 個人物品打包守則
*   **專用箱發放：** 預計於搬遷前 3 週發放標準紙箱與麥克筆。
*   **標籤制度：** 每一位同仁將獲得專屬「搬遷代碼標籤」（格式：`部門-英文姓名-座號`）。標籤須貼在紙箱的正面與頂部。
*   **打包限制：**
    *   **禁止打包：** 易燃物、腐蝕性化學品、貴重個人物品（如現金、珠寶、身分證件）、生鮮食品及植物。
    *   **個人電腦：** 螢幕、主機、鍵盤需按照 IT 組提供之圖示拔除線材並妥善放置。筆記型電腦請同仁隨身攜帶，切勿放入搬家紙箱。

### 6.2 辦公室動線與安全須知
*   **搬遷當日管制：** 搬遷週末（週六、週日）除專案指派人員外，其餘同仁禁止進入新舊辦公室，以維護搬運效率與人身安全。
*   **第一天上班注意事項：**
    *   請於新辦公室入口處報到，領取新門禁卡及座位導引圖。
    *   抵達座位後，請先檢查個人物品是否完整，並自行組裝電腦與電話。
    *   若發現網路不通或設備損壞，請立刻掃描桌上之 QR Code 聯繫 IT Helpdesk。

## 七、 應變計畫（Contingency Plan）

為防範搬遷過程中可能發生的突發狀況，特擬定以下緊急應變方案：

| 潛在風險狀況 | 發生機率 | 嚴重程度 | 應變與緩解措施 (Mitigation Plan) |
| :--- | :--- | :--- | :--- |
| **1. 搬家公司車輛故障或延誤** | 中 | 高 | • 簽約時明訂違約罰則。<br>• 要求搬家公司預留 20% 之備用車輛與人力。<br>• 若遇延誤，立即啟動備用物流方案。 |
| **2. 新址網路佈線或機房發生故障** | 低 | 高 | • 提前 3 天完成壓力測試。<br>• IT 團隊與電信商工程師於搬遷週末全程駐點。<br>• 準備 4G/5G 行動網卡作為臨時網路備援。 |
| **3. 辦公家具尺寸不合或損壞** | 中 | 中 | • 驗收時嚴格把關。<br>• 要求供應商提供「備品」於現場即時更換。<br>• 若需重新訂製，由行政部協調臨時替代桌椅。 |
| **4. 天氣因素（如颱風、豪雨）** | 中 | 高 | • 隨時監控中央氣象局動態。<br>• 紙箱全面加裝防水塑膠套。<br>• 若發布海上陸上颱風警報，立即順延搬遷時程至次一週末，並通知全體同仁。 |
| **5. 機密文件遺失或外洩** | 低 | 極高 | • 實施雙人押運制度。<br>• 紙箱貼立體防拆封條。<br>• 簽署保密協定（NDA），落實追溯責任。 |

## 八、 預算規劃概要

本搬遷專案預算編列涵蓋以下五大核心項目：

1.  **新址裝潢與工程費：** 包含室內設計費、隔間工程、水電消防重置、地毯與照明更新。
2.  **專業搬遷服務費：** 舊址打包、大型辦公家具與設備吊運、新址定位。
3.  **IT與通訊升級費：** 機房遷移、網路線路鋪設、新購硬體與不斷電系統。
4.  **行政與雜支費用：** 員工搬遷補貼、紙箱採購、清潔費、搬遷日餐費及應變準備金。
5.  **雙租期過渡成本：** 新舊辦公室重疊期之租金與物業管理費（預計 1 個月）。

*(註：詳細預算金額與各項明細參見《辦公室搬遷財務預算明細表-附件A》)*

## 九、 結語與核准

辦公室搬遷是公司發展歷程中的重要里程碑，不僅是硬體環境的更新，更是企業文化與工作效率的一次全面躍升。這需要各部門主管全力支持與全體同仁的積極配合。

本計畫書經專案委員會審議通過後正式生效，各工作小組應依照本計畫書之規範與時程表確實執行。
