# 2024年度公司教育訓練總體規劃與實施辦法

## 第一章 總則

### 1.1 目的
為配合公司長期策略發展目標，持續提升全體員工之專業職能、管理效能與創新思維，並打造學習型組織以增進企業核心競爭力，特擬定本年度教育訓練計畫。本計畫旨在透過系統化、結構化之培訓體系，協助員工實現個人職涯成長，同時滿足公司業務擴展與數位轉型之需求。

### 1.2 適用範圍
本計畫適用於本公司全體正式員工（包含總公司、各分公司及海外據點之全職與約聘人員）。依據員工之職務類階、部門屬性與發展需求，實施分層分類之培訓。

### 1.3 辦理原則
1. **策略導向原則**：訓練需求緊密結合公司年度營運目標與關鍵績效指標（KPI）。
2. **全员學習原則**：確保每位員工皆享有平等之受訓權利與發展機會。
3. **學用合一原則**：強調知識轉化與實務應用，注重培訓成效之追蹤與評估。
4. **資源最佳化原則**：整合內部講師資源與外部專業機構，追求訓練投資報酬率（ROI）之最大化。

## 第二章 訓練需求分析與目標設定

### 2.1 需求調查方法
本年度教育訓練需求係透過以下三維度進行綜合評估：
1. **組織層面**：依據公司高階管理會議決議之年度策略方針、市場趨勢及數位轉型藍圖進行推導。
2. **職務層面**：基於各職位說明書（Job Description）與職能矩陣（Competency Matrix），評估特定職位所需之核心職能與專業職能落差。
3. **個人層面**：結合去年度績效考核結果（Performance Appraisal）與員工個人發展計畫（IDP，Individual Development Plan），由直屬主管與員工共同面談確認培訓需求。

### 2.2 年度三大發展主軸
經綜合分析後，本年度教育訓練確立三大發展主軸：
1. **數位轉型與科技賦能**：全面提升全員之數位素養、數據分析能力及AI工具應用。
2. **領導力與管理效能深化**：強化中高階主管之策略思維、跨部門協作與敏捷管理能力。
3. **核心專業與品質精進**：深化各事業群之專業技術、法規遵循、客戶服務與資訊安全意識。

## 第三章 課程體系與架構

本年度教育訓練體系分為四大構面：「新進人員訓練」、「專業職能訓練」、「管理職能訓練」及「通識與法遵訓練」。

```
┌─────────────────────────────────────────────────────────┐
│                    年度教育訓練體系                         │
└────────────────────────────┬────────────────────────────┘
                             │
       ┌─────────────────────┼─────────────────────┐
       ▼                     ▼                     ▼
 ┌──────────┐         ┌──────────┐         ┌──────────┐
 │ 新進人員 │         │ 專業職能 │         │ 管理職能 │
 │  訓練    │         │  訓練    │         │  訓練    │
 └────┬─────┘         └────┬─────┘         └────┬─────┘
      │                      │                    │
      └─────────────────────┼─────────────────────┘
                             │
                             ▼
                      ┌──────────┐
                      │ 通識法遵 │
                      │  訓練    │
                      └──────────┘
```

### 3.1 新進人員訓練（Onboarding Program）
旨在協助新進同仁快速融入企業文化並掌握工作技能。
1. **新人入職培訓（Orientation）**：
   * **時數**：到職首週內完成共計 16 小時。
   * **內容**：公司願景與核心價值、企業文化、人事規章、資訊安全政策、勞工安全衛生。
2. **「導師制」（Buddy System）**：
   * **實施方式**：每位新進員工指派一位資深同仁擔任導師（Buddy），進行為期三個月的實務工作指導與生活適應協助。
   * **考核**：試用期滿前需通過新人結業測報與實作考核。

### 3.2 專業職能訓練（Professional Competency Training）
依據各部門特性規劃專屬課程，涵蓋技術、業務、研發與支援單位。
1. **業務暨行銷團隊**：
   * 顧問式銷售技巧（Consultative Selling Skills）。
   * B2B數位行銷與社群流量變現策略。
   * 關鍵客戶關係管理（Key Account Management, KAM）。
2. **研發暨工程團隊**：
   * 敏捷開發（Agile/Scrum）專案管理實務。
   * 雲端架構安全與微服務設計。
   * 新興技術工作坊（如：Generative AI 在工程上的應用）。
3. **營運暨支援團隊（財務、人資、法務、行政）**：
   * 財務報表分析與成本控制。
   * 勞動法令最新修法解析與風險防範。
   * 高效溝通與跨部門衝突解決。

### 3.3 管理職能訓練（Leadership Development Program）
針對各級主管分層實施，打造具前瞻性與執行力的管理團隊。
1. **初階主管（新任組長/副理）——「卓越管理者工作坊」**：
   * 從工作者到管理者的心態轉變。
   * 目標管理（MBO）與績效面談技巧。
   * 部屬培育與指導技術（Coaching Skills）。
2. **中高階主管（經理/協理以上）——「策略領導學苑」**：
   * 策略思維與商業模式創新。
   * 變革管理與組織敏捷度提升。
   * 危機處理與高階決策模擬。

### 3.4 通識與法遵訓練（General & Compliance Training）
全體員工必修之基本素養與法規遵循課程。
1. **資訊安全與個資保護**：全員年度必修，防範社交工程攻擊與個資法規遵循（含測驗）。
2. **職場性騷擾防治與多元共融（DEI）**：建立尊重、包容且無歧視之職場環境。
3. **職場健康與安全衛生**：人因工程、壓力管理、急救常識及防災演練。

## 第四章 培訓實施方式與資源配置

### 4.1 多元化學習模式（Blended Learning）
為因應混合辦公模式與不同世代員工的學習習慣，本年度採用多元學習管道：
1. **實體課程（Classroom Training）**：強調互動、演練與深度討論，主要應用於管理職能、團隊建立及高互動性工作坊。
2. **線上數位學習（E-Learning）**：利用內部「企業學習管理系統（LMS）」，提供法遵、資安及基礎軟體應用等隨選課程（On-demand），供員工自主安排學習。
3. **混合式工作坊（Hybrid Workshop）**：結合線上與實體，邀請產學界專家進行專題講座。
4. **讀書會與知識分享會（Brown Bag Lunch）**：鼓勵部門內部或跨部門發起自主性學習，分享產業趨勢、新書心得或專案經驗。

### 4.2 內部講師培訓計畫（Train-the-Trainer）
為落實組織內部知識傳承，並建立學習型企業文化：
1. **內部講師甄選**：每年招募具備豐富實務經驗與熱忱之資深員工擔任內部講師。
2. **師資培訓**：舉辦「內部講師授課技巧訓練營」（Train-the-Trainer, TTT），提升教材編寫、簡報技巧與互動引導能力。
3. **鐘點費與獎勵機制**：訂定優於市場行情之內部講師授課鐘點費，並將授課時數納入年度考績與晉升加分項目。

### 4.3 外部訓練補助政策（External Training Subsidy）
為鼓勵同仁主動進修外部專業課程或取得國際證照：
1. **公假進修**：員工報名與職務相關之外部短期研討會、訓練課程，經主管核准可請公假。
2. **學費/證照補助**：
   * 鼓勵員工報考與公司業務高度相關之專業證照（如 PMP、AWS、CPA、CFA 等），考試通過者得憑證照與收據申請全額或半額補助。
   * 參與長期學位進修或專業學程者，得依《員工進修補助辦法》申請專案補助。
3. **服務年限義務**：接受公司全額補助外部培訓或取得特定證照之員工，須簽署培訓服務協議，於結訓後在公司任職滿一定期限（通常為 1 至 2 年），以確保人才投資之效益。

## 第五章 訓練成效評估與追蹤

為確保教育訓練之品質與投資報酬率，本年度將採用著名的**柯氏四級評估模式（Kirkpatrick Four-Level Training Evaluation Model）**進行全方位評估：

```
┌────────────────────────────────────────────────────────┐
│               柯氏四級評估模式 (Kirkpatrick)             │
└───────────────────────────┬────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
  ┌──────────┐        ┌──────────┐        ┌──────────┐
  │ 第一級： │        │ 第二級： │        │ 第三級： │
  │ 反應評估 │        │ 學習評估 │        │ 行為評估 │
  └─────┬────┘        └─────┬────┘        └─────┬────┘
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │
                            ▼
                      ┌──────────┐
                      │ 第四級： │
                      │ 結果評估 │
                      └──────────┘
```

### 5.1 第一級：反應評估（Reaction / Smiley Sheet）
* **評估時點**：每堂課程結束後即時進行。
* **評估方式**：透過 LMS 系統填寫線上回饋問卷。
* **評估指標**：課程內容實用性、講師表達能力、教材品質、場地設備滿意度（滿分 5 分，目標平均分須達 4.3 分以上）。

### 5.2 第二級：學習評估（Learning）
* **評估時點**：課程進行中或結束後。
* **評估方式**：透過課後測驗、實作演練、個案研討發表或線上測驗。
* **評估指標**：知識吸收程度，學員測驗通過率須達 85% 以上。

### 5.3 第三級：行為評估（Behavior）
* **評估時點**：課程結束後 3 至 6 個月。
* **評估方式**：由人力資源部發放問卷，針對受訓員工及其直屬主管進行 360 度回饋調查。
* **評估指標**：觀察受訓者返回工作崗位後，其工作行為、技能應用與工作效率是否有顯著改善與轉化。

### 5.4 第四級：結果評估（Results）
* **評估時點**：年度結束時。
* **評估方式**：結合公司年度業務指標（如營業額成長率、客訴率降低、專案如期完成率、離職率變化等）。
* **評估指標**：評估整體教育訓練計畫對公司營運績效與財務指標之實際貢獻度（ROI）。

## 第六章 年度訓練行事曆與預算規劃

### 6.1 年度訓練執行時程規劃（範例）
* **第一季（1月 - 3月）**：
  * 完成年度訓練需求調查與計畫公告。
  * 啟動新進人員引導計畫與資安、法遵必修課程上線。
  * 舉辦「卓越管理者工作坊」（初階主管培訓）。
* **第二季（4月 - 6月）**：
  * 推動專業職能訓練系列（業務技巧、敏捷開發工作坊）。
  * 辦理內部講師培訓營（TTT）。
  * 啟動外部專業證照補助申請審查。
* **第三季（7月 - 9月）**：
  * 辦理「策略領導學苑」（中高階主管培訓）。
  * 推動跨部門知識分享會與讀書會。
  * 進行年中訓練成效檢討與課程調整。
* **第四季（10月 - 12月）**：
  * 持續辦理未完成之線上必修課程與補課。
  * 執行柯氏三、四級評估（行為與結果評估）。
  * 彙整年度訓練成果報告，並著手規劃次年度訓練計畫。

### 6.2 預算編列原則與配置
1. **預算總額**：本年度教育訓練總預算依據公司年度總人事成本之特定比例（建議為 1.5% - 2%）進行編列。
2. **經費配置比例**：
   * **外部訓練與講師費（45%）**：用於邀請外部重量級專家學者、委託專業培訓機構及員工外部進修補助。
   * **內部培訓與教材開發（25%）**：用於內部講師鐘點費、教材版權採購、內部工作坊場地與餐飲。
   * **數位學習系統維運（20%）**：LMS 系統平台訂閱費、線上課程版權採購。
   * **其他雜支與認證獎勵（10%）**：證照通過獎金、訓練成果發表競賽獎項及行政雜支。
3. **預算管控**：各部門得依業務需求提出專案培訓申請，由人力資源部統籌控管，確保預算得到最有效之運用。

## 第七章 附則

### 7.1 考勤與結業規定
1. 凡經排定參加公司舉辦之必修課程（含實體與線上），學員應準時出席並完成簽到退。因故無法出席者，須於事前完成請假手續並擇期補課。
2. 未經請假缺席或無故曠課者，將依公司工作規則處分，並列入年度考核之參考；若為必修法遵課程未在期限內完成者，取消當年度績效獎金評定資格，直至補課完成為止。

### 7.2 計畫修訂與解釋權
本計畫由人力資源部負責擬定、執行與檢討，並得視公司營運策略調整之需要，呈報總經理核准後進行修訂。本計畫之解釋權歸公司人力資源部所有。
