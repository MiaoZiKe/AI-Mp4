# tech-target 畫面規格（可執行）
單位 1＝10 cm，晶圓直徑 3。建模 gen-model.mjs，腳本 genscript.py，2D 卡 HudTarget.tsx（target-*）。陰極總成沿 y 軸疊，靶面朝下對晶圓；本集不畫整台集群機台。

## 二、物理表現
氬氣稀薄擴散（細粒子）；離子 accel 加速帶拖尾；原子餘弦分布（中間多、斜向少）＋一道被散射；電子沿跑道轉圈；磁場線半橢圓；磁鐵起轉停轉；冷卻水沿水路流；溝 V 形逐階段加深；焊料先厚後薄、邊緣圓鈍；軋輥與輸送滾輪方向正確。
## 三、爆炸順序
高壓接頭與上蓋＋驅動 → 磁鐵組 → 水腔＋水管 → 背板 → 焊層 → 靶材（不動）→ 遮蔽環往下；s5 起組回下半截（上半截 s3 起退場，s12 全部回來）。一次一張標籤。
