# tech-clean 旁白稿：清洗（接離子佈植；片尾預告氧化與熱處理）

1. 【鉤子】上一支打完離子，光阻焦硬，表面也髒。先進晶片要洗五十次以上，為什麼？
2. 因為線寬只剩幾十奈米，一顆線寬一半大的顆粒，就可能讓線路短路。
3. 先去光阻。焦硬的殼，用氧電漿低溫慢慢燒掉，叫灰化。
4. 不能高溫，因為底下的光阻會冒氣，把殼撐破，碎片噴滿晶圓。
5. 殼燒穿後再加溫燒乾淨，殘渣用硫酸加雙氧水溶掉。
6. 接著是單片清洗。晶圓在轉盤上旋轉，噴嘴從中心掃到邊緣，把顆粒往外甩。
7. 黏太緊的小顆粒，用兆音波。每秒振動約一百萬次，推出細小水流，把顆粒推走。
8. 藥液輪流換，一種去顆粒和有機物，一種去金屬，每換一次都用超純水沖淨。
9. 最後是乾燥。直接甩乾會留水痕、拉倒細線，所以用異丙醇把水換掉，從中心往外推乾。
10. 【公司】機台有日本的迪恩士、東京威力科創、美國科林研發；台灣辛耘、弘塑做先進封裝的濕製程。
11. 【結尾】表面洗乾淨，才長得出均勻的氧化層；離子也要加熱才會歸位導電。所以下一支，看氧化與熱處理。留言清洗，看完整解說。

## 因果鏈
離子佈植片尾「光阻打到焦硬、表面也髒，所以下一支看清洗」→ 本片 s1 直接接「上一支打完離子，光阻焦硬，表面也髒」→ 為什麼要洗這麼多次（因為線寬小、一顆顆粒就短路）→ 所以先去光阻（灰化）→ 但不能高溫（爆裂）→ 殼穿後才加溫、殘渣用 SPM → 接著單片旋轉清洗 → 黏太緊的用兆音波 → 藥液輪流、超純水沖 → 最後乾燥（IPA）→ 誰在做 → 因為洗乾淨才長得出均勻氧化層、離子也要加熱才導電 → 所以下一支看氧化與熱處理。
