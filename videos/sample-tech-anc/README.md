# sample-tech-anc — 科技頻道試片：3D 產品台＋運作動畫（耳機主動降噪），2026/11/14 留存改版

使用者看完上一版（19.2 秒）說：「已經很棒了，但請專業人員評估。剛開始要能吸引關注：前 3 秒內就能抓住目光，以及讓人想繼續看的理由。可以參考 CoWoS 那支。」
三位評審的評估整理在 `docs/tech-3d-expert-review.md`，檢查清單在 `docs/channels/tech-3d.md`。這一版照採用的建議重做：先給結果再拆開、中段加衝突與逐步揭曉、結尾加提問與下一集鉤子。
模型沿用 `videos/bake-a/` 的示意耳機（非特定機型、沒有商標），`bake-a` 本身沒有動。

## 旁白（129 字、10 句，親和專業、沒有語助詞）

1. 降噪耳機會安靜，是因為它也在出聲。
2. 多一個聲音，怎麼會更安靜？
3. 拆開看，噪音先被麥克風收到。
4. 晶片馬上算出相反的波形。
5. 喇叭放出來，送進耳道。
6. 兩道波一疊，噪音抵消掉一大半。
7. 可是有人講話，還是聽得到。
8. 它擅長低沉的嗡嗡聲，變化快的就對不準。
9. 你的耳機，最消不掉哪種聲音？
10. 對了，裡面還有一顆朝內的麥克風。下一集講。

寫法說明在 `script.md`，事實依據在 `research.md`（第 1、2、4、5、6 點；第 6 點與「為什麼高頻難」是這次補查的）。

## 已知問題

- **無聲版**：節奏是估的。配音後每個 cue 會移動，前 3 秒的事件時間要重看（特別是「安靜」和「出聲」之間有沒有空太久）。
- **前 3 秒的事件間隔**：第 1.3 秒蓋章到第 1.9 秒畫圈之間、第 1.9 到 2.75 秒之間，只有聲波圈和波形在動，沒有新東西出現。和 CoWoS「每半秒一個事件」比還是疏一點。
- **耳機側面看起來仍然偏小**（頭部約佔畫面寬三成），握柄下半被波形面板蓋住。沒有加耳朵剪影，第一眼認不認得出是耳機，要請沒看過的人看一次。
- **「變化快的就對不準」是簡化的說法**。查到的依據是「高頻波長短、相位要對得很準」與廠商說明「對人聲這類較高頻的聲音效果較差」（research.md 第 6 點與分析預期），都只看到搜尋摘要，沒有逐頁讀原文。畫面上「人聲」的波形、藍波慢多少、「一大半」的比例都是示意，不是量測。
- **「下一集講」是還沒兌現的承諾**：這支是試片，回饋式麥克風那一集還沒有做。
- 朝內的麥克風在模型上是喇叭外框旁一顆小方塊，圈起來之後看得到，但零件本身很小；它的位置是示意，不對應任何機型。
- s9 提問卡出現後到念「哪種」之前約 1.5 秒，畫面只有底部波帶在動。
- s6–s8 的波形基準線略斜（模型躺下後還在慢慢轉），和上一版一樣。
- 聲波圈、波形畫在最上層，不會被零件擋住，所以開場的紅圈是疊在耳機前面，不是真的繞過去。
- 只演了前饋式（外側麥克風）這一條路。
- `voice.profile` 用的是 `tech` 預設檔加 `delivery: "warm-pro"`：提示詞裡的 Tone 一行仍是 tech 預設的「像跟熟的朋友聊天」，和「親和專業」不完全一致；這次沒有改預設檔（共用檔），試聽後如果覺得太隨興再調。
- 封面（`out/sample-tech-anc-cover*.png`）改成停在開場第 24 幀，1:1 與 3:4 兩張沒有逐張細看。
- audit、selfcheck 沒有跑（它們的門檻是照 v2／紙拼貼訂的）。
- validate 有 2 個 warning：s6 新增 3 張標籤（建議 ≤2）、估算長度超過「風格試片 10–15 秒」的建議（這支指定做到 25–30 秒）。
