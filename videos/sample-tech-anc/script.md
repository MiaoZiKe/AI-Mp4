# 降噪耳機怎麼把噪音抵消掉？（sample-tech-anc，科技頻道 3D 產品台＋運作動畫試片）

旁白（83 字，目前是無聲估算時間軸；口吻＝親和專業，不用欸、啦、齁這類語助詞）：

1. 降噪耳機會安靜，是因為它也在出聲。
2. 拆開看，關鍵是麥克風、晶片和喇叭。
3. 外面的噪音，麥克風先收到。
4. 訊號送進晶片，算出相反的波形。
5. 振膜一振動，反相聲波送進耳道。
6. 兩道波疊在一起，剛好抵消，
7. 你只聽到安靜。

寫法說明：
- 第一句先給反直覺的結論（要安靜，反而要出聲）；第 2 句只點三個等一下會用到的零件，拆解到這裡就結束。
- 第 3–7 句照訊號實際走的順序講，一句只講一步，每一步畫面上都有東西對到念到的詞（見 `README.md` 的每鏡說明）。
- 全片沒有語助詞；連接只用「是因為」「剛好」。句子長短交錯，最後一句最短。
- 沒有數字（不放 dB、不放百分比），事實依據見 `research.md`。

配音：今天沒有送任何 TTS 請求。設定寫在 `script.json` 的 `voice`（Iapetus、`tech` 預設檔＋`delivery: "warm-pro"`、語速 4.6–5.0 音節/秒）。
