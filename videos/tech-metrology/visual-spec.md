## 三、運作動畫（每段寫流動物種類與形狀，#54）
| 段 | 幕 | 動作（順序、方向、同步） | 流動物 |
|---|---|---|---|
| A 膜厚 | s3 | 載台把晶圓移到量測點（減速、微回彈）→ 白光燈亮 → 一束細光斜打在膜上 → 一部分在表面反射（短路徑）、一部分穿過膜在底面反射再出來（長路徑）→ 兩道反射光在偵測臂前重疊，亮暗條紋隨「膜厚」變動（用旋鈕式 meter：厚度 ± 小幅）→ 光譜儀條紋跟著移，讀出厚度（示意值，不標沒查證的數字） | 光＝直線光束／平行光帶（白色，反射光略偏暖色與偏冷色）；干涉＝兩道光相疊處的明暗條紋（波形 trace） |
| B 線寬 | s4 | 電子槍燈絲亮 → 一束細電子束沿鏡柱直線加速向下 → 偏轉線圈擺動，束沿線條橫向掃過 → 打在線條邊緣處放出較多二次電子（小「−」點），被側上方偵測器吸過去（彎曲路徑，不是飄在半空）→ 訊號波形在邊緣處兩個峰 → 峰間距＝線寬，標尺量出 | 電子＝更小的「−」點（主電子沿鏡柱直線、二次電子短弧線）；訊號＝波形 trace；只在鏡柱與腔內 |
| C 疊對 | s5 | 晶圓切割道上放大到兩層光柵 → 光從上方打下 → 繞射成 0 階與 ±1 階三道光 → 兩側偵測器各收一道 → 兩邊亮度條（bars）比較：歪就一高一低、不歪就等高 → 「差多少就是歪多少」：亮度差轉成偏移量，上層光柵橫移動畫對應 | 光＝直線光束（0 階向上反射、±1 階向兩側斜出）；亮度比較＝長條（bars）；全部在光柵上方空間內 |
| D 缺陷 | s6 | 寬光帶從晶圓一側掃到另一側（等速掃描線，兩端加減速）→ 掃過處晶圓亮起，發現缺陷時彈出色點，累積成缺陷圖 → 鏡頭切到電子束複檢：載台移到第一個色點（減速）→ 視窗放大成顆粒外形 → 逐點跳下一點（每點 1 秒內） | 光＝光帶（寬線）；缺陷點＝色點（橘）；電子束＝細束；顆粒＝不規則團塊，飄不起來，貼在晶圓表面 |
| E 回饋 | s7 | 量測機顯示數值（偏移量，由灰轉綠或橘）→ 一串方波脈衝沿資料線送到曝光機 → 曝光機載台微調一下 → 另一邊：有缺陷的晶圓由手臂夾起放進紅色「檢出」盒 | 訊號＝沿線路前進的方波脈衝＋箭頭；只在線上 |

## 四、2D 剖面卡（section kind 命名建議 met-*，念到就完整，不留空框）
1. met-prev（s1）：上一支結果「膜已磨平」→「這麼平，要量到幾奈米？」：膜剖面＋兩個奈米數字尺（示意）。
2. met-film（s3）：側視圖，入射光、兩條反射光、膜層、基板，右側干涉條紋與光譜曲線，隨 cue 亮：光打在膜→各反射一次→疊起來→亮暗不同→算出厚度。
3. met-cd（s4）：線路剖面＋掃描位置游標，下方二次電子訊號曲線，邊緣處兩個峰，峰間距標「線寬」。
4. met-ovl（s5）：兩層光柵側視（藍下、橘上）、0 與 ±1 階光、兩個亮度長條，上層橫移時長條一高一低。
5. met-def（s6）：晶圓圖（含缺陷色點）＋兩段式流程條（光學掃描→電子束複檢），「快／粗」與「慢／細」兩欄對照（新舊對照卡概念）。
6. met-co（s8）：公司引線卡，見第五節。
2D 卡位置照 tech-cmp：x 64、w 952，y 與 h 依畫面空白決定，卡片「找空白、主素材固定置中放大」。
