## 已知問題

1. **selfcheck 的單幀跳變關口沒過（22 幀）**：第 8、12、52、54、208、331、334、336、540、542、568、658、934、1062、1102、1134、1248、1250、1402、1445、1802、1804 幀。拿幀號對照 cue 表，這些幀都落在紙片貼上或滑入的時刻（鉤子的照片與紅標、s04 處理器照片蓋上、s07 基板與主機板滑入、s12 訂單紙、s14 長條、s19 大樓照片等）。CLAUDE.md 已記載這個關口是照 v2 訂的，v3 的「貼上」會被算成跳變（what-is-server 是 13 幀）。這 22 幀我沒有逐張放大看，也沒有改門檻。
2. **事實來源沒有人讀過原文**：`research.md` 寫明全部來自搜尋摘要。上片前請打開 F1（CoWoS 是什麼）、F6（2012 年推出）、F9（2026/10/15 法說會、封裝越做越大）、F10（產能約 7 萬 → 約 11.5 萬片，法人估；商周轉載中央社那篇的日期沒確認）的原文各確認一次。
3. **s08「通常用矽做」有被挑錯的風險**：`research.md` F4 寫中介層有三種（一整片矽、重佈線層、重佈線層埋小塊矽橋），媒體描述目前最高階 AI 晶片多用第三種。「通常用矽做」不算錯，但不精確。要改得更保守（例如「最早是用矽做」，要先確認出處）就得整篇重配音。
4. s10、s11、s18 推近時，基板左右兩端超出左右 64px 安全區（紙本身出血，字都在安全區內）。
5. s17 畫面上的「良率／EUV／2 奈米」只是提問的例子，沒有對應的旁白與出處。
6. `timeline.json` 的 s10 字幕分段是手改的（把兩段併成一段），沒有重跑對齊。`script.json` 的字幕已同步，之後重跑 `npm run align` 應該得到相同結果；若不同要再看這一段。
7. `caption.md` 沒有寫 AI 輔助製作；片中依指示不加 AI 標示，貼文要不要加請你決定。

## 需要人耳確認（我和評審都聽不到音檔）

聽成片 `out/tech-cowos.mp4`（下面的秒數是成片時間）。

1. 整支：加速 1.06 倍之後有沒有機械感、尾音有沒有被切；語氣是不是「稍快、稍嚴肅」；BGM 有沒有蓋到人聲。
2. 56.2–58.7 秒「對了，旁邊那排記憶體叫 HBM」：全片對齊信心最低的一句（0.764，最低的字 0.224）。聽「對了」有沒有被吞、「HBM」三個字母是不是分開念清楚（約 57.8 秒）。
3. 「CoWoS」的念法：約 5.0 秒、6.5 秒、49.5 秒三處，念法是不是一致、聽得懂。
4. 「AI」：0.0 秒（開頭第一個字，有沒有被切到）、約 37.9 秒。
5. 19.7 秒「中介層」、約 22 秒「通常用矽做」的「矽」（ㄒㄧˋ）。
6. 41.1–45.2 秒「法人估，台積電今年底產能，比去年底多一半以上」：「法人估」有沒有念清楚，這是區分估計和事實的關鍵詞。
7. 26.1–29.7 秒「接點太密、線路太粗、接不上」：三個短句的停頓是不是自然；畫面的紅叉是不是在「接不上」出現（約 29.5 秒）。
8. 59.0–61.3 秒「它為什麼要疊得像大樓？下一集講。」：問句語調、最後三個字會不會太趕。

任何一個字要改都得整篇重配（1 次 TTS 請求），再做加速、align、render。
