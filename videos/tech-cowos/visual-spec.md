## 7. 已知的事

- validate 是 0 error。警告「場上同時有 N 樣主要元素」是因為三層剖面圖的每一張色紙都算一樣，而且鏡頭外的也算進去；實際每一鏡畫面上是「剖面圖＋一到兩樣新東西」。
- s10、s11、s18 推近時，基板左右兩端會超出左右 64px 的安全區（紙本身出血，字都在安全區內）。
- 畫面上的名詞「良率／EUV／2 奈米」只是提問的例子，沒有對應的旁白與出處。
- 字幕：s10 的「基板線路太粗」和「接不上」併成一段（原本「接不上」只顯示 0.6 秒）。這是直接改 `timeline.json` 的 s10 `lines` 和 `sub`，沒有重跑對齊；之後如果重跑 `npm run align`，結果應該一樣（`script.json` 的字幕已經同步改了），不一樣的話要再檢查這一段。s18 英文拆成三段。
- 片尾卡關掉右上角的紙雲（`cloud: false`）。
