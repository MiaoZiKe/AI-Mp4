# 分鏡（bake-a）

時間是無聲估算（scripts/ui/silent-timeline.mjs，每秒 4.9 個音節），配音後會跟著 cue 自動移動。

| 幕 | 旁白 | 畫面 | cue → 動作 |
|---|---|---|---|
| s1 鉤子 | 欸，降噪耳機會安靜，其實是它在出聲。 | 第 0 幀大標「耳機出聲才安靜？」；深色示意耳機立著轉一圈（看得到背面的耳塞） | start → 轉盤 |
| s2 | 拆開外殼，電池、晶片、天線， | 躺下、沿厚度分成 8 層（外殼｜電路板｜電池｜喇叭單體｜內殼｜耳塞｜兩片波形盤），殘影＋導引虛線 | 外殼 → 分解；電池／晶片／天線 → 三張標籤 |
| s3 | 還有喇叭跟好幾顆麥克風。 | 電池、天線標籤退場 | 喇叭 → 喇叭單體標籤；麥克風 → 麥克風標籤 |
| s4 | 麥克風聽到噪音，晶片算出相反的聲波， | 最下面珊瑚色波形盤貼「噪音」；念到「相反」鏡頭推近兩片波形盤，其他層飛走 | 噪音 → 標籤；相反 → 聚焦＋「反相聲波」標籤 |
| s5 | 喇叭一放，兩邊一疊就抵消啦。 | 兩片波形盤靠近、鏡頭繞開再推回；「抵消」標籤 | 放 → 鏡頭繞開；抵消 → 推回＋標籤；最後 20 幀自動後退 |

引擎限制：沒有 thermal 的產品不能用掀蓋／粒子／光掃聚光燈；聲波不能逐幀變形，所以「抵消」用兩片反相波形盤靠近＋標籤表達，沒有做「疊成一條直線」的動畫。
