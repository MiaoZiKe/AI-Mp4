## 1. 無塵室原理
| 內容 | 來源 | 信心 |
|---|---|---|
| 潔淨度依 ISO 14644-1，以**每立方公尺**微粒數分級；ISO Class 1 在 ≥0.1 µm 微粒上限約 **10 顆／m³**（舊 FED-STD-209E 用立方英尺，已被取代） | [1] horiba 分級表、igus 說明、terrauniversal ISO／209E 對照 PDF | 高（分級定義，多源一致） |
| **ISO 1 在實務上極少見；晶圓廠常見 ISO 5～7（整廠），最敏感區（如曝光）更高**，ULPA 用於 ISO 3～5 | [2] 檢索摘要（含 ASHRAE 概述） | 中 → 念稿寫「最乾淨那一級」，**不說晶圓廠整體達 ISO 1** |
| 垂直單向（層流）：乾淨空氣由天花板高效率濾網送下，從地板抽回，通常配高架（穿孔）地板循環；FFU（風扇濾網單元）＝風扇＋HEPA／ULPA 濾網，大型廠有數千到數萬台，單台故障只損失小部分風量 | [3] Wikipedia Cleanroom／Fan filter unit、ASHRAE Handbook ch.18（clean spaces）、USPTO 9115910 | 高 |
| 流速約 0.3～0.5 m/s、FFU 覆蓋率 80～100%（ISO 1 等級的廠商表）；換氣次數各來源衝突（Class 1000 約 50～150 次／時；ISO 2 約 300～720 次／時）→ **不上片** | [1][4] | 低（衝突） |
| HEPA 定義：對 0.3 µm 微粒效率至少 99.97%；ULPA 對更小、用於最敏感區 | [5] 檢索摘要（IEST／供應商） | 高（定義，通識）；念稿不寫數字 |
| 濾網機制：纖維網以攔截、慣性撞擊、擴散等方式捕捉微粒（不是單純篩孔） | 通識 | 高；比喻「纖維迷宮」可用 |
| **人員是最主要微粒來源**：估計人與其攜帶的微粒微生物約占 75～80%；穿全套無塵衣靜止約每分鐘 10 萬顆微粒、走動約 100 萬顆（供應商部落格）；一項研究指衣物貢獻不到 4%、主要來自人體 | [6] rssl.com、prudentialuniforms、agris.fao.org 論文摘要 | 中（75～80% 是供應商說法；念稿只說「最大來源之一」→ 改寫為「最大的灰塵來源，其實是人」，**需審片人確認口氣**，保守可改「主要來源」） |
| **正壓**：無塵室氣壓高於外面，開門時空氣往外流，阻擋外面污染；晶圓廠通例 | [7] Wikipedia Cleanroom、ASHRAE（檢索摘要） | 高 |
| 溫度、濕度為環境污染因子之一（影響材料膨脹、靜電）；半導體廠「約 22°C／45%」常被提到，**本次沒查到來源** | [6] | 中（只說「固定」，無數字） |

| 比喻 | 幕 | 對應物理動作 | 風險 |

| 一道往下流的瀑布 | s3 | 垂直單向氣流把微粒往下帶走、不被捲起 | 不會；畫面箭頭平行向下、不亂流 |

## 4. 分類（上片守則）
- **已確定**：ISO 14644-1 以每立方公尺分級；ISO 1 的 0.1 µm 上限約 10 顆；垂直層流＋天花板濾網＋地板回風；HEPA 定義；無塵室正壓；人是主要微粒來源之一。
- **媒體報導**：漢唐、亞翔、洋基為無塵室／機電工程商，訂單創高。
- **分析推測**：「人占 75～80%」。
- **查不到**：晶圓廠各區實際 ISO 等級（官方）；換氣次數；溫濕度設定；國際無塵室工程廠；洋基與台積電關係原文；各家市占。
