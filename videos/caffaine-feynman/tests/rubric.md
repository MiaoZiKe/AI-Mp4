# 實測做法（先寫，再跑；2026/11/17）
主題（上班族會想學、不涉及投資建議）：複利。模型：gemini-3.5-flash-lite，Gemini API 多輪對話。
第 1 步提示：叫 AI 用國中生聽得懂的話解釋（≤150 字，一個生活例子）。
第 2 步：我用自己的話講一遍。故意放一個常見誤解（把複利講成「每年固定領同一筆利息」）：
  「複利就是銀行每年固定給你一筆利息，存越久領越多，利率越高越好。」
第 3 步提示：叫 AI 當老師，指出我講錯或漏掉的地方，再問我一個問題檢查有沒有懂；先不要給完整答案。
  判讀：回覆有沒有指出「利息也會再生利息（利滾利）」這個核心差異。第 3 步另外重送 2 次（共 3 次，同一個對話脈絡），看每次有沒有抓到。
第 4 步提示：叫 AI 把正確版本再簡化成一句我能講給同事聽的話。
