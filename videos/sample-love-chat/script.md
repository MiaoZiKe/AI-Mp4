# script.md — sample-love-chat（10–15 秒風格試片，不是完整影片）

題目：大家都有對象了，只剩我？
形式：對話泡泡。整個畫面是一個自製的聊天介面，訊息跟著旁白一則一則跳出來，中段打開一張統計卡。

| 幕 | 旁白（字幕同） | 畫面（都由配音 cue 觸發） |
|---|---|---|
| s01 | 你也傳過這種訊息嗎？ | 朋友的訊息已經在畫面上；下方輸入框正在打字 |
| s02 | 大家都有對象了，只剩我。 | 念到「大家」送出第一則、念到「只剩我」送出第二則；接著出現「已讀」與對方輸入中的三個點 |
| s03 | 先看一個數字。國科會的萬人調查發現， | 對方回「先看這個數字」；念到「國科會」跳出調查卡片，念到「萬人」人數數字跳到位 |
| s04 | 沒結婚的裡面，大約三分之二沒有對象。 | 統計卡從下面升起蓋住對話：30 個圓點；念到「三分之二」20 個上色、大字 2/3；念到「沒有對象」標籤落下 |
| s05 | 單身的，不是只有你。 | 統計卡收起，對方說「單身的不是只有你」；自己回一則，對方的訊息被按了愛心 |

共 63 字。沒有片尾卡。
