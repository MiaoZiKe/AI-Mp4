# sample-love-chat — 感情頻道風格試片：對話泡泡

這是 10–15 秒的**風格試片**，不是完整影片（沒有片尾卡，也沒有完整的起承轉合），用來和其他三種風格一起挑。

- 成片：`out/sample-love-chat.mp4`（1080×1920、30fps、H.264，13.97 秒、419 幀）
- 人聲：`out/sample-love-chat/voice-final.wav`
- 題目：大家都有對象了，只剩我？
- 旁白（63 字）：你也傳過這種訊息嗎？大家都有對象了，只剩我。先看一個數字。國科會的萬人調查發現，沒結婚的裡面，大約三分之二沒有對象。單身的，不是只有你。

## 風格說明

整個畫面是一個自己畫的聊天介面：上面是聯絡人列，中間是對話串，下面是輸入框，最下面的深色面板放旁白字幕、英文副字幕與出處。
訊息跟著旁白一則一則跳出來（先在輸入框打字、送出、已讀、對方輸入中的三個點），講到數字時從下面升起一張統計卡（30 個人形，20 個上色，大字 2/3），最後回到對話收尾。
和紙拼貼的差別：沒有紙材、沒有桌面與鏡頭移動；全部是乾淨的介面元件、圓角泡泡和彈出動作，配色是珊瑚紅配深梅子色。

介面是中性的自製樣式，不仿任何真實通訊軟體，沒有商標與真人頭像。畫面右上角與出處列固定標示「情境示意，非真實對話」。

## 怎麼做的

- `script.json` 頂層 `styleVersion: 3` 加 `stage: "chat"`：配音、對齊、字幕檔、混音都沿用 v3 的整篇配音流程，只有畫面換成 `src/components/chat/`。
- 每幕 `component: "ChatScene"`，`props.events` 列出這一幕發生的事：`bubble`（訊息）、`compose`（輸入框打字）、`read`（已讀）、`typing`（對方輸入中）、`card`（調查卡片，數字會數上去）、`stat`（統計卡）、`react`（按愛心）。
- 每件事的 `at` 只寫 cue id，或 `start｜voice｜end｜exit` 加減幾幀；要用別幕的 cue 寫 `幕id:cue`。沒有手填秒數。開場前就在畫面上的訊息寫在頂層 `chat.history`。
- 檔案：`src/components/chat/engine.ts`（把 cue 換成絕對幀、排對話串）、`src/components/chat/ChatVideo.tsx`（畫面）、`src/theme.ts` 的 `THEME_CHAT`／`LAYOUT_CHAT`（顏色與版面，元件不寫死色碼）、`scripts/chat/validate-chat.mjs`（檢查）、`scripts/chat/sfx.mjs`（把訊息跳出的幀寫成音效事件）。
- 指令順序：`npm run validate sample-love-chat` → `node scripts/tts-take.mjs sample-love-chat` → `npm run align sample-love-chat` → `node scripts/chat/sfx.mjs sample-love-chat` → `node scripts/v3/peek.mjs sample-love-chat <圖檔> <幀,…>` 看畫面 → `npm run render sample-love-chat`。

## 配音

- 音色 Sulafat、`gemini-2.5-flash-preview-tts`、`cmn-TW`、整篇一次生成。**只送了 1 次請求，成功，沒有重送。**
- 設定檔：`love` 預設檔改寫，語速目標 4.6–5.0 音節/秒，語氣寫明「講話偏快、很俐落，一句接一句，不拖尾音」。
- 量到的語速：63 個音節／13.37 秒（含句間停頓）＝ **4.71 音節/秒**，在目標內。之前試聽的 love-stats-Sulafat 是 4.18。**沒有做後製加速。**
- 捲舌指標（ㄗㄘㄙ − ㄓㄔㄕ）：3.6 kHz。但稿子裡 ㄗㄘㄙ 開頭的字只有 2 個，樣本太少，這個數字不可靠，要用聽的。
- 對齊信心：整篇 0.923；s03、s04 各有一個字信心很低（最低 0.015–0.05），可能是輕聲字或對齊誤差。

## 渲染

- 渲染 22 秒（419 幀，每幀約 51 毫秒，4 核心、不需要 GPU），連打包與混音整個指令約 31 秒。
- 混音後 −14.2 LUFS；有自己合成的背景音與 7 個音效（6 個訊息提示音、1 個鐘聲）。

## 已知問題

- 查證只看了搜尋結果摘要，沒有打開原文；國科會調查的原始報告、抽樣方式沒查到。「三分之二」是遠見雜誌轉述學者的說法，不是官方統計表。詳見 `research.md`。
- 沒有跑 `npm run still`（封面與覆蓋率檢查）。封面元件有接（停在統計卡那一幀），但沒有實際跑過；畫面是用 peek 與成片抽幀看的。
- 沒有跑 audit 與 selfcheck（那些門檻是給完整影片的）。
- 安全區上方 0–220px 只有白底，下方 1700–1920px 只有深色面板，沒有放內容。
- 對話內容是寫死在 `script.json` 的情境，做成正式影片時每支都要自己寫對話。
- `audio.events` 裡的幀數是 `scripts/chat/sfx.mjs` 算出來寫回去的，重新配音或對齊後要重跑。

## 人耳確認清單

1. 語速有沒有比 love-stats-Sulafat 試聽檔快、夠不夠快。
2. 聽起來像不像真人在聊天，還是仍然像機器人。
3. 口音：ㄓㄔㄕ 的字（這種、傳、數字、調查、只剩、單身、只有）捲不捲。
4. s03「國科會的萬人調查發現」、s04「沒結婚的裡面」有沒有吞字或念錯（對齊信心最低的地方）。
5. 開頭有沒有把設定說明念出來（開口在 0.18 秒，應該沒有）。
6. 訊息提示音會不會太吵、背景音會不會蓋到人聲。
7. 訊息跳出來的時間點和念到的詞有沒有對上。
