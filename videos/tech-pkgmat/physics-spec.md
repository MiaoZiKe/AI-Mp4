# tech-pkgmat physics-spec：封裝材料（給 3D 動畫師）
來源見 research.md（#編號）。可標數字：封裝膠填料約七到九成（#12，念「大約八成」，畫面標「依配方而異」）、錫球直徑零點幾毫米（#23）、模溫約 175 度（#15，畫面小字，不念）。其餘示意不標數。
敘事＝一顆晶片從「光著」到「穿好衣服、長好腳、焊在板子」：導線架（沖壓／蝕刻）→ 轉移成型灌膠 → 硬化外殼（爆炸分解）→ 植錫球 → 焊到電路板 → 熱脹冷縮扯裂 → 底部填充 → 公司 → 下一集覆晶。

## 2. 爆炸分解（逐步一次一件標籤）
1. 封好的封裝：黑色膠體往上拿開（標「封裝膠外殼」）。
2. 金線與晶片一起往上分開（標「晶片＋金線」）。
3. 黏晶膠層、晶片座、引腳留在導線架（標「導線架」）。
4. 組回，膠體落回。

## 3. 運作動畫物理（第 15 條）
- 沖壓：上滑塊加速落下、撞擊瞬間下模微震、回程減速；銅帶間歇前進（每沖一次送一格）。
- 蝕刻：噴嘴往下噴藥水（受重力加速的小滴），銅片沒被光阻蓋到的地方逐格消失。
- 轉移成型：料餅在料筒加熱（發紅），柱塞往上推（等速偏慢）、膠沿流道前進、從澆口進模穴，前緣逐格往前填滿；金線被流動推得微微擺動（沖線，示意）；填滿後保壓、模具持續發熱＝熱固化（越熱越硬，膠色由深褐變黑）。
- 擋濕氣：水滴受重力落在外殼，彈開或滑落，不滲入。碰撞：小石子落下彈開。
- 植球：助焊劑點先出現，錫球一顆顆落下（重力、落地小彈）、回焊時發亮變圓。
- 熱脹冷縮：電路板受熱往兩側伸長得比封裝多（相對位移），錫點被剪成平行四邊形來回擺，次數多了頂端出現裂縫（紅）。
- 底部填充：針沿封裝邊緣移動點膠，膠靠毛細作用自己從邊緣往縫內前進（逐格，越往內越慢），填滿後加熱硬化；再熱循環時錫點只微擺、不裂。
- 覆晶預告：晶片翻面 180 度（加減速），落到基板。

## 4. 2D 卡
1. 開場：光著的晶片與金線，問號。2. 導線架構造。3. 沖壓 vs 蝕刻。4. 料餅成分（約八成細砂，依配方而異）。5. 轉移成型步驟（布丁 vs 越熱越硬）。6. 外殼功能（濕氣、碰撞、絕緣；不寫散熱）。7. 四周排腳 vs 底部錫球（零點幾毫米）。8. 熱脹冷縮剪切。9. 毛細作用（茶滲進兩片玻璃）。10. 公司（長華電材 8070／長華科技 6548、界霖 5285、住友電木）。11. 下一集覆晶。

## 5. 常見錯誤提醒
- 封裝膠是黑色不透明（畫內部時用剖面或爆炸，標「剖開示意」）。
- 封裝膠不寫「散熱」（#18）。
- 底部填充是毛細作用吸進去，不是壓進去；說「分散應力」，不說「保證不裂」（#33）。
- 錫球在封裝底面，晶片本身在 BGA 裡仍可能是打線的；「倒扣」是下一集覆晶，不要把 BGA 畫成晶片倒扣。
