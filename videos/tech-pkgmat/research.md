## 四、比喻清單（給審片人）
| 比喻 | 放哪 | 物理是否誤導 |
|---|---|---|
| 餅乾模壓出來的金屬骨架（導線架） | 導線架幕 | 對「沖壓」不誤導；但蝕刻是藥水咬出來，不是壓，畫面若講兩種做法要分開：沖壓＝餅乾模，蝕刻＝「用藥水把不要的地方吃掉」（像版畫腐蝕） |
| 灌模做布丁（轉移成型） | 封裝膠幕 | 「把液體擠進模子、成形後脫模」不誤導；**但布丁是冷卻凝固，EMC 是加熱（約 175 °C）硬化**，口白要補「加熱反而變硬」，或改「烤蛋糕定型」 |
| 把晶片封進琥珀 | 封裝膠幕 | **誤導**：琥珀透明、天然慢慢形成；EMC 是黑色不透明、幾十秒到兩分鐘在模具裡硬化。只能取「封起來保護」，不建議用 |
| 一排小焊錫珠當腳（錫球） | 錫球幕 | 不誤導；補「整個底面都排滿」才講得出比四周排腳多 |
| 磁磚填縫劑（底部填充） | underfill 幕 | 部分誤導：填縫劑是用刮刀壓進去；underfill 是沿邊點膠、靠**毛細作用自己吸進去**。建議改「水沿著紙巾往上吸」或「茶滲進兩片玻璃中間的縫」，再接「乾了把上下黏成一塊」 |
| 牙齒補洞 | underfill 幕 | 誤導：補牙是填一個洞、修補損壞；underfill 是預先填縫、分散應力，不建議 |
| 鐵軌留縫（熱脹冷縮） | 為什麼要 underfill | 用來講「東西受熱會變長」不誤導；**但解法相反**：鐵軌是留縫讓它自由伸縮，underfill 是把縫填滿、黏在一起分攤應力。若用，口白要講「這裡不能留縫，所以反過來把它黏死」；更貼切的是「兩種膨脹不同的材料黏在一起會彎（雙金屬片）」 |
| 膠流進去把金線沖歪（wire sweep） | 封裝膠幕 | 用「水流沖倒細草」不誤導，接上一集金線 |

## 七、沒問到、但撞到的
1. **委託的公司代號有誤**：「長華科技（8070）」應是「長華電材（8070，長華*）」；「長科（6548）」就是長華科技，不是順德；順德工業是 2351。母子關係＝長華電材（母）→ 長華科技（子），兩家都是長華集團。片中若出公司 LOGO 與名牌（tech-andy-fixes 規則），名稱要照這裡。
2. **「封裝膠散熱」是常見誤解**：一般 EMC 導熱很差（約 0.3～1 W/mK），散熱主要靠晶片座／導線架；功能列「防濕氣、防撞、絕緣」，散熱不列或改「高導熱配方另外做」。
3. **板級 underfill 有反例**：材料沒配好，熱循環壽命可能變差（#33），念稿說「分散應力」，不說「保證不裂」。
4. **銅夾片（Copper Clip）導線架**是 AI 伺服器電源的新應用（界霖），可當結尾「導線架沒有過時」的一句，屬媒體報導。
5. **MUF（molded underfill）**：把模封與底部填充一次做完（Resonac、Panasonic 有產品），可留給 3-4 覆晶或之後的先進封裝集。
6. 口袋學堂文章把界霖寫成 6534，是 AI 摘要式文章，**不要當來源引用**。
