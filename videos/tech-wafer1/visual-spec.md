## 二、運作動畫與旁白同步（≥3 段）＋流動物物理形狀（lessons 54）
1. s2 電弧爐：砂沿輸送帶與溜槽滾進爐（grit 小方塊、砂色）→ 念「跟碳一起燒」三支電極下端電弧閃爍（7 Hz＋光暈）→ 念「燒掉氧」一氧化碳分子（2–3 球分子形）往上進排煙罩 → 念「冶金級矽」熔融矽從出料口流進盛桶（連續液帶＋液滴、橘色）。2D 卡 si-mg 同步。
2. s4 西門子法：念「變成氣體」氣體沿管線（液帶）→ 念「蒸餾」塔內分子往上升（分子形）、再沿管線送進鐘罩 → 念「長回棒子上」矽棒發亮、綠色分子撞上棒面，矽棒一層一層變粗（3 層外殼依序出現）。2D 卡 si-siem 同步（棒剖面一圈圈長大）。
3. s5 熔化：念「石英坩堝」多晶矽塊受重力落進坩堝（落下加速＋回彈）→ 念「加熱」石墨加熱器發橘、塊料發紅 → 念「熔掉」熔湯出現、塊料淡出，液面往上冒熱波。2D 卡 si-melt 溫度 25→1420°C。
4. s6 拉晶（主角）：念「晶種浸下去」晶種下降碰到液面、交界亮環出現 → 念「慢轉」晶棒與坩堝反方向轉（看得到晶稜在轉）→ 念「往上拉」整根從熔湯裡慢慢長出來（晶頸→肩部→晶身）；氬氣光點沿晶棒往下吹、掠過液面從坩堝外側排出。2D 卡 si-cz：剖面同一份時間＋右邊原子一排排從熔湯飛上來照晶種排好。
5. s7–s8 切片拋光：晶棒往下壓進線網，線上的鑽石顆粒沿線跑、冷卻液滴下 → 切完整排抬起、一片片分開 → 拋光盤與載具頭反向轉、研磨液滴下 → 念「拋光成鏡面」載具頭抬起，晶圓換成鏡面並反光。2D 卡 si-saw、si-pol（表面起伏變平、光線整齊反射）。
6. s3 晶格：電子（小藍點拖尾）沿晶格流、在雜質附近被撞偏；念「雜質」紅色原子閃。
