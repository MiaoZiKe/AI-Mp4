# short-stock 分鏡

風格：紙拼貼「貼紙式」，`styleVersion: 3`、`skin: newsprint`（軟木板＋報紙色紙、黑白照片），頂層 `sample: true`（10–15 秒試片，不放片尾卡）。鏡頭固定在 [540, 960, 1]，換鏡靠紙片滑走／新紙片蓋上，不用淡入淡出。秒數是無聲估算，有配音後以 timeline.json 為準；所有動作都掛在 cue 上。

## 規則對照

- 同屏主要紙片 ≤3（膠帶、箭頭、問號不算）。
- 每 2–4 秒都有事件：s01 0 幀完整、約 1 秒畫底、約 2.5 秒 punch；s02 約 3.4、4.2、4.9 秒；s03 約 6、7.3 秒；s04 約 9、9.6、10.4 秒；s05 約 12、12.8 秒。
- 手機最小字：畫面字最小 34px（照片圖說、收盤價），≥28px。
- 安全區：所有紙片中心在 x 290–860、y 440–1100；字幕紙條 1300–1532、出處 1601 起。還沒跑 still，要截圖確認 s01 數字卡和照片、s04 圖表有沒有超出左右 64px。
- 照片：`produce`（Pexels 701970，裁掉右上角攤販）、`dollars`（Pexels 164527，沒有人臉），來源見 `assets.md`。
