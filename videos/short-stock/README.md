# short-stock（哩股哩股 15 秒短片，無聲版）

題目：美國 10 月通膨超乎預期，台幣為什麼跟著動？

## 成片

- `out/short-stock.mp4`：15.0 秒、449 幀、1080×1920、30fps、H.264。**沒有配音**（音軌是靜音）。
- 字幕檔：`out/short-stock.srt`（中英）、`.zh.srt`、`.en.srt`。
- 截圖：`out/short-stock/stills/`、總覽 `out/short-stock-overview.png`、九格圖 `out/short-stock-review.png`、封面 `out/short-stock-cover.png`。
- 2026/11/14 20:35（台灣時間）出片。

## 為什麼是無聲版

使用者決定哩股哩股改用他自己在 Google AI Studio 生成的聲音，音色與提示詞還沒提供。`script.json` 的 `voice.voiceName` 寫 `"TBD-user-voice"`，這支片沒有送過任何 TTS 請求。時間軸是估算的（每秒 5 個音節、幕間停 0.3 秒），由 `SILENT_RATE=5 node scripts/ui/silent-timeline.mjs short-stock` 產生。

拿到聲音之後：把音檔照 `tts-take` 的流程對齊（`npm run align short-stock`）會整份覆蓋 `timeline.json`，畫面的動作全部掛在 cue id 上，會自動對到真的聲音，再 `npm run still` → `npm run render` 即可。

## 風格

紙拼貼「貼紙式」：`styleVersion: 3`、`skin: newsprint`（軟木板、報紙色紙、黑白照片），頂層 `sample: true`，沒有片尾卡。鏡頭固定，只有 s01 念到「0.4%」推近一次；換鏡靠紙片滑走和砸下。沒有新建元件，也沒有動共用程式。

## 做法與時間

- `npm run validate short-stock`：0 error、2 個 warning（見已知問題 3）。
- `npm run still short-stock`：約 1 分鐘；覆蓋率最低 71%、中位 80%，沒有空白帶。
- `npm run render short-stock`：約 40 秒（每幀約 76 毫秒）。
- ffprobe：h264、1080×1920、30fps、449 幀；ffmpeg blackdetect 沒有黑幀。
- 自查：前 3 秒每 2 幀、之後每 0.25 秒抽格看過，改了五處（紀錄在 `storyboard.md` 最後一段）。
- `npx tsc --noEmit` 通過。

## 已知問題

1. 沒有配音，節奏是估算的。真的聲音進來後每幕長度會變，要重看 s02 的「再升息？」和 s04 的「約 12–15%」停留夠不夠久。
2. 數字都來自搜尋摘要，沒有逐字讀過原文（這個環境連不到中央社、工商時報、Kalshi 等網站）。上片前要開原文核對，清單在 `research.md`。
3. validate 警告 s04 同屏 5 樣、s05 同屏 6 樣主要元素（規則是 3 樣以內）。原因是把一張圖表拆成白紙、兩條橫條、一張貼紙來分別對 cue，看起來是一張圖；s05 的 6 樣是圖表退場前和新紙條重疊的約 1 秒。
4. s05 大紙條砸下的前 1 秒會蓋住圖表左上角的「分析預期」貼紙和圖表上緣。
5. s01 開頭約 1 秒畫面不動（第 0 幀已是完整主張，念到「超乎預期」才畫底）。
6. 出處紙條和頁首右上標籤的字約 24px，低於 28px；這是 v3 引擎共用的尺寸，這次沒有改共用檔。
7. 橫條長度用 87 和 12 當示意，標的是範圍「約 85–90%／約 12–15%」。
8. 兩張 Pexels 照片的授權頁沒有逐張核對；菜市場照片上有手寫德文價格牌。
9. 沒有跑 `selfcheck` 和 `audit`（沒有 `review.md`，`scripts/v3/review-sheet.py` 跑不了，九格圖改用 ffmpeg 直接抽格拼成）。
