# short-stock（哩股哩股 15 秒短片，無聲版）

題目：美國 10 月通膨超乎預期，台幣為什麼跟著動？

## 成片

- `out/short-stock.mp4`：15.0 秒、449 幀、1080×1920、30fps、H.264。**沒有配音**（音軌是靜音）。
- 字幕檔：`out/short-stock.srt`（中英）、`.zh.srt`、`.en.srt`。
- 截圖：`out/short-stock/stills/`、總覽 `out/short-stock-overview.png`、九格圖 `out/short-stock-review.png`、封面 `out/short-stock-cover.png`。
- 2026/11/14 20:50（台灣時間）出片（評審後修正版）。

## 為什麼是無聲版

哩股哩股的男聲音色還沒定：使用者 2026/11/14 聽過後否決了 Iapetus 與 Achird，要在 Google AI Studio 試聽後再選（候選與提示詞在 `docs/prompts/liguligu-男聲試聽.txt`）。`script.json` 的 `voice.voiceName` 寫 `"TBD-user-voice"`，這支片沒有送過任何 TTS 請求。時間軸是估算的（每秒 5 個音節、幕間停 0.3 秒），由 `SILENT_RATE=5 node scripts/ui/silent-timeline.mjs short-stock` 產生。

拿到聲音之後：把音檔照 `tts-take` 的流程對齊（`npm run align short-stock`）會整份覆蓋 `timeline.json`，畫面的動作全部掛在 cue id 上，會自動對到真的聲音，再 `npm run still` → `npm run render` 即可。

1. 沒有配音，節奏是估算的。真的聲音進來後每幕長度會變，要重看 s02 的「再升息？」和 s04 的「約 12–15%」停留夠不夠久。
2. 數字都來自搜尋摘要，沒有逐字讀過原文。上片前要開原文核對，清單在 `research.md`。
3. s01 數字卡砸下時會從 +0.0% 跳到 +0.4%（約 0.3 秒），第 14–20 幀暫停看會看到 0.0、0.3 這些中間值。
4. s02 第 102–126 幀（約 0.8 秒）畫面只有一張標籤。
5. 出處紙條和頁首右上標籤的字約 24px。
6. 橫條長度用 87 和 12 當示意，標的是範圍「約 85–90%／約 12–15%」。
7. 兩張 Pexels 照片的授權頁沒有逐張核對；花椰菜照片裁切後下緣有點失焦。

9. `script.json` 的 `voice.profile` 還是舊的（`preset: stock`、`delivery: chat`）。CLAUDE.md 現在規定哩股哩股用 `liguligu` 預設檔（`delivery: "probe"`）、男聲音色待使用者選定；配音前要改設定檔，稿子也要照追問式結構重看。
