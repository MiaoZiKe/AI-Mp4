# 評分規則（跑實測前先寫好，2026/11/17）
文件：handout.pdf（4 頁，虛構，自製）。問題含一項文件根本沒寫的事（館內影印）。
1. 拆句：回答裡一個「。」「！」「？」結尾的句子、或一個條列項目＝一句。只算「有陳述事實、數字、規則、功能」的句子；標題、問候、純轉折（例如「以下整理」）不計。
2. 「有出處」＝這句講的每一個數字與規則，都能在文件原文找到相同內容。
3. 「找不到出處」＝這句含至少一個具體說法（數字、規則、功能、價格），文件沒寫；「通常」「一般圖書館」這類推測也算。
4. 回答「文件沒寫」那一句算有出處（它沒有編）。
5. 限制版另外檢查：句後標的頁碼對不對（標的那一頁真的有那句話的內容）。
6. 每個版本問兩次，以第一次為主數字，第二次當穩定度參考。
