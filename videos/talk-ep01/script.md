# talk-ep01 旁白（290 字；無聲版 66.7 秒）

結構：一句讓人停下來的話 → 這是什麼數字 → 為什麼降不下來 → 這個數字不能怎麼讀 → 晴 → 提問 → 下一集 → 片尾卡。空一行＝換段（送配音時也照這樣分段）。

一年工作兩千零二十七小時。下班的時候，天早就黑了。

這是勞動部算的，二零二五年的年總工時。換成一天八小時，是兩百五十三個工作天。二零一四年更長，兩千一百三十五小時。後來一路降，疫情那年不到兩千。之後又回升。去年假變多，全年只少了三點六小時。

為什麼降不下來？我們幾乎都是全職。兼職只有百分之三到四，日本大約四個有一個。再來是加班。去年正常工時變少，加班卻變多。還有下班以後。四個人有一個，收過交辦工作的訊息。

只是這個數字要小心讀。全職和兼職，是一起平均的。所以不能說，我們比日本人多上將近四百小時的班。只看全職，台灣一週四十一點五小時，比日本還少。

不過有些傍晚，走出公司，天還亮著。我們多走一站，買一份熱的晚餐。

你上一次天還亮著下班，是什麼時候？

下一集，我們看房租。

## 對照頻道規則

- 主詞是「我們」；「你」只出現在提問。沒有禁用語（validate 0 error、0 warning）。
- 原因只講有數字的三件事，不怪個人、不怪哪個群體，也沒有採用學者或勞團任何一方的解釋。
- 口徑提醒佔三句（第 11–13 鏡），而且兩邊都說：不能說多上四百小時；只看全職比日本少。
- 晴是兩個看得到的畫面（天還亮著、一份熱的晚餐），用「不過」接，沒有寫成道理；佔 18 鏡裡的 2 鏡。
