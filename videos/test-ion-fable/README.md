## 自己看出的缺點
1. 字幕框那一帶（y1452–1700）是空的。規定無字幕，沒有放別的東西；正片接上字幕後才會填滿。
2. 最後一段終端站頂端（掃描驅動、燈塔）被頁首讀數帶的字壓到；晶圓在畫面上偏小，右前方的腔體邊框也切過晶圓。
3. 開場全景的機台只佔畫面中段，下方地板偏空。
4. 剖面卡的摻雜區是一條條色帶疊出來的漸層，細看有階梯；卡片上除了「摻雜區」沒有其他文字（引擎沒有 3D 文字）。
5. 磁鐵是六段折線拼的扇形，邊緣看得出折角；上半抬起後直接淡掉，沒有留殘影。
6. 離子的「＋」是貼在球面外的小平板，鏡頭角度偏離太多時會看得出是浮著的。
7. 沒有開陰影（這台機器太慢），只有機櫃底下的假陰影；零件 910 個，每幀約 2 秒。
8. `validate` 有 1 個 error（第一幕沒有 hook 大標），是照「無字幕」規定刻意不放。
9. 整支畫面只抽格看過，沒有逐幀看動態；重疊檢查沒有跑程式逐幀版。
