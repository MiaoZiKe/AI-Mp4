# sample-tech-3d 旁白稿（科技風格試片：3D 產品台）

題目：手機裡可能藏著一點水？拆開看均熱板。旁白 66 字，目標 12–15 秒。音色 Sulafat，語速目標 4.6–5.0 音節/秒。

| 幕 | 旁白 | 畫面（念到哪個詞、發生什麼事） |
|---|---|---|
| s1 鉤子 | 你的手機裡，可能藏著一點水。 | 第 0 幀就有大標「手機裡有水？」；3D 手機在轉盤上轉。念到「一點水」→ 一顆水滴圖示落在手機旁 |
| s2 | 拆開來看，晶片上面蓋著一片金屬板， | 念到「拆開」→ 手機轉成斜側面，沿厚度方向一層層分開（背蓋、電池與主機板、金屬板、中框、螢幕）。「晶片」→ 晶片亮起、貼標籤。「金屬板」→ 金屬板亮起、貼標籤 |
| s3 | 叫均熱板，裡面封著一點純水。 | 「均熱板」→ 其他層退開變淡，鏡頭推近那片板子，標籤改成「均熱板 Vapor Chamber」。「純水」→ 板子上蓋掀開，看到裡面的水滴，貼「純水」 |
| s4 | 晶片一燙，水變成蒸氣，把熱帶到整片板子； | 「燙」→ 晶片位置變紅發熱。「蒸氣」→ 水滴變成往上飄的蒸氣粒子。「整片」→ 蒸氣散開到整片板子，板子顏色由紅擴散 |
| s5 | 涼了變回水，再流回來。 | 「涼了」→ 遠端的蒸氣變回藍色水滴。「流回來」→ 水滴沿板子流回晶片，出現循環箭頭與「一直循環」 |

沒有片尾卡（風格試片）。事實出處見 research.md。
