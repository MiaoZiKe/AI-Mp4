# sample-tech-3d — 科技頻道風格試片：3D 產品台

這是 10–15 秒的**風格試片**，不是完整影片（沒有片尾卡，也沒有完整的起承轉合），用來和其他三種風格一起挑。

- 成片：`out/sample-tech-3d.mp4`（1080×1920、30fps、H.264，14.7 秒、441 幀；目前是第三版）
- 人聲：`out/sample-tech-3d/voice-final.wav`
- 題目：手機裡可能藏著一點水？拆開看均熱板
- 旁白（65 字）：你的手機裡，可能藏著一點水。拆開來看，晶片上面蓋著一片金屬板，叫均熱板，裡面封著一點純水。晶片一燙，水變成蒸氣，把熱帶到整片板子；涼了變回水，再流回來。

## 細緻度與特效升級（2026/11/13，第三版）

使用者看完第二版說：「架構介紹方式很棒，美中不足就是在產品上細緻度要加強，並且多點特效試試」。這一版只改畫面，**配音與時間軸完全沿用**（沒有送任何 TTS 請求）；沒有再請評審重評。

**產品細緻度**（手機現在是 `model.json` 裡的 65 個零件，複製品算進去約 150 個形狀）：
- 外殼：背蓋、鏡頭島、中框都有倒角；螢幕拆成膠圈＋玻璃＋畫面三件；中框上有電源鍵、音量鍵、側鍵、四個天線斷點、充電孔、喇叭孔（下方 8 個）、上方收音孔。
- 鏡頭模組：金屬外圈、鏡筒、光圈環、壓扁的鏡片（會反光）、閃光燈與燈圈、收音孔。直排兩顆，不對應任何機型，沒有商標。
- 內部：主機板與副板（有線路紋理）、主晶片與金屬蓋、記憶體、電源晶片、數據晶片、兩個屏蔽罩、17 顆電容、兩個排線接頭、兩個鏡頭模組背面、前鏡頭、7 顆螺絲（有一字槽）、電池（標籤、拉帶、接頭）、側邊長排線、喇叭、充電座、震動馬達。
- 均熱板：底板（毛細網紋理）、兩側回流用的毛細條、32 根支撐柱、外框、上蓋（髮絲紋、有一圈壓紋）、注水口。
- 材質分四類：金屬（中框、屏蔽罩、螺絲：帶底色的環境反光）、玻璃／烤漆（背蓋、鏡片、螢幕玻璃：銳利高光＋白色反光）、塑膠（天線斷點、膠圈）、銅（均熱板）。反光來自一張程式畫的攝影棚環境貼圖。

**沒做的**：環境光遮蔽（SSAO）沒有量也沒有做；地面鏡面反射沒做（立著時手機底部緊貼字幕卡，沒有位置放倒影）。

**資料驅動**：手機的定義搬到 `videos/sample-tech-3d/model.json`（色票、材質、層、零件、標註點、熱循環範圍），`src/components/three/` 裡不再有手機的尺寸或顏色。格式與可用的形狀／材質／特效／鏡頭動作見 `docs/three-stage.md`。換產品＝寫一份新的 model.json。

## 風格說明

畫面中間是一個真的 3D 舞台（淺灰攝影棚），放一支用基本形狀自己建的示意手機：
先立著轉一圈 → 躺下、沿厚度方向一層層分開（背蓋｜電池與主機板｜金屬板｜中框｜螢幕）→ 零件貼標籤（圓點釘在零件上、引線接到標籤，會跟著模型走）→ 鏡頭推近均熱板、掀開上蓋 → 水滴變蒸氣散到整片板子、板子變熱 → 變回水滴流回熱點。
外面一圈（大標、標籤、頁首、字幕卡、出處）是一般的 HTML。和紙拼貼的差別：沒有紙材與桌面；主角是可以轉、可以拆的立體模型，配色是淺灰棚＋深藍機身＋銅色金屬板。

第三版做得到的是「乾淨但精緻」的 3D：倒角、分件、金屬與玻璃的環境反光、柔和的地面陰影。**還是做不到**真的玻璃折射、零件互相投影的陰影、物理材質那種發表會質感：這台機器沒有顯示卡，那些效果量過，一幀要多 1.6–24 秒。

## 怎麼做的

- `script.json` 頂層 `styleVersion: 3` 加 `stage: "three"`。任務說「新開 styleVersion 4」，實際上為了沿用 v3 的整篇配音、對齊、字幕檔、混音流程（那些程式都認 `styleVersion: 3`），我用的是 `stage` 這個開關，和另外兩支試片（`ui`、`chat`）同一種做法；文件裡把它叫「v4 產品台」。要不要真的改成數字 4，請你決定。
- 每幕 `component: "ThreeScene"`，props 寫這一幕發生什麼事：`spin`（轉盤）、`drop`（水滴圖示）、`explode`（分解）、`labels`（貼標籤：`part`、`text`、`color`、`at`）、`focus`（聚焦均熱板）、`rename`（標籤改名）、`peek`（上蓋微抬）、`cutaway`（掀蓋）、`orbit`／`settle`（後段兩次鏡頭變化）、`heat`／`vapor`／`spread`／`condense`／`flowBack`。每個 `at` 只寫 cue id 或 `start｜voice｜end｜exit` 加減幾幀，沒有手填秒數。
- 檔案：`videos/sample-tech-3d/model.json`（手機的零件資料）、`src/components/three/model.ts`（資料 → 幾何、材質、程式紋理、環境貼圖）、`engine.ts`（把 cue 換成絕對幀；算每一幀的姿態、層距、鏡頭、熱度、粒子；標籤投影）、`Scene.tsx`（3D 畫面，@remotion/three）、`ThreeVideo.tsx`（背景、殘影與導引線、光斑、大標、標籤、封面）、`Tracks.tsx`（頁首、字幕卡、出處）；`src/theme.ts` 的 `THEME_3D`／`LAYOUT_3D`（顏色、燈光、鏡頭、動作，元件不寫死色碼）；`scripts/three/validate-three.mjs`（檢查）、`scripts/three/bench30.mjs`（先渲 30 幀量速度）、`scripts/three/bench-fx.mjs`（逐項量特效成本）。
- 全專案只有 `src/components/three/` 可以用 three.js（validate 規則 8 改成只放行這個資料夾）。
- 指令順序：`npm run validate sample-tech-3d` → `node scripts/tts-take.mjs sample-tech-3d` → `npm run align sample-tech-3d` → `node scripts/v3/peek.mjs sample-tech-3d <圖檔> <幀,…>` 看畫面 → `npm run still sample-tech-3d` → `node scripts/three/bench30.mjs sample-tech-3d` → `THREE_CONCURRENCY=3 npm run render sample-tech-3d`。
- `stage: "three"` 時 `scripts/lib.mjs` 自動把 Chrome 的 gl 從 swiftshader 換成 swangle（swiftshader 開不出 WebGL），平行數預設 1，可用環境變數 `THREE_CONCURRENCY` 調。

## 已知問題

- 查證只看了搜尋結果摘要，沒有打開原文（Apple 新聞稿、DNP 技術頁；兩個網域這個環境連不上）。畫面已不掛這兩個來源。詳見 `research.md`。
- 模型是示意的：層次順序、均熱板大小與位置不對應任何實際機型；水滴與蒸氣粒子是誇大的示意（實際水量很少、吸在毛細結構裡看不到水珠）。第 2–5 幕的出處列都標了示意。
- 金屬板畫成銅色。旁白只說「金屬板」（查到的資料是銅、鋁、鈦都有）；出處列已註明銅色是示意。
- 地面陰影是「每一層的外形沿燈光方向壓到地面」的模糊貼圖，不是陰影貼圖：零件之間不會互相投影，立著時腳下的陰影偏重。
- 反光是近似的（Phong＋一張環境貼圖），沒有菲涅耳、沒有折射；鏡片與螢幕玻璃看起來是亮面，不是透明的。
- 內部零件的種類與位置是示意的，不對應任何實際機型的主機板。
- 熱循環那一組特效（掀蓋、水滴、蒸氣、熱擴散）是引擎裡的一個固定模組，靠 model.json 的 `thermal` 設定範圍；其他產品要別種「主角特效」得再寫。
- 第 3 幕一開始（念「叫均熱板」的前半秒）上一幕的「晶片」「金屬板」標籤還在退場。
- 安全區上方 0–220px 與下方 1700–1920px 只有背景，沒有內容。
- 沒有跑 audit 與 selfcheck（那些門檻是給完整影片的）。
- 只有一個手機模型。換產品不用改引擎，但要自己寫一份 model.json（手機這份 65 個零件）；或經你同意後用有授權的現成模型。
- 多裝了 `three`、`@react-three/fiber`、`@remotion/three`、`@types/three`（node_modules 多約 35MB；打包所有影片時都會把 three 包進去，其他片的打包時間可能略增，畫面不變）。
