# 畫面規格：ai-make-video（styleVersion 3・桌面紙拼貼・sticky 外觀）

> 與 `script.json`、`timeline.json`、`storyboard.json` 同步（2026/11/13）。時間只有一個來源：配音對齊後的 `timeline.json`；本檔的幀數是從它抄來的，改稿或重配音後要重產。分鏡的設計理由在 `storyboard.md`（配音前的版本）。
> **props 不要直接改 `script.json`**：畫面是 `python3 videos/ai-make-video/props.gen.py` 產生的（只覆寫各幕 props、s19 的 still、頂層 cover；旁白、字幕、cue、配音設定不動）。

## 2. 一鏡到底的做法

整支片是同一面白板。五張便利貼各有一個鏡位，排成一條往下的「之」字，紙虛線把它們串起來，鏡頭沿虛線走。

| 鏡位 | 鏡 | camera.to | 放什麼 |
|---|---|---|---|
| H 開場 | s01–s02、s18–s19 | [540, 960, 1] | 鉤子大紙條（screen 層）、麥克風拍立得、聲波、稿紙 |
| B 五張總覽 | s03、s16–s17 | [540, 2280, 1] | 五張便利貼（s03 只有數字；s16 寫上名字、縮成一排） |
| S1 題目 | s04 | [1580, 2800, 1] | 黃便利貼、筆記本拍立得、三張題目紙條 |
| S2 稿子 | s05–s06 | [2620, 3400, 1] | 薄荷便利貼、紙手機（near 層，畫面座標）、沙漏拍立得、大數字 260 |
| S3 聲音 | s07 | [1580, 4000, 1] | 紅便利貼、牛皮卡「配音工具」、稿紙、聲波 |
| S4 畫面 | s08–s09 | [2620, 4600, 1] | 藍便利貼、長聲波條、三張拍立得 |
| S5 剪接 | s10 | [1580, 5200, 1] | 牛皮便利貼、剪刀拍立得、字幕紙條 |
| T 轉折 | s11–s15 | [2620, 6100, 1] | 深色切割墊（mat 層）上的大紙條、日期紙條、複製紙堆 |

- 相鄰鏡位水平只隔 1040px（一個畫面寬多一點）。移鏡 16 幀，途中舊鏡位靠邊的紙還在畫面裡，新鏡位「只有數字的便利貼」在本鏡第 3 幀就已經貼在板上跟著進畫面，念到「第幾張」才重貼成有名字的那張。這樣移鏡途中畫面不會空掉（樣片關口的 midEmptyFrames、transitionOccupancy）。
- 新鏡位的便利貼放在「鏡頭來的那一側」：往右移的鏡（S2、S4）便利貼在左，往左移的鏡（S3、S5）在右。
- 轉場：沿虛線移鏡（s03–s10）；切割墊蓋上（s10→s11）、掀開（s15→s16）；奶油色大紙從下蓋上（s19→片尾卡）。
- 推近（`punch`）四次：s03「五張」、s06「兩百六十」、s11「不是工具」、s15「不能分潤」。
- 跨鏡沿用的紙片（`id`／`ref`）：鉤子紙條 `hook`（s01→s03 往上撕走）、麥克風拍立得 `mic`（s01 一直留在 H，s19「攤開」前滑走）、日期紙條 `date`（s14→s15 縮到左上）、五張便利貼 `r1`–`r5`（s16→s17 撕走四張、`r1` 放大）。
- 聲波是 `bars` 紙片逐格換圖（每 3 幀一張，直接長好、`from/to: cut`），高度表固定 seed（20261113）。
- 注意：引擎把 `start／voice／end／exit` 當保留字。s01、s18 各有一個 cue 叫 `voice`，`at: "voice"` 會被當成「開口那一幀」，所以產生器遇到這兩個 cue 一律換算成別的錨點（`AT()`）。

## 6. 檢查結果（2026/11/13）

- `npm run validate ai-make-video`：0 error、21 warning。19 條是「同屏 >3 樣」，它是照整場紙片數算的（逐格聲波每一格算一樣、鏡頭外的也算），實際畫面逐張看過；另外兩條是 s14「YouTube 營利政策」11 字（>10）與字數估算 76 秒（實際時間軸 63.6 秒，以實際為準）。
- `npm run still ai-make-video`：通過，覆蓋率佔用率最低 40.4%、中位 62.0%；一條警告（s08 空白帶 352px）。
- `npm run selfcheck ai-make-video -- --sample`（前 15 秒）：確定性、fastMotionRatio、midEmptyFrames、staticRuns、hookDiffs、transitionOccupancy 都過；只有 jumpFrames 不過（第 48、177、180、183、298 幀，都是紙片「貼上」那一幀，是 CLAUDE.md 寫的已知限制）。所以指令的總結果仍顯示「不通過」。
- 全片 render、audit、全片 selfcheck、評審評分都還沒做。
