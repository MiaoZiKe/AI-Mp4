- 我不能聽音檔。下面的數字只能說明快慢、起伏、字有沒有念到；口音、語氣、音色好不好聽要用耳朵確認，清單在最後。

### 提示（全文）

```
用台灣人平常講話的口音，語氣沉穩認真一點，語速比平常稍快，咬字清楚說：
（念稿版全文，四段，段與段之間空一行）
```

`script.json` 的 `voice.style` 只放前面那一句，程式自動接「說：」。四支樣片用同一句提示。提示沒有被念出來：聽寫開頭直接是「你現在聽到的聲音」，原始錄音 0.16 秒開口。

### 和 what-is-server 對照

量法和 what-is-server 的 voice.md 相同：語速＝音節數 ÷ 去頭尾靜音後的說話長度（`scripts/voice-measure.py`；國字一字一音節，A I 算 2、YouTube 算 2，共 283 音節）；音高起伏＝自相關法估 F0 的 5–95 百分位半音數。

| | what-is-server | ai-make-video |
|---|---|---|
| 提示 | 像跟朋友聊天、自然平穩 | 沉穩認真一點、稍快、咬字清楚 |
| 原始錄音長度 | 61.61 秒 | 60.97 秒 |
| 音節數 | 271 | 283 |
| **語速（音節/秒）** | 4.42 | **4.66**（快約 5%，落在目標 4.6–5.0 的下緣） |
| 扣掉停頓的語速（音節/秒） | 5.73 | 5.61 |
| 停頓（≥0.15 秒）次數／總長／中位數 | 35 次／13.96 秒／0.41 秒 | 27 次／10.29 秒／0.35 秒 |
| 音高中位數 | 122 Hz | 118 Hz |
| 音高起伏（5–95 百分位，全部音框） | 12.3 半音 | 29.1 半音（**不可信**，見下） |
| 音高起伏（只算 80–200 Hz 的音框） | 11.7 半音 | 12.8 半音 |
| 響度範圍 LRA | 4.3 LU | 3.9 LU |
| 整篇 FA 信心 | 0.917 | 0.868 |

怎麼讀這張表：

- **「稍快」有做到，但快的來源是停頓變短、變少**，不是字念得比較快：扣掉停頓後每秒 5.61 音節，和上一支的 5.73 差不多。整體聽起來會比較緊湊。
- **音高起伏的 29.1 半音是量測失準，不是真的起伏很大。** 這份錄音有 13.7% 的音框被估到 200 Hz 以上（其中 5% 撞到量測上限 400 Hz）、12.9% 被估到 80 Hz 以下，what-is-server 分別只有 0.6% 和 1.8%。只算 80–200 Hz 的音框是 12.8 半音，和上一支的 11.7 相近；響度範圍也沒有變大（3.9 對 4.3 LU）。所以比較可信的說法是「起伏和上一支差不多」，但這是推估。
- **這份錄音的音色和另外幾支明顯不同，偏低沉、高頻少**：能量集中在 300 Hz 以下，1–3 kHz 比 what-is-server 低約 6 dB、6–12 kHz 低約 8 dB（頻譜重心 350 Hz，what-is-server 869 Hz，另外三支樣片 756–1226 Hz），底噪也高一些（−53 dB 對 −65 dB）。沒有爆音（沒有連續削波）。提示裡的「沉穩」可能讓它壓低聲音、帶一點氣泡音，這也是音高量不準的原因。**聽起來會不會悶、和其他三支放在一起會不會像不同人，要用耳朵判斷。**

## 聽寫比對（整篇，全文在 `tts-take-asr.json`）

沒有漏句、沒有多句、沒有念出提示。和念稿不同的地方有三處（簡體字、阿拉伯數字、標點不算）：

| 位置 | 念稿 | 聽寫寫成 | 對齊信心 | 判讀 |
|---|---|---|---|---|
| s06，約 17.3–17.7 秒 | 我們**實測** | 我们**测试** | 「實」0.889、「測」0 | 「測」很可能沒念清楚，或念成別的字。**一定要聽** |
| s10，約 31.0–31.5 秒 | 最後一張是**剪接** | 最后一张是**剪辑** | 兩字都正常 | 比較像聽寫模型自己換成常用詞，但要聽一下 |
| s12，約 39.5–40.5 秒 | 講得跟**真的一樣**順 | 讲得跟**真的的一样**顺 | 「一」0.037 | 可能多了一個音或有點結巴，要聽 |

依這次的規則，只有漏句、念出提示、或整篇信心 < 0.6 才可以再送一次，三項都沒發生，所以沒有重送。如果人耳聽了「實測」確定念錯，要整篇重來（1 次請求），念稿可以把「我們實測」改成「我們自己量過」之類不容易吞字的說法。
