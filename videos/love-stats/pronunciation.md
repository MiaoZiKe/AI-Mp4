# pronunciation.md — love-stats 念稿規則

念稿版只改送配音的 `tts`，字幕維持原文。念稿全文在 `script.md`「念稿版」，逐鏡的 `tts` 在 `script.json`。**還沒配音，下面的「要求」都還沒有量測結果。**

## 送出去的格式

- 整篇一次送出（`voice.mode: "take"`，`scripts/tts-take.mjs`）。四段（每鏡的 `para` 1–4），同一段的鏡接成同一行，段與段之間空一行。
- 提示＝`voice.style`＋「說：」＋換行＋念稿。`voice.style` 現在是空的，要配音前填。
- 提示句建議（使用者要「稍微快一點、稍微嚴肅一點」；還沒試聽，沒有定案）：
  - 候選 A：`用台灣人平常講話的口音，語速稍快，語氣平穩、認真`
  - 候選 B：`用台灣人平常講話的口音，像在跟朋友講一件正經事，語速稍快，不誇張`
  - 不要寫場景、動作、引號或像台詞的句子（what-is-server 試過，會被念出來）。

## 字幕和念稿不一樣的地方

| 字幕／旁白 | 念稿 | 鏡 | 理由 |
|---|---|---|---|
| 但最該注意的，其實還不是這個數字。 | 但最該注意的其實還不是這個數字。 | s02 | 拿掉逗號，不做戲劇性的頓 |
| 那是不是代表，大家都不想結婚了呢？ | 那是不是代表大家都不想結婚了呢？ | s09 | 同上；句後已有 0.35 秒停頓 |
| 結了婚之後，是另一組數字， | 結了婚之後是另一組數字， | s19 | 收尾不拖 |

其他鏡的念稿和旁白逐字相同。數字在旁白裡就是國字唸法，全片沒有阿拉伯數字、百分比符號、英文。

## 配音後要人耳確認的字

| 詞 | 鏡 | 要求 | 念錯時怎麼改（只改 `tts`） |
|---|---|---|---|
| 結婚對數 | s04 | 對數＝ㄉㄨㄟˋ ㄕㄨˋ，不要念成數學的「對數」腔或把「數」念成 ㄕㄨˇ | 改「結婚的對數」或「結婚數」 |
| 占多少 | s06 | 占＝ㄓㄢˋ | 改「佔多少」 |
| 四成 | s08 | 成＝ㄔㄥˊ，只有六個字的短鏡，不能含糊 | 改「超過百分之四十」 |
| 一萬名 | s11 | 「一」變調念 ㄧˊ | 改「上萬名」（意思稍有不同，先聽再決定） |
| 三分之二 | s13 | 四個字都清楚、不吞「之」 | 前面加逗號「大約，三分之二」 |
| 不要／不是不要 | s14、s15 | 「不」在四聲前變調 ㄅㄨˊ，連講兩次不要糊在一起 | s15 改「很多人不是拒絕，是還沒遇到」 |
| 還沒／還是 | s15、s16、s17 | 還＝ㄏㄞˊ，不念 ㄏㄨㄢˊ | 改「仍然沒」／「或是」 |
| 不想結 | s17 | 「結」後面沒有「婚」，尾音要念完 | 改「是不想結婚，還是遇不到」 |
| 五萬兩千對 | s18 | 「兩」不念成「二」 | 照原字再生一次 |
| 夫妻離婚 | s18 | 妻、離兩個 ㄧ 韻相連，要分得開 | 改「夫妻，離婚」 |

改任何一個字都要整篇重來（`npm run tts love-stats` 1 次請求 → `npm run align love-stats`）。
