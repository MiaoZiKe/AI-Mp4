# tech-cufoil 構造與物理規格（示意）
1. 電解銅箔（s2）：電解槽裝硫酸銅藥水；鈦滾筒是陰極、下半泡在藥水裡慢轉；弧形陽極在滾筒下方；通電後銅離子從陽極往滾筒走、沉積成一層銅；滾筒轉出液面的那段已長滿銅，在頂端被撕下、繞過導輥、捲到收卷輥（research #1）。厚度由轉速與電流控制，不標數字。比喻「煎潤餅皮」只比「長在轉動的面上、整片撕下」，卡片標「電鍍，不是加熱」。
2. 光面／粗面（s3）：貼滾筒那面複製滾筒的平滑面（光面）；另一面是粗面，後處理長出小銅瘤（瘤化），樹脂壓下來包住銅瘤（錨定）→ 魔鬼氈（research #2、#3）。放大，不按比例。
3. 集膚效應（s4）：高頻時電流集中在導體表面薄薄一層；表面凹凸和這層厚度差不多時，訊號沿凹凸走、路徑變長、損耗變大（research #4）。動畫：訊號光點沿粗面的凹凸繞路（慢）；s5 低粗糙度銅箔上走直線（快）。不標頻率、粗糙度數字。
4. 低粗糙度的取捨（s5）：越平損耗越低，但銅瘤小、附著力變難；卡片用蹺蹺板表示「平」與「黏牢」互相拉扯（research #5）。
5. 玻纖布（s6）：白金漏板流出熔融玻璃→拉成細絲集束→收絲；捻紗（紗管自轉）；織布機：經軸送經紗、綜框一上一下開口、劍桿送緯紗、筘打緊、布軸捲布＝平紋一經一緯（research #6、#7）。
6. 玻纖效應（s7）：玻璃與樹脂介電常數不同；一對訊號線一條在紗上（周圍玻璃多、慢）、一條在空隙上（樹脂多、快）→ 抵達時間差（skew）（research #8）。速度差放大示意。
7. 開纖＋低介電（s8）：圓紗束攤平成扁帶、空隙變小 → 兩條一樣快；再換低介電玻璃 → 兩條都更快、損耗更少（research #8、#9）。不標介電常數。
8. 預告（s10）：銅箔／膠片×3／銅箔疊好、上熱板壓下（壓合）；右邊已壓好的板子上一排鑽孔、孔壁鍍銅的孔圈，鑽軸上下鑽孔（下一集 3-13 細講）。
