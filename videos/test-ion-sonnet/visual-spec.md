# test-ion-sonnet 畫面規格（離子佈植，14.5 秒無聲）
- 產生方式：`python3 videos/test-ion-sonnet/genmodel.py` → model.json、script.json；`node scripts/three/silent-timeline.mjs test-ion-sonnet` → 無聲時間軸。
- 四幕：s1 0–3 秒無塵室全景（緩推、略升仰角）｜s2 3–7 秒離子源出離子、加速管內加速（鏡頭繞到管子水平）｜s3 7–10 秒分析磁鐵轉彎、重離子撞外壁、輕離子撞內壁｜s4 10–14.5 秒射束經直管與下彎打到晶圓、晶圓來回掃描，再放大到矽剖面，離子停在不同深度，摻雜帶漸層浮現。
- 離子＝球＋三軸白色加號＋光暈＋三階拖尾（落後 3／6／9 幀，所以越快拖越長）；對的離子珊瑚色、太重藍色大球、太輕青綠小球。
- 動作全用 props.shift 組：加速＝a²（fallOut），減速＝2a−a²，彎道＝二次貝茲，晶圓掃描＝預設緩動；皆有加減速。
- 標籤 4 個：離子源、加速管、分析磁鐵、摻雜區。無配音、無字幕（字幕框關閉）。
