# 音色設定：taiwan-youth-no-kids

## 為什麼選 Sulafat（一句話）
這一題講的是每個上班族都碰得到的錢、房、時間，數字很沉、受眾又最怕被說教，所以要「溫暖、沉穩、像朋友坐下來講」而不是「新聞播報」的聲音 —— 選 **Sulafat（溫暖）**。

## 候選比較（Gemini TTS 預建音色）

| 音色 | 官方特色 | 聽感定位 | 適合度 |
|---|---|---|---|
| **Sulafat** | 溫暖 | 有溫度但不甜膩，咬字清楚，念 0.695、5,839 億這類數字時不會顯得冰冷 | ★★★★★ 主選 |
| Achernar | 柔和 | 更軟、更貼近耳邊，第 13 幕年輕人的話很適合，但第 03–08 幕的數字段落容易顯得沒有力氣 | ★★★★ 第一備選（若 Sulafat 試聽太像播報） |
| Schedar | 平穩 | 中性、穩定、資訊感強，像晨間新聞；中立度最高，但共鳴感較弱 | ★★★ 第二備選（若審核要求更客觀） |
| Vindemiatrix | 溫柔 | 四個裡最柔，全集用會太軟、可能讓人覺得在「安慰」 | ★★★ 備選 |

沒選的原因：Charon／Rasalgethi（資訊感）太像新聞台，少了「跟你聊」的感覺；Kore／Orus／Alnilam（堅定）對這題容易被聽成在責備年輕人或政府；Puck／Laomedeia（輕快）和「出生數歷史新低」的內容不搭。

## 語速目標
- **每秒 4–5 字**（scripts/validate.mjs 以 4.3 字／秒＋每幕 0.9 秒間隔估算，本集 15 幕估約 95 秒）。
- 數字段落（第 04、07、08、09、11 幕）放慢到約 4 字／秒，讓「零點六九五」「五千八百三十九億」每個數字都聽得清楚。
- 問句（第 01、13 幕）語尾稍微上揚，不拖長；第 14 幕總結稍慢、句尾收穩。
- 逗號停 0.2–0.3 秒、句號停 0.4–0.5 秒：align.mjs 用這些停頓對上字幕在「，」的斷行。

## 風格指示句（＝ script.json `voice.style`）
```
用溫暖沉穩、像朋友聊天的台灣國語，語速中等、每個數字唸清楚，不激動也不說教
```
tts.mjs 對 gemini-2.5 系列會送成「…不激動也不說教說：＜旁白＞」；3.x 模型只送純文字，語氣靠音色本身。

## 試聽與回讀流程
1. `npm run voices taiwan-youth-no-kids` → 用第 1 幕試聽 4 個候選，輸出到 `out/taiwan-youth-no-kids/voice-samples/`，看 `samples.json` 的 `charsPerSec` 是否落在 4–5。
2. 選定後 `npm run tts taiwan-youth-no-kids`，再 `npm run align taiwan-youth-no-kids`。
3. 打開 `videos/taiwan-youth-no-kids/tts-check.md`：CER > 20% 的幕重跑；重點聽第 12 幕「朝野」、各幕「率」、第 08 幕「百分之四點九」有沒有念對（規則見 pronunciation.md）。
4. 若改了任何一幕的文字，從 TTS 重跑該幕（`--only=<id>`），配音是整支影片的時鐘。
