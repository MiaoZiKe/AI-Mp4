# 念稿規則：taiwan-youth-no-kids

本表和 script.json 每幕的 `tts` 欄位一致；`tts` 省略的幕（01、02、05、13、14、15）旁白沒有數字或縮寫，直接念 `narration`。
Gemini TTS 用 `voice.style` 當語氣指示（見 voice.md）；配音後用 `npm run align` 產生的 tts-check.md 核對下列「回讀重點」。

## 一、通則

| 類型 | 規則 | 例子 |
|---|---|---|
| 整數 | 阿拉伯數字一律改成中文口語讀法（十／百／千／萬／億），不逐位念 | 2,030 → 兩千零三十；5,839 億 → 五千八百三十九億；164 → 一百六十四；10 萬 → 十萬；7 萬 → 七萬 |
| 「二」與「兩」 | 千、萬、億位前讀「兩」；個位、十位以下與小數讀「二」 | 3 萬 2 → 三萬二（口語省略「千」，不讀「三萬兩」）；2,030 → 兩千零三十；2 到 4% → 二到四 |
| 小數 | 「點」後逐位念 | 0.695 → 零點六九五；4.9 → 四點九 |
| 百分比 | 「百分之」放在數字前；本集**不用「趴」**（太隨性，與溫暖沉穩的語氣不搭） | 4.9% → 百分之四點九；2 到 4% → 百分之二到四 |
| 「成」 | 原樣念 | 四成 → 四成 |
| 範圍 | 「到」 | 35 到 39 歲 → 三十五到三十九歲；0 到 18 歲 → 零到十八歲 |
| 年份 | 本集旁白刻意不念年份（用「去年」「今年」「8 年」），若日後補念：逐位讀 | 2025 年 → 二零二五年；2026/11/6 → 二零二六年十一月六日（只出現在畫面，不念） |
| 「8 年」 | 數量詞，念「八年」 | 少子化預算 8 年編了 → 八年 |
| 單位 | 原樣念 | 小時、萬、億、歲、人 |
| 英文縮寫 | 本集旁白沒有英文；畫面上的 TFR、NT$、Dcard、yes123、AI 都只顯示、不念（第 06 幕 footer 已改寫成「第 1 季／第 2 季」，不再出現 Q1、Q2） | （若日後要念：TFR → T F R；Dcard → D card；yes123 → yes 一二三；AI → A I） |
| 標點 | 「，」停 0.2–0.3 秒；「。」停 0.4–0.5 秒；「？」句尾上揚；「、」短停；「：」停頓後語氣轉接 | — |
