# sample-ai-ui 獨立評審（風格試片，13.9 秒）

評審沒有參與製作。看的是 `out/sample-ai-ui.mp4` 每 0.25 秒抽一格的拼圖（56 格）加 5 張放大格，對照 script.json、storyboard.json、research.md。聲音沒有用耳朵聽，聲畫匹配只依 storyboard 的 cue 幀和畫面對照。

## 風格判斷
- 和紙拼貼明顯不同：深色軟體介面、游標、打字、節點連線，沒有紙材。這點成立。
- 專業度：中段（四個欄位逐一上色填字）最好，像產品示範片而不是簡報。開頭與 s3 的空視窗、結尾的小標籤拉低完成度，整體還沒到 what-is-server 的水準。

## 問題
| 位置 | 等級 | 問題 | 建議 |
|---|---|---|---|
| s3（3.3–5.2 秒） | should-fix | 編輯器面板約 1.9 秒只有一條文件列，其餘全空 | 四個空欄位在 start 就出現（灰階），或把指南文件放大成主角 |
| s1（0–1.8 秒） | should-fix | 鉤子幕的聊天視窗是空的（製作方也回報空白帶 428px） | 視窗縮矮、輸入框放大置中，或先放一則灰色舊訊息 |
| s5 回覆卡 | should-fix | 每行對應哪一塊的標籤看不出道理（「第二包九折」標角色、「三分鐘沖好」標任務），教學片會誤導 | 改成說得通的對應（語氣＝角色、主題＝任務、上班族＝背景、標題加三行＝格式），或拿掉逐行標籤 |
| s5 旁白 | should-fix | 「四塊補上去」比官方原意強（官方：不必四項都用）；出處原文沒親眼讀到，只有搜尋摘要 | 正式片補一句「不用每次寫滿」，並放行 services.google.com 讀原文後再上片 |
| 出處列 | should-fix | 24px 低對比灰字，手機上讀不到 | 至少 28px、提高對比 |
| s5 回覆卡標籤、「同一個」膠囊 | should-fix | 字太小、底色太暗 | 放大到 ≥30px 或刪除 |
| s5 節點圖 | should-fix | 四條連線匯到 AI 節點擠成一團，節點區只佔頂端一小條 | 節點區加高、連線分開進節點 |
| s4 字幕 | nit | 中文一次一個詞，英文整句常駐，兩者不同步 | s4 中文四個詞同列、念到哪個哪個上色 |
| s2 蓋章 | nit | 「很普通」章蓋住回覆第二行的後半 | 章往右下移 |
