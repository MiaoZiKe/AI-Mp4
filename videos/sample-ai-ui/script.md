# sample-ai-ui 旁白稿（63 字，目標 13–15 秒）

題目：提示詞只打一句話？官方指南說要有四塊

| 幕 | 旁白 | 畫面（仿介面動畫） |
|---|---|---|
| s1 鉤子 | 你問 AI，是不是都只打一句話？ | 聊天視窗：輸入框打出一句很短的提示詞，游標移到送出鍵按下 |
| s2 | 難怪它回得很普通。 | 訊息送出，AI 回一則灰色的空泛回覆，蓋上「很普通」標籤 |
| s3 | Google 的官方指南說，好的提示詞有四塊： | 鏡頭拉到「提示詞編輯器」：出處小標出現，四個空欄位依序排出來 |
| s4 | 角色、任務、背景、格式。 | 四個欄位念到哪個、哪個上色並打字填入，計數 1/4→4/4 |
| s5 | 四塊補上去，同一個 AI，回答更貼近你要的。 | 游標按送出，四塊沿連線流進 AI 節點，吐出一則有標題、有重點的回覆 |

念稿版（tts）只把 AI 寫成「A I」，其餘同旁白。
