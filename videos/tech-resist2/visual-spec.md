## 運作動畫與旁白同步（流動物依 lessons 54）
1. s1、s3 旋轉塗佈：念「滴一小灘光阻」光阻滴（液體＝水滴形）從噴嘴落到中心 → 念「高速旋轉」吸盤＋晶圓轉（整數圈、加減速）、噴嘴收回、光阻沿螺旋往外流（連續液帶）→ 念「甩成薄膜」膜一圈圈從中心鋪到邊緣、邊緣甩出液滴打到杯壁再流下。2D 卡 trk-coat 同步。
2. s5 軟烤：手臂從旋塗杯夾起晶圓（減速、夾、抬、轉、放、微回彈）放到加熱板 → 加熱盤與銅線發橘、三組熱波往上（熱＝上升波浪）→ 溶劑分子（兩球分子形）從膜面往後排氣口飄走。2D 卡 trk-sb。
3. s6 曝光：手臂把晶圓搬到介面台 → 晶圓沿滑軌滑進曝光機傳送口 → 觀察窗發紫光、窗內光束直直往下（光＝直線光帶）→ 晶圓帶著看不見的潛像滑回來。2D 卡 trk-exp（光穿過光罩開口照到光阻）。
4. s7 曝後烤：手臂搬到加熱板 HP2、加熱、熱波 → 念「反應完全」照光條紋發紫變色。2D 卡 trk-peb（白點＝酸，加熱下走完反應）。
5. s8 顯影：手臂搬到顯影杯 → 縫隙噴嘴掃過晶圓、顯影液扇形噴下（6 道液帶）、液膜（puddle）→ 念「溶掉」照光條紋消失、露出晶粒 → 念「沖水」側邊噴嘴純水扇形 → 念「甩乾」晶圓加減速轉、水滴從邊緣甩出 → 念「烤硬」手臂搬回加熱板 HP1、發熱。2D 卡 trk-dev。
6. s9 為什麼連在一起：遠景；2D 卡 trk-wait（空氣中的鹼性分子飄到頂端 → 頂端變寬走樣）。
