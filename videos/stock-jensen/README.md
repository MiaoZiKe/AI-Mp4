## 已知問題

1. 原文沒有逐字讀過。新聞稿、8-K、員工信、董事會聲明都只看到搜尋摘要（`www.sec.gov`、`nvidianews.nvidia.com` 等主機在這個環境打不開）。涉及私事的 s04 最好等讀過原文再上片。
2. 11/12 收盤跌幅沒查到（出片時剛收盤，搜尋還沒有結果）。s08 只說「盤中一度跌超過一成」。
3. 事件進行中：調查進度、正式人選、本人是否發聲，上片當天要重查；有變化的話 s15、s16 要改稿並整篇重配。
4. s18 折線停留約 0.75 秒，略低於評審建議的 0.8 秒。片尾卡起點由 `scripts/align.mjs` 固定在收聲前 2 幀，再延後要改共用程式。
5. 字幕以下約 360px 一直是空軟木板（評審提過，版面格線如此，沒有改）。
6. `out/stock-jensen-sample.mp4` 是修正前的前 15 秒樣片，已過期。
