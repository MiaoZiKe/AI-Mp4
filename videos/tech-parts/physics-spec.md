## 2. 爆炸分解（只有這一份）
### 2.1 s3 邊緣環（鏡頭側剖 25°）
1. 腔體剖面中，晶圓向上升起半個身位（頂針抬起）→ 標「晶圓」。
2. 邊緣環沿 Z 軸向外上移，露出下方吸盤邊緣 → 標「邊緣環」。
3. 環剖面放大：階梯內緣與電場等位線延伸（桌面接一圈的對應）→ 標「石英」或「矽」。
4. 組回。
### 2.2 s4 靜電吸盤（鏡頭俯角 30°）
1. 吸盤盤面層沿 Z 軸向上分開 → 標「陶瓷盤面」。
2. 電極層露出（銅色圖案，通電後出現 + − 電荷）→ 標「電極」。
3. 背冷氦氣孔與頂針層分開 → 標「氦氣冷卻」（若審片人嫌多可併入下一步）。
4. 冷卻基座與水冷管分開 → 標「冷卻」。
5. 組回；晶圓落下被吸住（無晃動）。

## 3. 運作動畫物理要點
- **電漿轟擊（s2）**：離子在鞘層電場中向被偏壓的表面加速（箭頭方向垂直表面、越靠近越快）；撞擊處亮點閃爍並濺出微小碎屑（沿表面法線附近拋出）；表面逐漸變粗、變薄（用厚度條示意），不是瞬間消失。
- **邊緣均勻（s3）**：晶圓與環組成「一個延伸的表面」，電場等位線在邊緣平順延伸；沒有環時等位線在晶圓邊緣彎折、電漿邊緣不均（作對照圖，標「示意」）。
- **靜電吸附（s4）**：電極通電，盤面介電層兩側出現相反電荷（+ 在盤、− 在晶圓底面），吸力把晶圓壓向盤面；晶圓落下有彈跳阻尼（0.2 秒內收斂）；氦氣在晶圓背面小空隙流動、傳走熱量（細小淡藍粒子，沿孔環流動，**不是**等速直線點）。
- **磨損（s6）**：環厚度逐步下降，內緣被打圓；電漿輝光邊緣隨之偏移（藍色→偏粉），表示分布改變；提示更換。
- **更換動作**：機械手臂或夾具把舊環取出（慣性、輕微擺動），新環落下對位（有微調與停頓）；不瞬移。
- **光**：電漿自發光，周圍零件受弱色光反射（紫粉暈）；石英透光、矽鏡面反射、陶瓷啞光。
- **氣體**：氦氣淡藍粒子；電漿氣體以大量細小粒子表現擴散與閃動。
