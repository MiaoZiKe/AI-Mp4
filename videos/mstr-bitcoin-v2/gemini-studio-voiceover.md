# MSTR 那支：到 Gemini 自己生旁白

網址：https://aistudio.google.com/generate-speech

## 設定
- 模式：Single-speaker audio（單人）
- 模型：Gemini 2.5 Pro Preview TTS 或 Flash Preview TTS（Pro 語氣較好；有語氣指示時兩者都比 3.x 聽話）
- Voice（音色）：Iapetus（清晰）；候選 Charon、Rasalgethi、Sadaltager
- Style instructions（風格指示欄）：
  用清晰、冷靜、略帶節奏感的台灣國語財經科普口吻，語速稍快，數字放慢，關鍵詞稍加重，不帶推銷感。

溢價兩倍時，發十股能買二十枚，每股含幣反而變多。

共同創辦人 Saylor 說要永遠買在頂部，但這有個前提。

到了二零二六年，溢價幾乎歸零，股價差不多只等於手上的幣。

## 生好之後
1. 按 Run 聽一遍，唸錯（例如「Saylor」「Strategy」）就改那句的寫法再生一次。
2. 下載音檔（.wav）。
3. 把檔案直接傳到這個對話給我。我會自動切成 13 幕、對齊字幕、重新渲染影片。

注意：旁白文字不能改句子內容，只能改唸法，否則畫面上的字幕和數字會對不上；要改內容先跟我說。
