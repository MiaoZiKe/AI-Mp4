## 要你決定的事

1. **風格 A 或 B。** A 是桌面紙拼貼（親切、小知識感，素材幾乎都能自己做）；B 是實拍照片壓大字（比較有份量，但還缺 3 張照片、色調偏深）。我的建議是 A；也可以 A 為主，「約 6 小時」和「放在哪」兩鏡借用機房照片。
2. **音色。** 請聽 `same-loudness/` 四段，選最像台灣人、最像真人、英文（IG、Server）也清楚的一段。我聽不到音檔，下面的順序只依量測：
   - E（Achird 男聲）：Server 念得最穩，但起伏最小。
   - A（Callirrhoe 女聲）：整體咬字最穩，但音量最平，而且和上一支片是同一個音色。
   - C（Achird 男聲、新模型）：節奏變化最大，但咬字信心最低。
   - D2（Iapetus 男聲）：抑揚最明顯，但把提示裡的一句話念出來了，這種提示寫法不能用；音色本身可以留著考慮。
   - 特別請聽：「伺服器」的伺是不是 ㄙˋ、I 和 G 有沒有分開、Server 尾音有沒有出來。完整清單在 `voice.md`。
3. **旁白要不要改。** 上面 19 句有沒有哪句不像你會講的話。改稿就要重做配音。
4. **App 怎麼念。** 一個音節（æp）還是 A-P-P。這次沒做出兩版音檔，可以直接告訴我，或選好音色後我補做。
5. **片長。** 目前約 67 秒。要更短可以先刪句 12（半夜到天亮，約 3.3 秒），再刪句 6 後半（約 3.7 秒）。
6. **系列下一集。** 結尾預告的是「雲端，到底在哪？」。research.md 的五集規劃是：Server → 雲端 → 資料中心 → CDN → AI 伺服器。順序要不要照這個走。
7. **要放行的網站或額度（非必要，但會影響品質）：**
   - `engineering.fb.com`：2021 事件的 Meta 原文還沒讀到，目前靠多個二手來源比對一致。
   - `www.pexels.com`：樣張用的 4 張照片授權還沒對過官網原文。
   - AI 生圖目前生不出來（帳號沒餘額）。選 A 的話不需要。

## 目前的缺口

- 樣張只有 s01、s05、s10 三鏡；直向全景（s08）還沒打樣，鎖、雲、信封也還沒試做。
- 試聽只念了句 1–6（含 IG、Server）；LINE、App 兩個字還沒有音檔。
- `gemini-2.5-pro-preview-tts` 在這把金鑰的免費額度是 0，正式配音只能用 Flash 系列。
- 還沒跑 `npm run validate`：這份稿短句多、提問放在懸念之前，和 v2 規則不同，預期會有警告。
- 樣張和分鏡總覽都沒有在實體手機上看過。

## 確認後的製作步驟與預估時間

| 步驟 | 內容 | 預估 |
|---|---|---|
| 1 | 依你的回覆改稿、定音色與提示；補聽 LINE／App | 半天內（每次試聽花 1 次配音額度） |
| 2 | 改 `scripts/tts.mjs`：按四段送、段內不換行、支援整段提示 | 約半天 |
| 3 | 整篇配音＋回讀校驗＋逐字對齊，產生時間軸 | 約 1 小時（看額度，可能要等隔天重置） |
| 4 | 做素材：紙材約 25–30 個 PNG、色紙物件 5 樣（已有 2 樣）；s08 全景先打樣給你看 | A 約 1 天；B 要先補 3 張照片 |
| 5 | 新元件（PaperStage、Cutout、TapeLabel、PaperCaption 等）並依時間軸排 23 鏡 | A 約 2–3 個工作天；B 約 2 個工作天 |
| 6 | 逐鏡截圖檢查 → 渲染（約 4 分鐘）→ 字幕檔 → ffprobe → 給你看 | 約半天 |

合計：方向 A 大約 4–5 個工作天，B 大約 3–4 個工作天（不含找照片與授權確認）。這些是估計，沒有實測過新風格的整支流程。
