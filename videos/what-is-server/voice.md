## 試聽稿（四段都念同一段）

定稿句 1–6 的念稿版，兩段之間空一行：

```
I G 打不開，你是不是先怪自己網路爛？有時候，問題根本不在你這邊。

你滑到的照片，原本都不在你手機裡喔。那在哪？在別人的電腦裡。那種電腦，就叫 Server。中文叫伺服器，說穿了，就是專門幫別人做事的電腦啦。
```

- 英文單字兩個：IG、Server。專有名詞解釋一個：Server＝伺服器。問句兩個，語助詞「喔」「啦」。
- 長度約 20 秒，比任務說的 10–12 秒長。原因：Server 的解釋在句 5–6，只念到句 3–4 就聽不到「解說感」，`script.md` 也指定句 1–6。每個組合一樣只花一次請求。

## 排序與理由

1. **E：Achird＋2.5 Flash＋導演筆記版**
   - 提示沒被念出來。Server 的對齊信心最高（0.977，六個字母都在 0.93 以上），「伺」最接近 ㄙˋ（0.64），除了「伺」以外沒有哪個中文字低於 0.4。
   - 節奏有變化：短語語速變異 14.5%，句號停頓 0.42–1.32 秒不等距，LRA 4.5。
   - 風險：音高起伏是四段裡最小的（13.1 半音，音高中位數 111 Hz 偏低），可能聽起來比較沉、不夠「亮」。
2. **A：Callirrhoe＋2.5 Flash＋短版**
   - 整段對齊信心最高（0.947），提示沒被念出來。
   - 風險：LRA 3.3 是四段裡最平的，句號停頓 0.58–0.88 秒比較規律，比較可能有上一支片那種「平均」的感覺。它和上一支片是同一個音色、同一個模型，使用者已經說過那支旁白糟糕。
   - 「Server」結尾音高比整句高 7 個半音，可能是上揚的強調，也可能是量測誤差，要聽。
3. **C：Achird＋3.8 Flash＋純文字**
   - 節奏變化最大（18.4%），LRA 4.9，而且完全沒有提示就做到。
   - 風險在咬字：整段信心最低（0.875），「你是不是」的「不」0.05、「是」0.19，Server 0.856，G 0.29。這可能是口語化的連音（比較像真人），也可能是含糊。使用者要求咬字清楚，所以排第三。
   - 這個模型不能帶提示，之後沒辦法用文字調整語氣。
4. **D2：Iapetus＋2.5 Flash＋情境對話版**
   - 音高起伏（17 半音）和 LRA（5.3）都是最大，抑揚最明顯。
   - 但提示被念出來，這個提示寫法不能用在正片。G 的信心只有 0.09，「滑到」被聽成「滑多」。
   - 如果使用者喜歡這個聲音，下一步是 Iapetus 配導演筆記版再試一次。

這個排序把「咬字清楚」和「提示不外洩」放在「節奏變化」前面。如果使用者聽完覺得 C 最像真人、字也夠清楚，C 可以排第一。
