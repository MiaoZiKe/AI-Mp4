# pronunciation.md — what-is-server 念稿規則

念稿版只改送配音的 `tts`，字幕維持原文。定稿念稿全文在 `script.md`「念稿版」，逐鏡的 `tts` 在 `script.json`。

## 送出去的格式

- 整篇一次送出（`voice.mode: "take"`，`scripts/tts-take.mjs`）。四段（`script.json` 每鏡的 `para` 1–4），**同一段的鏡接成同一行**，段與段之間空一行。
- 提示＝`voice.style`＋「說：」＋換行＋念稿。提示裡不放場景、動作、引號或任何像台詞的句子（下午的 D2 把「你笑了一下，放下杯子」念出來了）。
- 英文字只在和中文相接的地方留半形空白，標點前不留空白。

## 字幕和念稿不一樣的地方

| 字幕 | 念稿 | 鏡 | 理由 |
|---|---|---|---|
| IG | `I G` | s01、s12 | 拆成兩個字母念 |
| 2021 年 | 二零二一年 | s12 | 數字寫成唸法 |
| LINE | `Line` | s17 | 寫成單字，避免被拆成四個字母 |
| 有時候，問題不在你這邊。 | 有時候問題不在你這邊。 | s02 | 拿掉逗號，不做戲劇性的頓 |
| 那萬一，廚房出事了呢？ | 那萬一廚房出事了呢？ | s10 | 同上 |
| 所有客人，通通沒飯吃。 | 所有客人通通沒飯吃。 | s11 | 同上 |
| 搞不好，是人家的廚房出事了。 | 搞不好是人家的廚房出事了。 | s18 | 同上 |
| 下一集，帶你去看。 | 下一集帶你去看。 | s22 | 收尾不拖 |

字幕在畫面上用換行分段、不帶標點；旁白原文見 `script.json` 每鏡的 `narration`。

## 白名單（確定照原字送、不用改寫的詞）

## 念法要求與這次的結果（2026/11/12 正式配音）

| 詞 | 要求 | 這次量到的 | 狀態 |
|---|---|---|---|
| IG | I、G 兩個字母分開，G 清楚 | 對齊：I 0.99、G 0.50（工具把 G 當「ji」比，只會對上一半）；聽的模型：/aɪ dʒiː/、分開 | 待人耳確認 |
| Server | 兩個音節，尾音有出來 | 對齊 0.89、0.93；聽的模型：[ˈsɝ.vɚ] | 待人耳確認 |
| LINE | 英文 /laɪn/，有尾音 n | 對齊：l、i 有對到，**n 是 0.00**（拿「賴」去比是 0.96）；聽的模型：/laɪn/ | **兩個工具不一致，一定要聽** |
| 伺服器 | 伺念 ㄙˋ，不是 ㄘˋ | 這個字只有 0.1 秒，對齊分數低（當 ㄘˋ 0.05、當 ㄙˋ 0.14）；聽的模型：ㄙˋ | **一定要聽** |
| 二零二一年 | 逐位念 | 聽的模型：ㄦˋ ㄌㄧㄥˊ ㄦˋ ㄧ ㄋㄧㄢˊ；五個字約 0.65 秒，偏快 | 待人耳確認 |
| 六個小時 | — | 整篇聽寫是「6个小时」 | 通過 |
| 掛掉、鎖死、那在哪、那種 | 不含糊 | 對齊都在 0.7 以上 | 通過（數字） |

「聽的模型」是把單鏡音檔交給 `gemini-3.5-flash-lite`／`gemini-flash-lite-latest` 問它聽到什麼。它可能被問法帶著走，只能當參考。

## 如果人耳聽了不對，怎麼改

- 「伺」念成 ㄘˋ：`script.json` s05 的 `tts` 改成「中文叫四服器，」，字幕不動。
- LINE 沒有尾音 n：s17 的 `tts` 試「LINE」（全大寫可能被拆成四個字母）或在後面加逗號「Line，打不開」讓尾音念完。
- 年份太快：s12 的 `tts` 改成「二零二一年，就有一次，」。
- 改任何一個字都要整篇重來：`npm run tts what-is-server`（1 次請求）→ `npm run align what-is-server`。同一個提示每次的語氣會有差，重做後要重量音高起伏（見 voice.md）。
