# 畫面規格：what-is-server（styleVersion 3・桌面紙拼貼）

> 與 `script.json`、`timeline.json`、`storyboard.json` 同步（2026/11/12）。數值對應 `src/theme.ts`（`THEME_V3`／`LAYOUT_V3`）、`src/components/v3/`。時間只有一個來源：配音對齊後的 `timeline.json`；本檔的幀數是從它抄來的，改稿或重配音後要重產。

## 1. 基本規格

| 項目 | 規格 |
|---|---|
| 尺寸／幀率 | 1080 × 1920、30 fps、H.264 MP4 |
| 長度 | 23 鏡、1913 幀＝63.77 秒（人聲 61.2 秒＋片尾卡 2.5 秒） |
| 人聲 | `public/audio/what-is-server/voice.wav`（Iapetus，整篇一次生成，整條 loudnorm −16 LUFS） |
| 風格 | 方向 A 桌面紙拼貼：米色桌面、撕邊紙條、紙膠帶、色紙疊的物件、剪下來的實物照片。不用 3D、SVG 圖示卡、霓虹發光 |
| 紙材 | `python3 scripts/make-paper.py what-is-server` → `public/v3/what-is-server/*.png`＋`meta.json`（程式產生的點陣圖＋4 張 Pexels 照片；不進 git） |
| 元件 | 每鏡 `component: "PaperScene"`，最後一鏡 `"EndCard"`；封面 `cover: { camera, items }`（同一套寫法） |

## 2. 一鏡到底的做法

- 全片是同一張桌面（世界座標）。23 鏡是 23 個鏡位：`camera.to = [cx, cy, s]` 表示世界點 (cx, cy) 對到畫面中心 (540, 960)、縮放 s。
- 紙片依 `at`（cue id，可加減幀；cue 自動提早 4 幀）貼上、移動、退場。沒有淡入淡出：貼上只有位移與縮放，退場是由一側揭掉（遮罩）、滑出，或被別的紙蓋住後直接拿掉，都不用透明度（唯一例外是出餐口關燈的 6 幀亮暗交疊），沒有「一幕一張圖卡」。
- 轉場都從內容長出來：鏡頭沿紙虛線移到桌面另一區（s04、s08、s18、s20）；色紙蓋下再掀開（s06→s07 牛皮紙、s22→s23 米白紙）；深綠切割墊由上蓋下／往上掀開（s10 進「轉」、s17 回到開場構圖）；色紙被抽走（s14→s15 晨色紙連太陽往左抽走 10 幀，不用透明度）。
- 逐格感：桌面上的紙片每 2 幀更新一次位置，落定後每 9 幀抖 ±1px、±0.3°（固定 seed；`AUDIT` 時關）。鏡頭每幀更新、不回彈。
- 重點推近（`punch`）全片 4 次：s05「Server」、s10「出事」、s13「六個小時」、s20「放在哪裡」。

## 5. 檢查方式

- `npm run validate what-is-server`：結構、字數、字幕寬度、出處寬度、畫面字 ≤14 字、禁「App」、cue／ref／紙材是否存在、封面。
- `npm run still what-is-server`：每鏡 still（v3 取下一鏡開始前 1 幀；鏡可用 `still: "cue+N"` 指定代表畫面）、封面、overview，再跑覆蓋率（`cov2.py` 量測、v3 門檻：佔用率 warn <40%／error <25%，最長空白帶 warn >260px／error >480px）→ `out/what-is-server/coverage.json`。
- `npm run selfcheck what-is-server -- --sample`：前 15 秒樣片的確定性、靜止段、鉤子幀差、跳變、轉場佔用。
- `node scripts/v3/peek.mjs what-is-server out.png s08:order+8,s09,120`：渲指定時刻排成拼圖，看動作中途。
