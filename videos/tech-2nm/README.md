## 配色：換色只要改一個欄位

`script.json` 頂層的 **`hudSkin`**。色票全部在 `src/theme-hud-skins.json`，一套一個鍵；要新增第三套就在那個檔加一個鍵，其他都不用改。

| hudSkin | 樣子 | 用在哪 |
|---|---|---|
| `deep` | short-tech 原本的：深藍黑底、青藍線條、琥珀強調、珊瑚警示；零件多色（金色閘極、紫色高介電層、綠色間隔層） | 對照圖上排；沒寫 `hudSkin` 的片（short-tech）就是這套 |
| `glass` | 「科技透明圈」提案：近黑底 `#05070A`、冰藍 `#A9DDFF` 與白的線條和零件、**只有一個品牌強調色**（螢光萊姆 `#C6FF4A`，蓋章、重點字、進度線、通電的閘極都用它）；紅色只留給漏電的小點 | **成片用這套** |

使用者還沒給 Tech 頻道的正式色票，`glass` 是提案。拿到正式色票後：把 `glass` 裡的 `line`（主線條色）、`amber`（品牌強調色）、`bg` 換掉，或另加一套，然後重跑 render。換皮膚不用重配音、不用改腳本。
看兩套的差別：`node scripts/three/skin-compare.mjs tech-2nm 60,320,690,1225`。

## 對 short-tech 已知問題的處理

| short-tech 的問題 | 這支怎麼處理 |
|---|---|
| 前 5.8 秒連鑽四級太趕 | 每一級一句旁白、各停 2–3 秒（s3–s6），前段縮放從 5.8 秒拉到約 15 秒 |
| 運作段太密 | 拿掉十項圖例、「電子 e⁻ →」「電流方向 ←」兩張小標；開和關拆成兩鏡各蓋一個章 |
| 運作段偏霧 | 接點、銅線整層收掉（原本是 7–14% 的半透明），間隔層 10%、閘極 50%；`glass` 皮膚的外圈光暈減半。**比 short-tech 清楚，但外層還是半透明，不是完全銳利** |
| 標籤壓到模型 | 「源極」「汲極」的標籤位置往外、往下移，引線拉出模型外 |
| 小字太小 | `hud.smallPx: 30`：對照卡與儀表的小字下限 30px；圖例拿掉 |
| 層級名與圖裡的小字重疊 | `glass` 皮膚把讀數底板的不透明度從 0.72 提到 0.9 |
| 沒有新舊對比、沒有片尾卡 | 加了 s10–s11 對照卡、s20 片尾卡 |

## 配音

- 音色 Iapetus（CLAUDE.md「各頻道音色」科技）、模型 `gemini-2.5-flash-preview-tts`、`languageCode: cmn-TW`、旁白設定檔 `tech-report`（只送一句說明）：
  「用台灣人平常講話的口音，不特別捲舌、不兒化，像平常跟人講一件事那樣，語速稍快、語氣沉穩、不拖尾音、不演，直接說：」
- **TTS 請求 1 次**（`tts-requests.json`，狀態 200），沒有重送。另外花了 1 次文字模型請求做聽寫。
- 聽寫（`tts-take-asr.json`）：19 句都在、順序對、提示句沒有被念出來。聽寫把「主機板」寫成「主基板」，其他只是簡體與用詞轉換（晶体管、栅极）。
- 語速（232 個字）：

| | 扣掉停頓 | 含停頓 |
|---|---|---|
| 模型原始錄音（63.0 秒） | 4.50 音節/秒 | 3.59 |
| 加速 1.08 倍後（58.4 秒） | **4.84** | 3.87 |
| 成片時間軸（停頓上限 0.6 秒，旁白 56.3 秒） | 4.84 | 4.12 |

  模型自己念不到 4.6–5.0，所以加速到上限 1.08（`ffmpeg atempo=1.08`，不變調；原始錄音留在 `public/audio/tech-2nm/.take-83740616bb.orig.wav`，加速前的切檔資料在 `tts-manifest.raw-pace.json`）。
  加速後連片尾卡是 60.8 秒，超過 60 秒，所以對齊時另外用了 `ALIGN_GAP_MAX=0.6`：句間停頓超過 0.6 秒的（原本最長 1.09 秒）壓到 0.6 秒，短的不動，成片句間停頓是 0.33–0.60 秒。**這和 CLAUDE.md「不把停頓壓成等距、不調 ALIGN_GAP_MAX」那一條有出入**（另一條「語速」又說可以用），這裡選了只壓最長的幾個；如果不要壓，片長會是 60.8 秒，或要刪字重配。
- 捲舌指標（`scripts/voice-retro.py`，原始錄音）：ㄓㄔㄕ 5439 Hz、ㄗㄘㄙ 9275 Hz，**差距 3836 Hz，偏高**（參考：what-is-server 0.9 kHz、tech-cowos 0.5、love-stats 2.9、被聽成中國口音的 stock-jensen 4.4）。照這個數字，這一版有可能聽起來捲舌偏重；口音只有人耳能判斷，沒有自行重配。
- 對齊信心：整篇 0.90；最低的是 s12「那二在哪裡？」0.62，其餘 0.78–0.99。

## 人耳確認清單（秒數是成片時間）

1. 全片：口吻是不是平實在講一件事；**捲舌會不會太重、像不像中國口音**（指標偏高）；加速 1.08 自不自然；背景音樂會不會蓋到人聲。
2. 0.0–2.6 秒：「兩奈米」的「兩」念 liǎng；「尺寸」。
3. 5.0–7.2 秒：「主機板」（聽寫聽成「主基板」）。
4. 9.1–12.5 秒：「指甲大」「上百億」；蓋章要在念到「上百億」之後才出現（約 11.5 秒）。
5. 14.9–19.4 秒：「閘極」念 zhá；念「拆開」時模型開始分層。
6. 19.4–23.9 秒：念「電壓」時電壓條升起、念「電子」時光點出發；句尾「這是開」。
7. 23.9–27.2 秒：句尾「這是關」；到下一句前有全片最長的停頓（0.6 秒）。
8. 27.2–31.0 秒：「鰭式」念 qí shì，不要念成「旗幟」之外的怪音。
9. 34.3–35.8 秒：「那二在哪裡」（對齊信心最低，蓋章可能早晚幾幀）。
10. 35.8–41.0 秒：「五奈米」「四十四奈米」「間距」；尺寸線在念到之後出現。
11. 46.3–52.3 秒：「兩成五到三成」數字清楚；橫條在念「耗電」時長出來。
12. 54.4–56.3 秒：「曝光機」。

## 已知問題（照實寫）

1. 捲舌指標偏高（見上），口音要人耳確認。
2. 句間停頓壓過上限 0.6 秒、整段加速 1.08 倍，才壓進 60 秒。
3. 前 3 秒的事件偏少：大字、關鍵詞上色、1.3 秒蓋章、字幕換段，背景只有手機慢慢推近與掃描線；沒有先預告 payoff 的畫面。
4. 有幾段畫面接近靜止超過 1.5 秒：主機板（約 5.5–7.2 秒）、晶片（約 8.3–10.8 秒）只有掃描線和小標；對照卡期間（27–34 秒）上方的 3D 模型不動。
5. `glass` 皮膚的 3D 零件都是冰藍／銀白，閘極、間隔層、高介電層之間的分別比 `deep` 小；拆開後主要靠標籤認零件。
6. 對照卡下緣的「閘極包三面／四面」貼著舞台下框線。
7. 「5 nm」尺寸線本身很短，主要靠數字框讀；再拆開那一鏡和第一次拆開是同一個角度。
8. 拆開時閘極直直往上抬離薄片，真實不可能這樣拆（出處列有寫「爆炸圖只是畫法」）。
9. 手機、主機板、晶片、陣列都是幾何示意；s15 拉遠回手機時 1.3 秒內倒著經過四級，中間幾幀只是色塊閃過。
10. 出處列出現「台積電」（s16–s17，因為省電的數字是它公布的目標值）；旁白沒有講公司名。要完全不出現就把那兩幕的 `sources` 改掉重渲。
11. 省電「少兩成五到三成」是廠商的設計目標、對比上一代製程，不是實測，也不等於手機續航多三成；片中有標「廠商目標值，非實測」。
12. 下一支「曝光機」只預告題目，內容還沒查證。
13. 片尾卡 2.4 秒，偏短。
