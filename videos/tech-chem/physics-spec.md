## 2. 爆炸分解（只有這一份；s4 送液、s7 研磨液槽）
### 2.1 s4 管理櫃（鏡頭俯角 30°，每步 1.0～1.5 秒綁 cue）
1. 櫃門打開向側面移開 → 標「化學品管理櫃」。
2. 泵與閥島沿 X 軸分開 0.4 個身位 → 標「泵」。
3. 過濾器殼沿 Z 軸向前抽出，剖面露出褶疊膜 → 標「過濾器」。
4. 流量計與壓力轉換器上移分開（顯示讀數）→ 標「測量」（注意：念稿不用「量測」，標籤用「測量」）。
5. 全部組回，液流從槽→管理櫃→迴路流動（藍箭頭）。
### 2.2 s7 研磨液循環槽組
1. 槽蓋掀開，攪拌槳露出（慢轉）→ 標「攪拌」。
2. 槽內分層剖視：結塊的大顆粒（灰色塊）沉在下層、被迴路抽走 → 標「循環」。
3. 迴路過濾器沿軸線拉開，濾膜表面卡住大顆粒 → 標「過濾」。
4. 組回。

## 3. 運作動畫物理要點（每幕至少一段與旁白同步）
- **液體送液（s4）**：泵啟動才有流動（有 0.3 秒起動延遲與壓力波）；管內層流為主，中心較快、管壁較慢（流線）；彎頭處略有二次流；轉彎不要瞬間改向。
- **酸與金屬（s5）**：鐵管內壁被酸腐蝕——先出現氣泡、鏽紅點從管壁剝落進入流線；剝落物隨流往下游走；塑膠管內壁光滑無反應。標「示意」。
- **研磨液（s6）**：磨粒在液體中做布朗運動（微小隨機抖動）＋隨液體流動；靠近晶圓凸起處，磨粒被壓住、凸起層被磨薄，同時表面氧化層被藥劑溶出（顏色由灰變透明，標「機械＋化學」）。
- **攪拌與結塊（s7）**：攪拌槳起轉有加速（0→穩速），液面形成淺渦；停止時磨粒緩慢沉降（加速度＝重力減去浮力，終端速度很小），結塊（多顆黏連）沉得更快；結塊被濾膜攔住；刮傷：大顆粒夾在晶圓與墊之間劃出一道線（示意，一次）。
- **光**：無（室內打光），藥水用折射不強的半透明材質。
- **氣體**：濕氮封只在槽頂畫淡淡薄霧，緩慢聚集於液面（不要等速直飛）。
- **所有運動**：加速／減速，不瞬移；泵閥開關有 0.2 秒反應。
