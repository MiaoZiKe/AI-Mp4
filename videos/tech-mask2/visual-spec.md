## 二、運作動畫與旁白同步（≥3 段）＋流動物物理形狀（lessons 54）
1. s5 電子束寫入（主角）：念「電子束」陰極發亮、三組線圈亮、電子（小藍點拖尾）從陰極沿鏡筒直線往下、打點處閃 → 念「一筆筆寫上去」平台左右掃、光阻上的線一條條出現（每 5 幀一條）。2D 卡 mk2-eb：剖面石英／鉻／光阻，電子帶「－」（線畫）往下打、寫過的格子變藍。
2. s6 多束：念「一起寫」單束停、8×8 光闌陣列與 64 道電子束（代表二十六萬道）同時往下、光阻上整塊整塊出現。2D 卡 mk2-mb：左邊一格一格填（慢）、右邊整片同時填。
3. s7 檢測：檢測頭帶光束（直線光、青色）沿光罩掃 → 念「一個瑕疵」紅點亮 → 念「每次曝光」旁邊晶圓每顆晶粒同一處紅點一起亮。
4. s8 光罩盒（主角）：一開始分層懸空（外盒上蓋最高、內盒上蓋中間、光罩懸在底板上）→ 念「裝進光罩盒」光罩落到支撐銷上 → 念「外盒擋灰塵」灰塵碎粒飄來撞到外盒彈開 → 念「內盒是金屬」內盒亮、密封面亮綠；s10 合回。
5. s9 真空：內盒從裝載埠（外盒留在外面）搬進腔、閘門落下 → 念「真空機台」空氣分子（雙球）被抽進真空泵 → 念「才打開」內盒上蓋抬起看到光罩。腔外灰塵撞到外盒彈開。
6. s11 預告：念「光罩到了」極紫外光（紫色光束＋光點）從左打到光罩、反射往下 → 念「一層膠」晶圓上光阻亮 → 念「照到光就會變」光阻上出現曝出的線。
7. s2–s4 廠區：自有光罩廠→天橋送光罩盒（小方塊）進晶圓廠；專業光罩廠→道路送出（往晶圓廠與畫面外客戶）；台灣光罩落下後也送出。
