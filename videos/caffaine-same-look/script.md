# caffaine-same-look 念稿（無聲版，未配旁白）

主旨（一句）：叫 AI 做網頁，沒指定風格就會做出常見的樣子，想要自己的樣子要先講風格。
結論句：先講風格，參考哪裡、要什麼、不要什麼。結構二（原理），片尾留言關鍵字「網頁」。
事實（3）：同一句話兩次，版型配色幾乎一樣（實測 2 次）／原因是一般認為的說法（分析推測）／加風格後明顯不同（實測 1 次）。

| # | 念稿 | 作用 |
|---|---|---|
| s01 | 我請 AI 做咖啡店首頁，同一句話做了兩次，兩份卻幾乎一模一樣。 | 鉤子：情境＋反常 |
| s02 | 兩次都是米白底，區塊都叫我們的堅持，連小標題都只差一個字。 | 現象（Gemini 實測逐字節錄） |
| s03 | 排法也一樣：左文右圖，下面三欄小卡片，右上角是深色按鈕。 | 現象補充（Playwright 量測） |
| s04 | 為什麼？一般認為，AI 偏向最常見的樣子。你沒指定，它就選最保險的。 | 原因（分析推測，畫面標示） |
| s05 | 所以我多寫一句風格，參考日本咖啡館的手寫菜單。再做一次，樣子明顯不同，只試了一次。 | 解法（實測 1 次） |
| s06 | 所以想要自己的樣子，先講風格：參考哪裡、要什麼、不要什麼。 | 所以呢 |
| s07 | 留言「網頁」，拿這句風格提示詞。 | 唯一動作 |

自檢：只聽旁白能講回主旨 ✔；每句接上一句（為什麼／所以／再做一次）✔；沒講沒測到的紫色漸層與別的模型 ✔。
已知限制：只測一個題目（咖啡店首頁）、一個模型；原因沒有實測，已標「分析推測」。
