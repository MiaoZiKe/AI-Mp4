# tech-implant 畫面規格（給 Opus 建模與運作動畫；Sonnet 前製，11/20）

沿用 `videos/test-ion-opus/`（Andy 看過的比較片）的整套模型與 gen.py 結構：離子源→加速管→分析磁鐵→射束管線（含解析狹縫、掃描板、渦輪幫浦）→終端站→晶圓剖面。不重建，**複製 `test-ion-opus/gen.py` 成 `videos/tech-implant/genmodel.py` 再改**（座標沿用：射束高度 y=5，離子源 (-8.75, 6.1, 4)，加速管 (-4.6, 5.75, 4)，磁鐵圓心約 (4.85, 4.9, 4.25)，晶圓 (5.5, 5.6, -6.75)，剖面放大約 (6.4, 11.3, -7.6)，單位約 20 cm）。`fable` 版 `test-ion-fable/` 只當細節參考（機櫃門板與板縫、10 片電極由深藍到淺藍表示電位、冷卻水管、閘閥）。
旁白、cue、字幕：`script.json`（`genscript.py` 產生）；時間軸：`timeline.json`／`storyboard.json`。**所有動作的幀數改用 cue（s?:<cue id>±幾幀）**，不手填幀。全片 ≈ 66 秒（以 timeline 為準），停頓 0.65–0.8 秒；每個畫面落定後 ≥1.5 秒才換。

## 四、流動物對照（#54）
氣體分子＝2～3 顆球黏成分子形（BF₃ 一大三小、PH₃ 一大三小），只在氣體管線與離子源腔內｜電子＝更小「－」點，腔內螺旋｜離子＝球＋「＋」，只在加速管／射束管／磁鐵飛行腔／終端站腔內，走完就消失（flow-check 驗）｜電場＝電極環間的淡藍弧線＋箭頭｜磁場（s6）＝垂直於射束的細弧線箭頭（符號⊗）｜火花＝星形＋擴散圈｜熱／修復不畫（本片不展開）。
