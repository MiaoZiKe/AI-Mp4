# tech-implant 旁白稿：離子佈植（接量測與檢測；片尾預告清洗；預定 11/30 週一 20:00）
念稿字數 317（不含標點），預估成片約 65～72 秒（含片尾卡 3.2 秒）。

1. 【鉤子】上一支量完，表面平，膜厚也對。但這片矽還不會導電，所以把離子打進去，每秒飛一千三百公里。
2. 純矽導電很差。打進磷多出電子，叫N型；打進硼留下電洞，叫P型。
3. 光阻先遮住不要打的地方。離子一路飛過離子源、加速管、分析磁鐵、終端站。
4. 離子源把氣體變成電漿。磷用磷化氫，硼用三氟化硼，再用電場把離子拉出來。
5. 加速管一環一環加電壓，離子越跑越快。十萬電子伏特的硼離子，每秒約一千三百公里。
6. 但離子源裡什麼都有。分析磁鐵讓離子轉彎，太重太輕的轉不過去，撞牆被擋掉，只剩對的過關。
7. 對的離子進終端站。射束左右掃，晶圓上下動，每一點打進的量才一樣。
8. 離子打進矽，一路撞一路慢，停在某個深度。能量決定多深，打多久決定多濃。
9. 【公司】機台有應用材料和亞舍立，植入氣體有台灣的兆捷。
10. 【結尾】這樣矽就有了導電的區域。但光阻被打到焦硬，表面也髒，所以下一支，看清洗。留言離子，看完整解說。
11. （片尾卡 3.2 秒，無旁白）

## 因果鏈
上一支「量完平、厚度對」→ 但還不導電 → 所以打離子（鉤子）→ 因為純矽導電差 → 摻磷／硼（2）→ 先用光阻遮（3）→ 機台四段（3–7）→ 離子源出來什麼都有 → 所以磁鐵篩（6）→ 為了每點一樣 → 掃描（7）→ 結果：停在深度（8）→ 結尾：打完光阻焦硬、表面髒 → 所以下一支清洗（10）。
