# tech-implant 念稿讀法

## 白名單
- 公司名全用中文：應用材料、亞舍立（ㄧㄚˋ ㄕㄜˋ ㄌㄧˋ）、兆捷（ㄓㄠˋ ㄐㄧㄝˊ）。
- 「矽」：念稿（tts）一律寫成「細」（字幕維持「矽」），送配音前 grep 矽、grep 夕 都要 0 筆。2026/11/22 從「夕」改「細」：寫「夕」被 Gemini 念成一聲 xī（大陸讀音），「細」兩岸都念第四聲 xì。
- 「N型」念稿寫「恩型」、「P型」寫「皮型」（避免英文字母被拆讀）；字幕維持 N型／P型。
- 三氟化硼、磷化氫為正式中文名，不寫 BF3／PH3。
- 「十萬電子伏特」＝100 keV；「一千三百公里」。

## 讀法檢查（送 TTS 前逐句）
- 無「欸」、無英文字母（念稿全中文）、無數字符號、無中國用語；每句不以英文字母開頭。
- 多音字：「撞牆被擋掉」「的」輕聲；「過關」；「磁鐵」ㄘˊ ㄊㄧㄝˇ。
- 待人耳確認：「亞舍立」「兆捷」「恩型／皮型」。
