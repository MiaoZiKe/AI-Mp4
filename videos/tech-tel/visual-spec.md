## 二、各幕鏡頭與現象（主畫面一定看得到）
| 幕 | 鏡頭 | 3D 現象 | 標籤（一次一張） |
|---|---|---|---|
| s1 | 塗佈杯正面推近 | 晶圓起轉（rampSpin）、光阻細流受重力加速滴下、五圈由內往外鋪開、邊緣切線甩出液滴 | 塗佈杯 |
| s2 | 爐管全景（yaw −0.35） | 側牆潔淨氣流、塔燈、指示燈 | 晶舟、加熱器 |
| s3 | 爐管全景（爆炸分解） | 頂蓋上抬 → 加熱器兩半往兩側掀開 → 外管往上抽出；「裝回去」念到時組回、停住 | 加熱器、石英管、晶舟、保溫座 |
| s4 | 手臂與晶圓盒 | 伸入晶圓盒 → 抬起五片 → 縮回 → 轉 180° 並升高（緩入緩出）→ 伸入晶舟空格 → 放下 → 縮回 → 回原位 | 晶圓盒、五支叉片 |
| s5 | 全景 | 擋板滑開、整舟先加速再減速升進爐管 | 爐口擋板、晶舟升降機 |
| s6 | 剖開（右半隱藏） | 五區線圈由下往上依序發光、橙點從線圈往內穿過石英管到晶圓、石英管再晶圓依序變暖 | 加熱線圈、晶圓最後才熱 |
