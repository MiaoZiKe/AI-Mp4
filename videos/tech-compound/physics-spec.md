# tech-compound 構造與物理規格（示意，數字出處見 research.md）
1. 能隙（s2、s3）：電子從價帶跳到導帶要越過的能量差。矽 1.12 eV、4H-SiC 3.26 eV、GaN 3.4 eV（約 3 倍）。能隙大→同樣厚度能承受的電場約 10 倍（崩潰電場：矽約 0.3 MV/cm、SiC/GaN 約 3 MV/cm）。畫法：下方價帶（填滿電子的藍色帶）、上方導帶（空的）、中間空隙高度按比例（1.12：3.3）；矽在高電壓下電子被拉過門檻（亮點跳上去、沿導帶流走＝漏電）；SiC 的門檻高，電子跳不上去。示意，非真實能帶形狀。比喻：門檻＝堤防高度，電壓＝水位。
2. 電動車主逆變器（s4）：電池直流 → 功率模組（SiC MOSFET 開關）→ 三相交流給馬達（畫法：直流單向流動；三相線上電荷來回擺動、三條相位差 120°；晶片快速開關閃動，頻率示意）。SiC 導通與切換損耗較低→發熱少（不標數字）。功率模組構造（由下而上）：銅底板（背面針狀散熱鰭）→ 銲料 → 陶瓷覆銅基板（DBC：上下銅層、上層切成走線）→ 銲料 → SiC 晶片（頂面源極金屬、閘極銲墊）→ 鋁鍵合線 → 塑膠外殼＋螺絲孔＋端子（DC＋／DC−、三相 U／V／W）→ 矽膠填充 → 上蓋。來源：System Plus Model 3 拆解（24 顆單管模組、針鰭散熱器）；通用模組構造（Infineon／ST 資料表）。
3. 氮化鎵快充（s5）：GaN 電晶體開關頻率高→變壓器、電容可以變小→整顆變小。構造：外殼兩半、插腳、PCB（走線、銲墊、過孔）、GaN 功率晶片（QFN：底部銲墊、側邊接點）、控制 IC（SOIC）、小型變壓器（鐵氧體磁芯＋銅線繞組）、電解電容、Type-C 母座。對照：同功率的矽充電頭較大（虛線外框，示意比例，不標數字）。AI 機房電源只在 2D 卡提一句。
4. SiC 長晶爐（s6，物理氣相傳輸 PVT）：感應線圈（銅管螺旋，內通冷卻水）在外 → 雙層水冷石英管（片中把線圈繞在石英管外，上下是不鏽鋼法蘭，上蓋有測溫窗） → 石墨氈保溫層 → 石墨坩堝：底部 SiC 粉末、頂蓋內側黏晶種。粉末在高溫（媒體報導 2000～2500°C）昇華成氣體，往上飄到溫度較低的晶種表面直接凝結成單晶（＝結霜：氣體直接變固體）。晶錠由晶種往下慢慢變厚（7～10 天只長幾吋；矽晶棒約 2.5 天 1～2 公尺）。畫法：線圈先亮（感應加熱），坩堝底轉橘紅，粉末上方細小粒子往上擴散（亂流、不是直線），在晶種下表面凝結，晶錠厚度隨時間加。無法即時觀察生長（爐子不透明）→ 剖開示意要標「剖開示意」。
5. 氮化鎵磊晶（s7，MOCVD）：反應腔內，旋轉承盤放多片矽晶圓，下方加熱；上方噴氣頭（孔陣）噴出含鎵氣體（有機金屬前驅物，如三甲基鎵 TMGa；不是金屬鎵蒸氣）與氨氣，在熱的晶圓表面反應，鎵與氮原子照底下的排列落下、長出一層 GaN 薄膜（功率元件常見矽基氮化鎵）。畫法：氣體從噴頭孔錐狀散開、碰到晶圓沿表面流走；承盤轉動；薄膜一層層變厚（極薄，示意加厚）。
6. 台灣分工（s8）：基板（環球晶 6488）→ 磊晶（嘉晶 3016）→ 元件代工（漢磊 3707）。代號兩源，見 research.md。
7. 下一集（s9）：工廠測機台用的控片／擋片（多為矽）用過後研磨拋光去掉表層再用＝再生晶圓。畫法：晶圓在研磨台，研磨墊轉動，表層被磨掉。

r2（2026/11/28）：s6 下熱上冷改在 3D 直接看得到（坩堝後壁與外壁由下到上橘紅→暗紅漸暗、粉末自發光），氣體粒子可見 ≥60 顆並一路到晶種下緣；s9 晶圓搬運照真機（頂桿＋翻面夾爪＋龍門載頭吸片），研磨後才停研磨液再取回。
