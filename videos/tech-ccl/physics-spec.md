# tech-ccl 構造與物理規格（示意）
1. 銅箔基板＝銅箔／膠片（玻纖布浸樹脂、半固化）／銅箔；厚度放大示意（research #3、#4）。
2. 玻纖布：玻璃絲捻成紗，經紗與緯紗一上一下平織（research #8）；s3 緯紗一根根落下就位。
3. 含浸：放卷→導輥→樹脂槽（布整片浸入）→擠壓輥一對（刮掉多餘樹脂）→烘箱（熱風貼布面吹過，半固化＝B-stage，不是全乾）→裁刀切成膠片（research #6、#7）。輥輪轉動、布面流動方向一致。
4. 熱壓：鋼板／銅箔／膠片×4／銅箔／鋼板依序落下（由下往上）；上熱板由油壓缸壓下；樹脂受熱先變軟流動、邊緣擠出一點，再固化變深色（research #6）。不標溫度與壓力。
5. 蝕刻：噴嘴噴藥水，整片銅被吃掉、只剩線路與銲墊；之後訊號光點沿線路走（research #9）。
6. 損耗：訊號脈衝幅度沿路指數衰減（介電損耗大致與頻率、Df 成正比，research #10）；一般材料（約 Df 0.02）衰減大、低損耗（約 0.002）吃掉約十分之一（research #11、#12）。只講損耗、不講速度（速度看 Dk）。示意，不是量測。
