# 旁白：無線耳機裡面有什麼？（69 字，約 14.3 秒；無配音，用字數估時的無聲時間軸）

1. 欸，你的無線耳機裡，塞滿了東西。（鉤子，開口先叫一聲）
2. 拆開外殼，有電池和喇叭單體。
3. 還有麥克風、晶片，跟一條小天線。
4. 降噪靠麥克風，先聽外面的噪音。
5. 喇叭再播出相反的聲波，兩邊抵消就安靜了。

口語規則（docs/voice-natural.md）：進場字「欸」、全篇只用一次語助詞、「跟一條小天線」「再播出」用講話的詞、短句長句交錯、不用「不是…而是」、逗號只放真的要停的地方。
專有名詞解釋：「喇叭單體」緊接在喇叭旁；「降噪」緊接著講做法（麥克風聽、喇叭反著播）。
備註：實際降噪對低頻最有效（約 1000 Hz 以下），片中沒講，留給下一集。
