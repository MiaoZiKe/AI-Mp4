# sample-ai-news：十月物價新聞丟給 AI（AI 教學頻道第一支完整版）

現在的成片是**無聲版**（還沒配音）：`out/sample-ai-news.mp4`，1080×1920、30fps、H.264，63.1 秒（1893 幀），20 鏡，最後一鏡是片尾卡。**注意：這支 MP4 是 2026/11/13 改寫旁白（親和專業版）之前渲染的，字幕還是舊稿；新稿的估算時間軸是 65.9 秒（1978 幀），還沒重渲染。**
時間軸是照念稿音節數估的（`videos/sample-ai-news/timeline.json`，裡面有 `estimated` 標記）。配音後重跑對齊，畫面會自動對上真的聲音，因為畫面的時間全部寫 cue id，沒有手填秒數。

- 九格圖：`out/sample-ai-news-review.png`
- 每鏡截圖：`out/sample-ai-news/stills/`、總覽 `out/sample-ai-news-overview.png`、封面 `out/sample-ai-news-cover.png`（另有 3:4、1:1 裁切）
- 腳本與分鏡：`script.md`、`storyboard.md`；查證 `research.md`；實測原始回答 `tests/*.json`、整理 `tests.md`

## 畫面是怎麼做的

- 風格：仿介面（`stage: "ui"`），`script.json` 頂層 `uiVersion: 3`。第 3 版是這支片新增的，檔案是 `src/components/ui/UiVideo3.tsx`（畫面）與 `src/components/ui/engine3.ts`（把每鏡的 props 換成絕對幀）。
- 第 1 版（`sample-ai-ui`）與第 2 版（20 秒試片）的畫面沒有動；第 3 版只是從第 2 版借用手繪記號、對照卡、範本卡的畫法（在 `UiVideo2.tsx` 那幾個零件前面加 `export`）。
- 全片切成依序接力的九段，每一段在下一段進來時退場：
  1. 聊天視窗（s01–s04）：第 0 幀實心大字 → 打字（有快慢與停頓）→ 送出 → 真的回答（節錄）→ 紅筆圈 → 蓋章 → 對答案的小卡
  2. 為什麼（s05）：第二次送出的回答（節錄）＋兩個標籤依序亮
  3. 「這樣問」編輯器（s06–s13）：五個欄位逐塊亮 → 送出 → 結果卡一行一行長出來（打勾、亮起、底線）
  4. 上下並排對照（s14）：兩個回答同時停在畫面上，落定後至少 1.5 秒才換下一段（`holdSec`，配音比較短時自動往後讓）
  5. AI 也會錯的那一行（s15）：黃色框＋說明卡
  6. 提醒卡（s16）
  7. 範本卡＋提問（s17–s18）
  8. 下一集預告（s19）
  9. 片尾卡（end，無聲）
- 開頭（評審後改）：第 0 幀就是後果「問 AI 物價／給我兩年前的」，下面一列數字 1.69%、今年 2.33%；0.3 秒內把 1.69% 劃掉並蓋章「2024 年的」。s02 開口時大標換成「Gemini 實測／只打一句話」（`hook.nums`、`hook2`）。
- s05 的第 2 次回答縮成上面一張小卡（一行節錄＋標籤「第 2 次，還是 2024 年」，`reply2.compact`），兩個原因放大。
- 紅筆圈只用一次（s03 的 1.69%，s14 對照卡裡是同一個圈的靜態重現）、打勾只用一次（s11，s14 同樣是靜態重現）。
- 畫面上的 AI 回答都是 `tests/*.json` 裡的原文，只刪節不改字，並標「Gemini 實測・2026/11/13（節錄）」。介面、游標、頭像、圖示都是自己畫的，沒有商標、截圖、真人，也沒有 AI 標示。

## 明天配音與重新對齊（照順序跑）

配音會花 1 次 TTS 請求。音色 Sulafat 在這個頻道的聊天口氣還沒有給使用者試聽過；依專案的試聽規則，要先由使用者在網頁版試聽並同意，才跑第 2 步。

```bash
cd /home/user/AI-Mp4
TZ=Asia/Taipei date                                           # 停工線檢查
node scripts/validate.mjs sample-ai-news                      # 1. 要 0 error
NODE_USE_ENV_PROXY=1 node scripts/tts-take.mjs sample-ai-news # 2. 整篇配音（1 次 TTS 請求）
NODE_USE_ENV_PROXY=1 node scripts/align.mjs sample-ai-news    # 3. 強制對齊，整份覆蓋估算的 timeline.json
node scripts/validate.mjs sample-ai-news                      # 4. 檢查每個 cue 都對到時間
df -h /                                                       # 可用不到 700MB 先清 out/sample-ai-news/ 的中間檔
flock /tmp/aimp4-render.lock node scripts/still.mjs sample-ai-news    # 5. 每鏡截圖，逐張看
flock /tmp/aimp4-render.lock node scripts/render.mjs sample-ai-news   # 6. 成片＋混音＋字幕檔＋storyboard.json
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height,r_frame_rate out/sample-ai-news.mp4
python3 scripts/ui/review9.py sample-ai-news 14,s03:old+14,s04:now+16,s10:me+14,s13:none+14,s14:ask+10,s15:view+16,s18:which+12,end:start+60   # 7. 重做九格圖
```

- 第 3 步**不要帶 `ALIGN_GAP_MAX`**：這支片的旁白設定是親和專業（`delivery: "warm-pro"`），句間停頓不壓成等距；要趕時間就刪字。
- 只想重出無聲版（改了稿子但還沒配音）：`node scripts/ui/silent-timeline.mjs sample-ai-news`，再跑第 5、6 步。已經有真的配音時間軸時它不會覆蓋。
- 看指定時刻：`flock /tmp/aimp4-render.lock node scripts/v3/peek.mjs sample-ai-news <out.png> s14:same+10,s15:view+12,1700`
- 配音後要人耳確認：s16 句尾的「喔」（全片唯一的語助詞）有沒有拖長；整體會不會太平、像朗讀；「Gemini」的念法；1.69%、2.33% 的念法；s04、s14、s17 後面的停頓。
