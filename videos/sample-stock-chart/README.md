# sample-stock-chart（股票頻道風格試片：資料圖表主導）

這是一支 13.5 秒的風格試片，不是完整影片（沒有片尾卡，也沒有完整的起承轉合）。用途是讓你比較四種風格。

| 項目 | 內容 |
|---|---|
| 成片 | `out/sample-stock-chart.mp4`（1080×1920、30fps、H.264，13.5 秒、406 幀） |
| 截圖 | `out/sample-stock-chart-overview.png`（每幕一張）、`out/sample-stock-chart-cover.png`（封面） |
| 人聲 | `out/sample-stock-chart/voice-final.wav`（成片用的人聲軌，−16 LUFS） |
| 題目 | 台股每一萬點走多久？ |
| 旁白（63 字） | 台股從一萬點漲到兩萬點，花了快 35 年。兩萬到三萬呢？一年九個月。三萬到四萬，只用了 119 天。不過同樣是一萬點，漲幅從一倍，縮到三分之一。 |

## 風格說明

- 整個畫面從頭到尾是同一張圖表，不換場：上面是圖表標題和一個大讀數，中間是階梯圖，下面是三條長條。
- 會動的都是「圖表在動」：階梯線跟著旁白往右畫、線頭帶著年份走、讀數跟著線數上去、念到的關卡那條線變成琥珀色虛線、時間軸從 40 年放大到 3 年、長條長出來、最後長條從「花的時間」變成「漲幅」。
- 深色看盤底、細格線、等寬數字；紅色代表上漲（台股習慣），琥珀色是讀數與時間。和紙拼貼的差別：沒有紙紋、照片、膠帶，也沒有卡片與圖示。
- 沒有任何真實商標或真人。頁首的三根長條是自己畫的。

## 為什麼畫階梯、不畫走勢線

這個環境連不到證交所，歷年收盤只查得到少數幾年，湊不出一條可靠的走勢線。所以只畫查證過的四個點：收盤第一次站上 1 萬、2 萬、3 萬、4 萬點的日期。畫面上有一行小字註明「階梯＝收盤首次站上的整數關卡，不是每日走勢」。正式片如果要畫真的走勢，要先拿到完整的收盤資料。

## 怎麼做的

- script.json 頂層寫 `styleVersion: 3` 加 `stage: "chart"`：配音、對齊、時間軸、字幕檔、混音都沿用 v3 的流程，只有畫面換成 `src/components/chartlead/`。不需要跑 `make-paper.py`。
- 資料寫在 script.json 頂層的 `chart.steps`（關卡、日期、當天收盤）。每一段花幾天、幾年幾個月、漲幅幾 %，都是程式從這四筆算出來的，沒有手填。
- 每幕 `component: "ChartScene"`，props：`view`（時間軸範圍，換了就會縮放）、`leg`（畫第幾段：`drawAt` 開始畫、`targetAt` 目標線亮起、`landAt` 往上跳）、`gain`（最後一幕換成漲幅）。時間都寫 cue id 或 `start｜voice｜end｜exit` 加減幾幀，沒有手填秒數。
- 元件：`engine.ts`（時間與數字的計算）、`ChartVideo.tsx`（圖表本體與封面）、`Tracks.tsx`（頁首、字幕列、出處）。色票與版面在 `src/theme.ts` 的 `THEME_CHARTLEAD`、`LAYOUT_CHARTLEAD`，元件沒有寫死色碼。
- 檢查規則：`scripts/chartlead/validate-chart.mjs`（關卡資料要完整且遞增、每幕要有出處、旁白出現買賣字眼會報錯）。
- 指令（都要包 `flock /tmp/aimp4-render.lock`）：
  - `node scripts/validate.mjs sample-stock-chart`
  - `NODE_USE_ENV_PROXY=1 node scripts/tts-take.mjs sample-stock-chart`（會花 1 次 TTS 額度；音檔已經做好，不要重跑）
  - `ALIGN_GAP_MAX=0.3 node scripts/align.mjs sample-stock-chart`（要帶 `ALIGN_GAP_MAX=0.3`，句間停頓才不會被放寬到 0.8 秒）
  - `node scripts/still.mjs sample-stock-chart`、`node scripts/render.mjs sample-stock-chart`
  - 看指定時刻：`node scripts/v3/peek.mjs sample-stock-chart <out.png> 0,50,125,...`

## 配音

- 音色 Sulafat（女）、`gemini-2.5-flash-preview-tts`、`cmn-TW`、整篇一次生成。TTS 請求只送 1 次，成功，沒有重送（紀錄在 `tts-requests.json`）。
- 旁白設定檔在 script.json 的 `voice.profile`：三十歲左右、在財經媒體做圖表的台灣女生，語速目標 4.6–5.0 音節/秒。
- 語速：原始錄音 13.41 秒、62 個音節，約 4.7 音節/秒；成片從開口到收聲約 4.8 音節/秒，在目標範圍內。**沒有做後製加速。** 對齊時把幕與幕之間的停頓上限設為 0.3 秒，實際是 0.27–0.30 秒。
- 捲舌指標（`scripts/voice-retro.py`，量原始錄音）：ㄗㄘㄙ 與 ㄓㄔㄕ 的擦音重心差 2.2 kHz（樣本 8 個和 7 個字，剛好在可靠門檻邊緣）。參考：love-stats 2.9、被聽成中國口音的 stock-jensen 4.4。
- 對齊信心：整篇 0.62；s1 0.69、s2 0.72、s3 0.49、s4 0.74。s3 低於 0.5，原因是「一百一十九」五個字的分數是 0。
- 聽寫（文字模型，不花 TTS 額度）結果：「……兩萬到三萬呢，一年**六**個月，三萬到四萬只用了 119 天。不過同樣是一萬點，漲幅從一倍縮到三分之一。」提示沒有被念出來，沒有漏句。**「九個月」被聽寫成「六個月」，不確定是配音念錯還是聽寫聽錯，要用耳朵確認。**

## 渲染

- 全片渲染 24 秒（406 幀、每幀 60 毫秒、concurrency 4），加上打包與混音共 51 秒。每幕截圖加封面 37 秒。
- 混音：背景音樂加 1 個轉場音效（最後一幕開頭），整體 −14.4 LUFS。
- 覆蓋率檢查（v3 門檻）沒有警告：佔用率最低 48%，最長空白帶 98px。沒有黑幀。

## 已知問題

1. 「一年九個月」可能被念成「一年六個月」（見上面聽寫結果）。如果真的念錯，只能整篇重配，會再花 1 次額度。
2. 畫的是階梯，不是真的走勢線（原因見上）。圖上的漲幅是用整數關卡算的（+100%、+50%、+33%）；用當天實際收盤算是 +99.9%、+49.0%、+35.2%。
3. 出處是媒體引述金管會與證交所的數字，沒有親眼看到證交所原始資料。
4. 5 萬點：截至 2026/11/13 沒有查到收盤站上的報導（最新查到 10/6 收 49,822.55），10/7 之後的走勢沒查到，所以片子不提。上片當天要重查。
5. 圖表只佔畫面的 330–1250，字偏小的地方：圖下方的註記（24px）、長條的單位字。正式片可以把圖再放大。
6. 時間軸放大的那一瞬間，2024/3/21 的日期標籤會從圓點左上換到右下（放大後左邊放不下）。
7. 這個風格目前只有「階梯圖＋長條」一種圖。做正式片要再補：真正的折線、多條線比較、片尾卡。
8. selfcheck、audit 沒有跑（門檻是照 v2／v3 紙拼貼訂的）。
9. 專案規範的停工線是台灣時間 07:00；這支是下午 16:35–16:50 做的，因為這次是明確要求現在做。
