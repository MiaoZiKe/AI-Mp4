# tech-precursor 視覺規格（模組清單見 physics-spec.md 第 1 節）
模組（皆在 gen-model.mjs，每項 ≥4 細節）：氣櫃（前門窗框、把手、鉸鍊、警示標籤、緊急鈕、狀態燈、排氣口與風量指示、漏氣偵測、貫穿板）｜起泡器容器（法蘭螺栓、焊縫、銘牌、警示標籤、液位計）｜液體與液面｜頂蓋與進出氣閥（氣動致動器、手輪、LED、氣管、VCR 接頭）｜插管與燒結頭（孔）｜加熱套（綁帶、控溫盒、探棒）｜減壓閥與雙壓力錶｜流量控制（接頭、纜線、銘牌、LED、感測管）與濾器｜加熱管路（細管、三段保溫套、加熱帶、熱電偶、管夾）｜閥箱（外框、通風槽、銘牌）｜閥塊底座（閥座環、流道、加熱棒）｜隔膜與彈簧｜閥塊上層（三閥、致動器、LED）｜腔體入口（玻璃筒、法蘭螺栓、進氣頭、吸盤、晶圓、抽氣口、泵）｜固體安瓿（托盤四層、粉粒、蓋與閥）｜加熱與未加熱對照管（玻璃管、加熱帶、凝結物三階段）｜晶圓表面分子（八個位置：羥基、鋁、甲基、薄片、雜質）。
