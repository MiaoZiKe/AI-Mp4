# tech-waferflow 設備與運作（每一步實際怎麼動）

站別：W 晶圓 x=0｜S 晶圓剖面方塊（x=60，寬 11.8、深 5、基板 1.4；層：基板→氧化層 .35→金屬 .3→光阻 .4；7 條線＋6 個縫，線寬 1.0、縫寬 .8）｜C CMP 研磨機 x=120｜K 疊層 x=180（12 層，奇偶層走線方向垂直）。

| 步驟 | 零件與動作 | 對旁白 |
|---|---|---|
| 沉積 | 蓮蓬頭（27 根噴嘴）往下噴氣體粒子：先藍色氧化物粒子，氧化層落下貼上；再橘色金屬粒子，金屬層落下 | 沉積／氧化層／一層金屬 |
| 塗光阻 | 噴嘴滴紫色光阻，轉盤標記轉動，光阻層落下；接著四層爆炸拉開並標名，再合回 | 塗上光阻／像底片 |
| 曝光 | 燈箱＋聚光鏡＋光罩（鉻塊對著線、縫透光）＋三圈鏡頭；黃色光點穿過光罩縫隙打到光阻縫，縫處發亮 | 用光／光罩／印進去／曝光 |
| 顯影 | 噴桿（13 噴嘴）噴藍色藥水，藥水桶；光阻縫被洗掉，金屬露出 | 顯影藥水／洗掉／露出來 |
| 蝕刻 | 上電極＋射頻線＋電漿（紫色閃動）；離子往下打，縫處金屬被刻掉，線上光阻擋住離子 | 沒有保護／電漿／刻掉 |
| 去光阻 | 噴桿噴橘色藥水（紅桶），光阻線被洗掉 | 沒用了／洗掉／一層完成 |
| 離子佈植 | 離子源→加速管→磁鐵→掃描板，紫色離子往下打，縫處打進矽，綠色摻雜區亮起 | 打進離子 |
| 研磨 | 轉盤＋研磨墊（同心溝槽，轉動）、研磨頭夾晶圓（自轉）、研磨液滴下、鑽石修整碟來回掃；2D 剖面顯示凹凸氧化層被磨平 | 研磨磨平／下一層 |
| 重複 | 12 層依序落下疊起，右側計數 1→12，再標「上百道光罩層（產業估計）」 | 一輪／重複／上百次 |
| 公司 | 引線指到：曝光機鏡頭、蝕刻腔上電極、光罩盒、去光阻噴桿、鑽石修整碟 | 艾司摩爾…中砂 |
