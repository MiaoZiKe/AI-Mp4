# tech-mature 構造與物理（示意）
- 垂直溝槽功率 MOSFET：由下到上 汲極金屬｜N+ 基板｜N− 漂移層（厚，承受高電壓）｜P 本體｜N+ 源極｜源極金屬；溝槽閘極＝多晶矽外包閘極氧化層，切穿 P 本體到漂移層。閘極加正電壓時，P 本體貼著溝槽側壁反轉成 N 型通道，電流（傳統方向）由汲極往上經漂移層、通道到源極。關掉時通道消失，漂移層擋住電壓（水龍頭關）。不標電壓、比例不準。
- 電源管理 IC（降壓轉換）：開關＋電感＋電容把電池電壓轉成各負載要的電壓，分給處理器、記憶體、螢幕（配電盤）。畫面只畫電流分路方向。
- 顯示驅動 IC：玻璃上晶片（COG），以凸塊接到面板走線；逐列掃描、每一行送亮度資料，所以像素一列列點亮。
- 晶圓尺寸：8 吋＝200 mm、12 吋＝300 mm（比例 2:3 照做）；缺口（notch）朝前。
- 電動車逆變器：功率模組把電池直流電切成交流電送馬達；AI 伺服器電源供應器把電分給每台伺服器。都是示意。
