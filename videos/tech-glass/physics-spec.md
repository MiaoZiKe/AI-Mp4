# tech-glass 物理與構造規格（3-10 玻璃基板）
全部是示意，不標厚度、孔徑、溫度、角度；數字只用念稿的兩個（英特爾說的「十倍」、分析預期的「最快 2027」）。

## 載板構造（s1–s2，站 K）
- 由下而上：錫球 → 底阻焊 → 下增層 4 層（絕緣膜＋銅線＋微孔）→ **芯板** → 上增層 4 層 → 頂阻焊＋焊墊＋加強環 → 晶片（中介層、運算晶片、四疊記憶體、底部填膠、凸塊）。
- 樹脂芯板＝玻纖布泡樹脂、兩面銅箔、鍍通孔；玻璃芯板＝一片玻璃、兩面銅、玻璃穿孔（TGV，銅柱）。玻璃基板只換芯板，上下增層照疊（Intel 2023/9/18 新聞稿）。
- 訊號只走銅：晶片凸塊 → 上增層微孔 → 芯板鍍通孔 → 下增層微孔 → 錫球。
- 換芯板動作：上增層＋晶片往上、下增層＋錫球往下分開 → 樹脂芯板往左抽走 → 玻璃芯板從右滑進同一格 → 合回。

## 受熱變形（s3–s4，站 W）
- 加熱台加熱（發熱條發光、熱點往上）。樹脂芯板試片兩端往上翹（示意，誇大）；換大晶片後翹更多（念稿「晶片越大越翹」）。
- 玻璃芯板試片保持平，平直尺貼平；上面的線更細更密、有穿孔銅柱。
- 方向：熱脹冷縮不一致造成翹曲，晶片面積越大，兩端位移越大（通則，不標數值）。「十倍」只寫成「英特爾說」（公司自己的宣稱）。

## 玻璃穿孔（s5，站 T）
- 主流做法 LIDE／SLE（LPKF；MDPI Micromachines 14(9) 1766）：① 超短脈衝雷射沿厚度方向改質（一排排掃）② 泡蝕刻液，改質處蝕刻較快 → 開孔 ③ 種子層＋電鍍銅填孔，上下銅墊接通（訊號從上面銅墊經孔到下面）。
- 對照：機械鑽頭直接鑽玻璃 → 孔邊裂紋、碎屑往外噴、小片裂成兩半（玻璃脆；通則，不標數字）。
