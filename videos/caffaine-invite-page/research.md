# caffaine-invite-page 查證（2026/11/17）

主旨（一句）：一句話做出能倒數、能回覆的邀請網頁；但預填名單與回覆沒存的毛病要叫它修，而且回覆只存在各自的手機。

## 實測做法（原文在 tests/，不改字）
- 工具：Gemini API（沒有開搜尋與程式執行），模型 **gemini-3.5-flash-lite**。原因：慣用的 gemini-3.5-flash（modelVersion gemini-3.6-flash）當天免費額度（20 次／天）已用完，回 429；改用同樣能用的 flash-lite，三支都用同一個模型。畫面與念稿一律標「Gemini 實測」，不講成 3.6 flash。
- 流程：tests/01-first.json（2026-11-17，Gemini API 單檔 HTML；主角小美、示範小館皆虛構，日期 12/19 週六）→ tests/play.py（Playwright 手機 390×844 觸控）→ 翻車 → tests/02-fix.json（多輪）→ play.py 驗證。舊的 12/20 版（我把週六寫錯日期，實際 2026/12/20 是週日）已棄用，留在 tests-old-1220/，不用於影片。
- 瀏覽器：Playwright 無頭 Chromium，視窗 390×844、觸控、`is_mobile`。

## 數字／事實
1. 倒數：頁面顯示 32 天 22 小時（2026/11/16 19:39 UTC 到 12/19 18:00），與日期差相符（tests/01-first-result.json）
2. 互動：點「我會去／可能去／去不了」→彈窗填名字→送出，名單新增（送出 3 筆後 5 人）
3. 翻車（實測）：一打開名單已有 2 人（程式碼 guests 陣列預填「小強」「美美」，不是我輸入的）；重新整理後我送的 3 筆全沒了，只剩那 2 人
4. 修好（1 次）：名單一開始 0 人；送 3 筆、重新整理後仍 3 人（tests/02-fix-result.json）
5. 限制（程式用瀏覽器儲存，只存在各人自己的瀏覽器）：朋友從自己的手機打開看不到你這支的回覆；要收所有人的回覆需要另外接收資料的地方，這次沒做、沒測

## 還不知道（片中要講）

## 不寫
