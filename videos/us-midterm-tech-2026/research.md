| 期中選舉（midterm） | 美國總統任期中間那一年的國會改選，等於對執政黨的「期中考」。 |
| 跛腳鴨國會（lame duck） | 選完到新國會就任前（2026/11–2027/1/3）仍在開會的舊國會，權力即將交接、但還能立法。 |
| 分裂政府（divided government） | 白宮和國會由不同政黨掌控，法案要兩邊都點頭才過得了。 |
| 否決權與三分之二 | 總統可以否決國會法案；國會要硬推翻，兩院都要三分之二同意，民主黨這次沒到。 |
| 第 120 屆國會 | 2027/1/3 就任的新一屆國會，民主黨籍主席從那天起才接掌各委員會。 |
| 委員會主席 | 國會裡各領域的「關主」，決定哪個法案排審、找誰來聽證。 |
| 聽證會／傳票（subpoena） | 國會把企業高層叫來公開問話；傳票是「不來不行」的法律文件。 |
| 凌駕州法／優先權（preemption） | 聯邦訂一套法，直接取代各州自己的法；AI 業者想要它，州政府不想。 |
| 「地板」vs「天花板」 | 聯邦規範是最低標準（地板，各州可以更嚴）還是最高標準（天花板，各州不能更嚴）。 |
| 州法拼貼（patchwork） | 50 個州各訂各的 AI 規則，企業要一州一州對。 |
| 行政命令（executive order） | 總統不經國會直接下的命令，能指揮聯邦機關，但不能直接廢掉州法。 |
| 前沿 AI（frontier AI） | 最頂尖、算力最大的那批 AI 模型，像 GPT、Claude、Gemini 這個等級。 |
| 自動化決策技術（ADMT） | 用 AI 自動幫人做決定（像審貸款、篩履歷）的技術，科羅拉多新法管的就是這個。 |
| 超級政治行動委員會（super PAC） | 可以無上限募款、幫候選人打廣告的政治募款組織，但不能直接把錢給候選人。 |
| 資料中心（data center） | 放滿伺服器、跑 AI 的大型機房，非常吃電吃水。 |
| 暫停令（moratorium） | 暫時停止核發新許可，等規則訂好再說。 |
| 地方公投案（ballot measure） | 選票上讓居民直接對某件地方議題投 Yes／No。 |
| 超大規模業者（hyperscaler） | 蓋全球最大雲端機房的那幾家，像微軟、亞馬遜、Google、Meta。 |
| 新雲（neocloud） | 專門出租 AI 算力的新興雲端公司，像 CoreWeave、Nebius。 |
| 232 關稅 | 美國《貿易擴張法》第 232 條，總統以「國家安全」為理由自己決定課關稅，不用問國會。 |
| 出口管制／BIS | 商務部工業與安全局（BIS）決定哪些高階晶片不能賣給中國。 |
| 遠端存取漏洞 | 中國公司不買晶片、改透過海外機房「遠端租用」算力，繞過出口管制。 |
| 48D 稅額抵減 | 在美國蓋晶片廠可以抵掉 35% 投資額的稅，但要在 2026 年底前開工。 |
| NDAA（國防授權法） | 每年一定會過的國防大法，常被用來夾帶晶片、AI 等條文。 |
| Cloture／60 票門檻 | 參院要先 60 票同意「停止辯論」才能真正表決，所以多數黨 54 席也不夠。 |
| 市場結構法案（CLARITY Act） | 規定加密貨幣由 SEC 還是 CFTC 來管、怎麼管的法案。 |
| SEC／CFTC | 證券交易委員會管「證券」，商品期貨交易委員會管「商品」；加密貨幣算哪邊是爭點。 |
| 穩定幣收益 | 穩定幣發行商能不能像銀行一樣付利息給持有人。 |
| 反壟斷（antitrust） | 政府告公司「獨大到傷害競爭」，最重可以要求拆分公司。 |
| 結構性拆分 vs 行為補救 | 一個是逼你賣掉部門，一個是不拆但規定你以後怎麼做生意；Google 兩案都只拿到後者。 |
| H-1B | 美國給外國專業人才（很多是工程師）的工作簽證。 |
| 撥款／臨時撥款（CR） | 國會每年要通過預算給政府花；來不及就先用短期延長案（CR）撐著，過期就停擺。 |
| 債務上限（debt ceiling） | 美國政府能借錢的法定上限，到頂又不調高就可能違約。 |
| NSF／NASA／DOE 科學辦公室 | 美國三大科研資金來源：國家科學基金會、太空總署、能源部科學辦公室。 |
| 排序複選制（ranked-choice） | 阿拉斯加的投票法：選民排序候選人，沒人過半就淘汰最低票重新分配，所以算很久。 |
| 費城半導體指數（費半） | 追蹤美國主要半導體公司股價的指數，台股 AI 鏈常跟著它走。 |
| ADR | 台積電等外國公司在美國掛牌交易的「存託憑證」，等於在美股買台積電。 |
| 外資賣超 | 外國機構投資人當天賣的比買的多，數字越大賣壓越重。 |
| 跌停 | 台股單日最多跌 10%，跌到底就叫跌停。 |
| 修正區間（correction） | 指數從高點回落超過 10%。 |
| 台美投資備忘錄 | 2026/1 台美簽的協議：台灣承諾投資美國 2,500 億美元，美方部分 232 關稅上限訂 15%。 |
