# tech-deposition 念稿與自檢

**主旨一句話**：薄膜是用氣體在晶圓表面「長」上去的——CVD 靠反應、濺鍍靠撞靶、ALD 一次一層原子，先進製程因溝槽又深又窄而靠 ALD。

| 自檢 8 項 | 過／不過 | 理由 |
|---|---|---|
| 1 先情境再反常事實 | 過 | 開頭「一層膜只有幾個原子那麼薄，怎麼長上去」＝反差事實＋本片要回答的問題 |
| 2 數字／事實量 | 過 | 全片無具體數字（只有「幾個原子」「一圈一層」） |
| 3 每句開頭回答上一句 | 過 | 蝕刻挖溝槽→所以要鋪回去→反應腔→氣體進出→做法不只一種→另一種→但深窄鋪不均→所以改用 ALD |
| 4 術語先白話 | 過 | 噴氣頭、加熱座、靶材第一次出現時畫面同步標名並用口語帶過 |
| 5 代名詞有前文 | 過 | 「這兩種」前文剛講完 CVD 與濺鍍 |
| 6 寧砍事實不加速 | 過 | 念稿約 280 字（不含標點） |
| 7 結尾一個動作＋同一條線 | 過 | 長完凹凸不平→所以下一支化學機械研磨；留言「沉積」 |
| 8 只聽旁白能講回主旨 | 過 | 旁白本身有完整因果鏈 |

## 念稿
- s1：晶片裡有一層膜，只有幾個原子那麼薄。它是怎麼長上去的？
- s2：蝕刻挖出溝槽後，要把材料鋪回去，這叫薄膜沉積，在反應腔裡進行。
- s3：噴氣頭灑下氣體，晶圓躺在加熱座上，用過的氣體從底下抽走。
- s4：做法不只一種，最常見的是化學氣相沉積，氣體碰到熱晶圓起反應，固體留下長成膜。
- s5：另一種是濺鍍，離子撞向金屬靶材，打出的原子落到晶圓上。
- s6：但溝槽又深又窄，這兩種不容易鋪均勻，所以先進製程改用原子層沉積。
- s7：兩種氣體輪流進來，第一種貼滿一層，多的吹掉，第二種再反應，一圈只長一層原子。
- s8：機台有應用材料、科林研發、東京威力科創、ASM。台灣光洋科做靶材，京鼎供應應用材料設備。
- s9：所以這層膜，是氣體一層層長的。但長完會凹凸不平，所以下一支，看化學機械研磨，磨到比鏡子還平。留言沉積，看完整解說。
