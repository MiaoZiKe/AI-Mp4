# CaffAIne 頻道主題方向分析（2026/11/16）

依據：使用者 2026/11/16 提供的 IG AI 類影片數據（收集日 2026-11-16，範圍 2026-09-17～11-16）。原話：「影片換主題，我覺得主題還是太差了，以下內容給以參考」。
本文只用這份數據推論；沒有的數字照實寫「無」，假設會標【假設】。

## 結論先講

- **推薦定位：「不會寫程式，也能用 AI 做出來」**——每支片做出一個看得到的東西，教一般人照著做，並把「做得像專業的（去 AI 味）」和「AI 為什麼會這樣（原理動畫）」當成固定支柱。
- 依據：收藏／讚比例最高的三支都是「不會寫程式也能做出作品」（webbyvaris 手繪變遊戲 0.88、OpenMontage 實測 0.85、asksui Claude＋Remotion 做動畫 0.72）；小帳號爆紅倍數最高的也是這類（asksui 6.4 萬觀看／1,592 粉＝約 40 倍；ai_bytes.lab 8.1 萬／1,711 粉＝約 47 倍）。
- **我們的差異化**：CaffAIne 的每支片本身就是「用 Claude＋Remotion 做的動畫」——正好是 asksui 那支 6.4 萬觀看的題目，我們可以拿自己真實的製作流程當素材，別人只能截圖。
- 已做好的「會議紀錄」「比價」兩支先不發，改編進新支柱（見第五節第 5、17 題）。

## 七、兩種腳本結構（30～60 秒）

**結構一：做出一個東西（P1／P2，約 40～50 秒）**

| 秒數 | 段落 | 內容 |
|---|---|---|
| 0～3 | 鉤子 | 成品先給看＋一句「我沒寫一行程式」或反差 |
| 3～10 | 情境 | 誰會需要、原本要花多久 |
| 10～30 | 步驟 | 3～5 步，每步一個畫面（實測畫面、提示詞原文） |
| 30～38 | 翻車與修正 | 實測中真的出錯的地方＋怎麼修 |
| 38～45 | 收尾 | 一句結論＋留言關鍵字拿提示詞 |
| 45～48 | 片尾 | 純白景深 LOGO 頁＋招牌音 |

**結構二：AI 為什麼會這樣（P3，約 30～40 秒）**

| 秒數 | 段落 | 內容 |
|---|---|---|
| 0～3 | 鉤子 | 日常場景＋反常事實＋懸念（「同一句話問兩次，答案不一樣」） |
| 3～12 | 現象 | 實測給觀眾看到現象 |
| 12～25 | 原理 | 一個比喻＋一張會動的示意圖（不講公式） |
| 25～32 | 所以呢 | 這對你有什麼影響、怎麼避開 |
| 32～35 | 收尾 | 一個問題或留言關鍵字（擇一） |
| 35～38 | 片尾 | LOGO 頁 |

兩種都照 `ai-daily-playbook.md` 第十、十三節：先寫一句主旨、開頭有情境、事實 ≤4、句子接得起來、只聽聲音能懂。
