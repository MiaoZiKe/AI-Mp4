# 科技片範例庫與每支復盤（2026/11/20 使用者要求）

使用者原話：「內容、素材、場景、背景、運作行為、對應內容的物理變化等細緻度，需要多花時間鑽研，並且讓下次有範例參考以提升製作影片效率，每次製作都需要優化更好方法，讓下次影片製作品質更好、更快、更完整。」

## 怎麼用
1. 開工前先讀這份，找有沒有做過的物件、場景、運作動畫，直接沿用該檔的寫法再加細節，不從零開始。
2. 做完一支，在下面「範例表」補上這支新增或做得最好的項目（指到檔案與成片秒數），並在「每支復盤」加一段。沒補就不算交件。
3. 範例只收「使用者核准過的成片」裡的畫面；被退回的寫進「踩過的坑」。

## 腳本安排（每支都要）
- 鉤子用試問法：第 0 幀就是一個觀眾會想知道答案的問題或反差（例：「一櫃 120 千瓦，風扇吹得走嗎？」），加一個數字與一個已經在動的東西；先給結果或衝突，再拆開。
- 每段之間講因果（因為／所以／但是），結尾用因果接下一支。
- 一句旁白對一個畫面動作；公司只列有來源的，用引線指到部位；不寫投資建議。

## 細緻度六個面向（開工在 visual-spec.md 逐項寫，審片逐項對）
| 面向 | 要寫清楚什麼 |
|---|---|
| 內容 | 每句旁白要讓觀眾看到什麼證據（數字、剖面、對照） |
| 素材 | 物件清單＋每個物件的最低細節＋實物參考 |
| 場景 | 物件放在哪個真實環境（機櫃在機房、機台在無塵室），不要懸在空白裡 |
| 背景 | 背景有層次與相關元素（管線、地板、鄰近設備），不搶主體 |
| 運作行為 | 每個會動的東西怎麼動（加減速、順序、誰帶動誰） |
| 物理變化 | 內容講到的變化要畫出來（變熱→變色、被磨→變平、通電→亮、流過→溫度漸層），流動物依物理種類換形狀 |

## 踩過的坑（不要再犯）
- 說明卡空白／淡到看不清／只剩條紋方塊（11/18 五支 v1 全退）。
- 流動物路徑中心放錯，整排光點懸在半空（tech-server v4 0:54）。
- 晶片畫成四個色塊（tech-icdesign v3 以前）。
- 為了壓秒數剪掉整句，因果斷掉（tech-etch v1）。
- 字幕把兩句黏成一行造成誤讀（「ASM台灣光洋科」）；用語讓人誤會（「台積電從先進做到成熟」）。
- 蓋章壓到卡片標題（tech-icdesign v2）。
- 「矽」念錯：念稿版一律寫「夕」。
