# 哩股哩股頻道規則（追問式短片）

來源：使用者 2026/11/14 的要求——「哩股哩股題目應該是更國際觀，例如最近黃仁勳發生的事情，且不能單純介紹，一開始前 3 秒需要抓住目光，除了介紹，我們還需要更進一步探討為何會這樣，是否存在陰謀？事情這樣合理嗎？」「聲音我不喜歡，需要男生旁白，且專業的介紹，帶點揭發以及解惑大家不知道的感覺」。
照這份做的第一支：`videos/liguligu-jensen/`（約 26 秒，無聲版，等男聲選定後配音）。舊的 `videos/liguligu-cpi/`（AI 實測物價）是改規則之前做的，題材與聲音都不再是這個頻道的方向。

## 1. 題材

1. 國際情勢、國際大公司與市場、基金。台灣觀眾會在新聞上看到、但沒人把來龍去脈講清楚的事。
2. 要有一個「不對勁的地方」才做：官方說法和報導對不上、時間點太巧、數字前後不一、該說的沒說。只有「發生了一件事」而沒有疑點的題目，不做。
3. 避開：只有單一來源的爆料、純八卦、個股該不該買。

## 2. 結構：不是介紹，是追問

| 段落 | 做什麼 | 規則 |
|---|---|---|
| 1 鉤子（前 3 秒） | 丟出一個反常的事實或疑點 | 第 0 幀就是實心大字加數字或反差；1 秒內有一個蓋章、撕紙或紅筆圈的動作；3 秒內 ≥4 個事件。鉤子必須是已確定的事實，不能拿推測當鉤子 |
| 2 發生了什麼 | 只講已確定的 | 官方文件、本人承認的話、收盤價這一類。一兩句就好 |
| 3 哪裡不合理 | 把疑點畫出來 | 時間線上的缺口、公告裡的空白用紅筆圈、兩種說法左右並排。每個疑點要附「為什麼這算不合理」 |
| 4 外界怎麼懷疑 | 把流傳的說法講出來 | 用問句或「有人懷疑是…」；講清楚是誰說的 |
| 5 逐一查證 | 每個說法給一個狀態 | 有證據／只是推測／查不到。畫面用打勾、問號、叉叉或狀態章 |
| 6 目前最合理的解釋與還不知道的事 | 收斂 | 可以說「目前最說得通的是…」，同時講清楚哪幾件事還不知道 |
| 7 提問＋下一集 | 一個具體的二選一問題，加下一集要查什麼 | 下一集的題目要是已經有報導的事，不預告沒查過的東西 |

長度：短片 20–26 秒、旁白 90–115 字、6–8 鏡；正式長片 45–75 秒照紙拼貼規範。短片沒有片尾卡，`npm run validate` 會留一個「最後一幕必須是 EndCard」的 error 和總長的警告，這是規則對短片的限制，照實寫在該片說明裡，不為了過關硬加片尾卡。

## 3. 事實紀律（硬規則）

1. **可以提問，不可以下沒有證據的結論。** 「這合理嗎？」「有人懷疑是…」可以；「其實是某某設的局」不行，除非有文件或當事人承認。
2. 每個說法在 `research.md` 與畫面上都要有狀態，四選一：
   - **已確定**：官方文件、公告、本人公開承認、交易所收盤價。
   - **媒體報導（誰報的）**：要寫出是哪一家；引述匿名消息來源的要寫「引述知情人士」；公司有沒有證實也要寫。
   - **分析推測**：分析師、評論者或網友的解讀。
   - **查不到（截至 YYYY/M/D）**：找過了，沒有證據。查不到不等於是假的，旁白不說「是假的」，除非有查核機構明確查證過那一則內容。
3. 「有人樂見」不等於「有人策劃」。動機、時間點巧合都不是證據，旁白要講出這個差別。
4. 涉及真實人物的私事：只寫本人承認或官方文件有的部分；不提第三人姓名；不描述細節；不用「偷吃被抓」「間諜情婦」這類定罪式或羞辱式用語；不評價人品。和主題無關的私事不寫。
5. 沒有逐字讀過原文的來源，要在 `research.md` 註明「只看到摘要或轉述」；涉及指控的內容，上片前要有人讀過原文。
6. 時事題材上片當天重查，畫面常駐「查證截至 YYYY/M/D」。
7. 不給投資建議：不說該買該賣、不預測股價；提到市場只講已經發生的收盤數字，或「分析師說…」。
8. 不出現真人肖像，也不用會讓人聯想到本人的替代物（招牌穿著、剪影）；不出現商標，公司名只用文字。照片只當情境，圖說標「示意」。
9. 政治立場中立：講到政府、政黨、派系時，只轉述報導的內容與出處，不加形容詞。

10. **相關公司（使用者 2026/11/16**：「後續這些題材，有跟股票公司有關的 麻煩補充上去，觀眾會想知道是哪些公司」；從下一支起，現有片不改）：題材只要跟上市公司有關，就寫出是哪些公司＝公司名＋股票代號（例：輝達 NVDA、台積電 2330），最多 3 家，放畫面「相關公司」卡或旁白帶一句。只列查證過、確實跟這件事有關的公司，每家附出處與狀態標籤（公司公告／媒體報導（誰報的））。只寫「跟這件事有關」，不寫買賣、目標價、漲跌預測，不用「受惠股」「概念股」；畫面角落固定放「非投資建議」。文章 JSON 加一段「相關公司」：名稱、代號、跟這件事的關係、出處。公司卡算寫稿八條裡的 1 個事實（30 秒事實 ≤4 不變），不能因此塞爆。

## 4. 口吻

> 2026/11/15 更新：旁白改用 API 生成（使用者同意），取代「使用者手動錄音、不呼叫 API」；音色待使用者選定（`docs/prompts/liguligu-API配音前選音色.txt`），流程見 `liguligu-daily-playbook.md` 第零節第 6 步。


- 冷靜、有把握，像「我幫你把沒人講清楚的地方查出來」。揭露感來自**具體的對照**（四天前說 A、四天後做 B；文件寫 X、報導說 Y），不是來自語氣。
- 不聳動、不喊口號：不用「驚爆」「內幕」「真相只有一個」「你絕對想不到」「細思極恐」。不用連續反問堆情緒。
- 句子短，一句一件事。結論句乾脆（「但樂見，不等於設局。」）。語助詞很少，全片最多一個。
- 旁白設定檔：`scripts/voice-profiles.json` 的 `liguligu`（男聲；跑國際財經線多年的記者，下班後把查到的東西講給信得過的朋友聽；`delivery: "probe"`＝講到疑點放慢、講到查證結果乾脆；每秒 4.4–4.9 字）。音色等使用者試聽後決定，候選與提示詞在 `docs/prompts/liguligu-男聲試聽.txt`；Iapetus、Achird 已被否決。

## 5. 畫面

- 紙拼貼（`styleVersion: 3`、`skin: "newsprint"`），頻道字 `channel: { name: "哩股哩股", tag: "查到底", slogan: "數字，查過再信" }`。
- 固定手法：時間線（日期籤＋虛線）、兩欄對照（官方文件／媒體報導）、狀態章（綠＝已確定、黃＝媒體報導或公司未證實、紅＝查不到或尚未確定）、紅筆圈空白、問號。
- 字幕以下不留空板：畫面最下方常駐一張「查證截至 YYYY/M/D」紙條（`layer: "screen"`）。
- 每 2–3 秒有事件；頁首（y 220–310）不壓內容，內容從 y 330 開始。

### 5.1 兩種畫面風格（2026/11/14 起）

使用者看完貼紙式的第一支後說「方向正確，但我想要再專業嚴肅點的風格」，所以多做了一種。內容規則（第 1–4、6 節）兩種都一樣，只有畫面不同。對照圖：`out/liguligu-jensen-style-compare.png`。

| | 貼紙式（上面第 5 節） | 檔案室式 |
|---|---|---|
| 開關 | `styleVersion: 3`、`skin: "newsprint"` | `styleVersion: 3`、`stage: "dossier"`（`src/components/dossier/`、`THEME_DOSSIER`／`LAYOUT_DOSSIER`、`scripts/dossier/`） |
| 樣片 | `videos/liguligu-jensen/` | `videos/liguligu-jensen-pro/`（寫法與重做指令在它的 README） |
| 看起來 | 軟木板上的紙片、紅筆圈、狀態章、拍立得；親切、有手感 | 墨藍炭灰底、襯線大標、文件摹本、細紅框與引線、單色狀態小標、黑白照片；冷靜、像調查專題 |
| 動作 | 貼上、砸下、沿虛線移鏡 | 擦入、描線、打字、淡入、慢推 |
| 適合 | 生活感的題目、要讓人覺得「這跟我有關」：物價、薪水、基金費用、懶人包式的來龍去脈；需要很多小東西同時擺在桌上比較時 | 有文件、有時間線、涉及真實人物或公司的指控與查證：高層去職、監管調查、財報疑點、國際制裁；要讓人覺得「這是查過的」、不想被看成八卦時 |
| 不適合 | 嚴肅的指控題材（紅圈、問號容易顯得在起鬨） | 輕鬆題材（會太沉）；一鏡要放超過 3 樣東西時（深色底上擠了會亂） |

檔案室式另外的規定：文件摹本下面一律標「示意，非文件原件」，內文用灰色橫條、不假造文件字句，只寫查證過的那一句；照片圖說一律有「示意」；紅色只給「要你看這裡」與「查不到／尚未確定」，冷色只給「已確定」。

### 5.2 主風格候選：檔案室＋國際新聞（2026/11/14）

使用者看完檔案室式之後說「帶點新聞、國際風格，語速要調整快點」——選了嚴肅這個方向，但要更像國際新聞、節奏更快。照這句話做的版本是 `videos/liguligu-jensen-pro/` 第 2 版（22.7 秒，無聲），**暫定為哩股哩股的主風格候選**，等使用者看過再定案（定案後寫進 `CLAUDE.md`）。

寫法：`styleVersion: 3`、`stage: "dossier"`，再加頂層 `news`（沒有 `news` 就是原本的檔案室式）。

```
"news": { "section": "國際", "sectionEn": "INTERNATIONAL",
  "places": { "ca": { "zh": "加州", "en": "SANTA CLARA", "lon": -121.95, "lat": 37.35 }, "dc": { … } },
  "link": { "from": "ca", "to": "dc", "at": "s03:res+4" } }
每鏡 props.news: { "dateline": "SANTA CLARA, CALIF.・2026/11/12", "place": "ca", "lt": "事件" }
```

固定的七樣東西（細節與座標在該片 README）：

1. 頂部新聞條：紅底頻道字標＋「國際｜INTERNATIONAL」；下面一行電頭（地點・日期），換鏡時重打。
2. 下三分之一標題條放中英字幕，上面一個紅色欄目籤（≤6 個字，說這一鏡在做什麼：事件、兩種說法、外界懷疑、查證、還不知道、提問）。
3. 點陣世界地圖當淡背景，標出事件地點與連線；目前這一鏡的地點有脈衝圈。地圖目前固定看美洲到大西洋，題材在別的地區要改 `LAYOUT_DOSSIER_NEWS` 的 `MAP_LON_C`／`MAP_LAT_REF`。
4. 底部跑馬燈：固定「查證截至 YYYY/M/D」＋全片出處輪播；每鏡自己的出處仍有固定的一行（跑馬燈讀不完整，不能只靠它）。
5. 時間線用新聞時間軸（日期籤＋節點）。
6. 引述媒體用報頭式小標（媒體名＋日期），**只用文字，不畫任何媒體或公司的商標**。
7. 換鏡用橫向擦切（8 幀），新鏡的底圖寫 `start-N` 提早做完，換鏡時畫面不空。

節奏：無聲估算用每秒 5.2 個音節、幕間停 0.12 秒（結論句後可用 `pauseAfter` 0.3）；短片 21–23 秒；每鏡事件間隔 ≤1.5 秒、前 3 秒 ≥3 個事件（`node scripts/dossier/events.mjs <slug>` 檢查）；查證小標出現後至少留 0.5 秒。
配色仍然克制：墨藍炭灰、白灰、一個紅（新聞條與標題籤用深一階的紅 `#B8322A`）、「已確定」的冷色。電頭的地點與日期也是畫面上的事實，要有依據，寫進該片 README 或 research.md。
配音說明用一句話的短版（`docs/prompts/liguligu-男聲試聽-短說明.txt`）：「像國際新聞記者把查到的事講清楚，語速偏快、語氣沉穩篤定」。長篇人設會讓 Gemini 變慢、變演（`videos/short-ai/voice.md`）；第 4 節的 `liguligu` 設定檔（probe、每秒 4.4–4.9 字）是使用者要求調快之前寫的，音色選定後以短說明為準。

## 6. 交付前自查

1. 旁白每一句都能在 `research.md` 的事實表找到編號與狀態。
2. 把旁白裡的問句都拿掉，剩下的句子有沒有任何一句是沒有證據的結論？有就改。
3. 有沒有第三人姓名、定罪式用語、投資建議？
4. 前 3 秒逐格看：第 0 格是不是完整主張、1 秒內有沒有動作。
5. 全片每 0.25 秒抽格：有沒有超過 1.5 秒沒變化、頁首有沒有蓋到字、字幕以下有沒有大片空板。
6. 照片逐張看過：沒有人臉、沒有商標；`assets.md` 記了來源與「未核對」的項目。
