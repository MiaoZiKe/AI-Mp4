# 科技頻道 3D 片規則（前 3 秒與留存）

來源：使用者 2026/11/14 的要求（「前 3 秒內就能抓住目光，以及讓觀眾想繼續看的理由，參考 CoWoS 那支」）與三位評審的評估，完整整理在 `../tech-3d-expert-review.md`。
照這份做的第一支：`videos/sample-tech-anc/`（耳機主動降噪，約 29 秒試片）。引擎與資料格式：`../three-stage.md`。

## 骨架（照 tech-cowos 的順序）

鉤子（先給結果）→ 問句 → 拆開、逐步揭曉 → 運作動畫走到 payoff → 「可是…」衝突與限制 → 回到生活 → 具體提問 → 下一集。
拆解不超過片長三分之一。正式長片 45–75 秒；鉤子後可以多一幕「你」的場景（捷運、飛機）。

## 檢查清單

前 3 秒
1. 第 0 幀：肯定的反差或後果大字（≤8 字、≥120px）＋一個已經在動的東西。不是只有產品在轉。
2. 3 秒內 ≥4 個事件，第一個在 1 秒左右，而且是「結果」（蓋章）。
3. 標題講的事，畫面上要看得到（說「出聲」就要有聲波）。
4. 不整圈自轉（`spin.turns` 寫小數）；角度要認得出產品。
5. payoff 在開場先預告一次。
6. 封面與第 0 幀單獨看得懂。

繼續看的理由
7. 鉤子後接問句，答案留到中段。
8. 零件講到才出現並留著累積（步驟列 `steps`）；一次新增的標籤 ≤2 張。
9. 中段有一個畫得出來的衝突（`cross` 叉叉、前後對照）。
10. 答案之後補一句有來源的限制。
11. 每 2–4 秒有事件，靠 2D 疊層補；不留 >1.5 秒靜止。
12. 一句回到觀眾的生活。
13. 結尾＝具體提問（`card`）＋下一集鉤子（`circle` 圈起畫面上已有、還沒解釋的零件）。沒查證的題目不預告。

事實與成本
14. 示意動畫不畫成歸零：留殘餘、儀表不標數字、旁白用「一大半」「通常」；重要限制寫進旁白。
15. 一個零件一個名字；名詞出現就解釋或換白話。
16. 出處列 ≥28px（`model.fx.srcPx`）、一幕一句，寫「示意動畫，不是量測」。
17. 新畫面先用 2D 疊層（`props.overlay`：`scope｜stamp｜cross｜circle｜steps｜card｜ribbon`，`src/components/three/Overlays.tsx`）；3D 用在開場、拆解、訊號流。先估渲染時間。
18. 上片後看留存曲線的第 3 秒、第 10 秒、結尾；一次只改一個變因。

## 使用者 2026/11/15 修正（之後每支都要照做）

使用者看完 tech-2nm（light 版）提出，並說之後每支科技片都照做。第一支照做的是 `videos/tech-2nm/`（成片 `out/tech-2nm.light-v2.mp4`）。

1. **LOGO 固定在左上角、版面不要留大片空白。** 版面數值在 `src/theme.ts` 的 `LAYOUT_HUD`（只給 HUD 片用，舊的 `LAYOUT_3D` 3D 片不受影響）：頁首 100–164（開口圈＋頻道名，全片不動，片尾卡也蓋在它下面）、舞台 184–1404（高 1220，舊版 300–1290；舞台中心幾乎不變，所以疊層 y 不用改，3D 模型自然放大約 1.23 倍）、字幕 1420–1656、出處 1676、1724–1920 頻道色帶（淡底＋滑動刻度＋全片進度條，不放要讀的字）。新片不要自己另訂版面。
2. **片尾卡的 LOGO 要有動畫。** `Hud.tsx` 的 `RingMarkAnim`：圓弧描線畫出（2–20 幀）→ 橘點繞圓心轉進缺口、落定回彈（16–34 幀）→ 一圈脈衝往外擴（34–52 幀）→ 頻道名、slogan、路線、下一支依序出現 → 之後輕微呼吸。片尾卡 `durationSec` 用 3 秒。
3. **物理／運作效果要清楚、有方向、跟旁白同步。** 電流用 `model.json` 的 `actions` 新 type `stream`（2D 畫在 3D 投影位置上，幾乎不增加渲染成本）：`lanes` 多條源極→汲極路徑、每條 `n` 顆電子（實心點＋往後拖的尾巴）、`drive` 指向閘極電壓動作，速度跟著電壓——加電壓逐漸加速、拿掉電壓減速後停住再淡出；`field` 畫閘極到各片的流動電場線；閘極的 `pulse` 加 `stagger` 讓幾塊零件依序亮起（充電掃過感）。舊架構對照的漏電小點不能畫成零。出處列照舊寫「示意」。

## 自查方法

- 前 3 秒逐格：`ffmpeg -i out/<slug>.mp4 -vf "select='lt(n,90)*not(mod(n,6))',scale=270:-1,tile=5x3" -frames:v 1 out/<slug>-first3s.png`，數事件、看第 0 格。
- 全片每 0.25 秒抽格，找連續 6 格以上沒變化的地方。
- 九格圖：`python3 scripts/ui/review9.py <slug> "s1:start+0,…"`。
