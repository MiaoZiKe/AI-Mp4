# 旁白設定檔（voice.profile）

**規定：每支片送配音之前，先在 `script.json` 的 `voice.profile` 寫好「這支片的旁白要怎麼講」。沒有設定檔就不送 TTS。**

為什麼要有這個制度：stock-jensen 那支被聽成中國口音。量測結果是同一個音色、同一句提示，四支片的捲舌程度差很多（模型每次生成會飄），而且請求裡從來沒指定語言地區。只靠一句「用台灣人平常講話的口音」控制不住。所以改成三層一起做：請求指定 `cmn-TW`、口音寫成每支片都一樣的固定句、語氣與情緒依主題另外寫；新音色或新頻道第一次用，先給使用者試聽。

程式：`scripts/voice-profile.mjs`（組提示、檢查欄位、中國用語清單）、`scripts/voice-profiles.json`（四個頻道的預設檔）、`scripts/tts-take.mjs`（讀設定檔送請求）。

## 怎麼寫

```jsonc
"voice": {
  "voiceName": "Sulafat",            // 音色：依頻道與內容選，不限男性
  "model": "gemini-2.5-flash-preview-tts",
  "mode": "take",
  "profile": "love"                   // 寫法一：直接用頻道預設檔（tech／stock／love／ai）
}
```

```jsonc
"profile": { "preset": "stock", "tone": "…", "arc": { "轉": "…" }, "englishTerms": { "NVIDIA": "en-VID-ee-uh" } }  // 寫法二：預設檔＋這支片要改的欄位
```

寫法三是整份自己寫，欄位如下。

## 欄位

| 欄位 | 必填 | 內容 | 會不會送給模型 |
|---|---|---|---|
| `persona` | 是 | 誰在講、對誰講。一句話，寫具體的人（年紀、做什麼的、講給誰聽）。虛構角色，不寫真人 | 會（AUDIO PROFILE） |
| `gender` | 是 | `female`／`male`／`any`。用來選音色，不限男性 | 不會（選音色用） |
| `accent` | 是 | 固定寫 `"台灣華語"`。實際送出的口音句是程式裡的固定句（下面），各片不能改 | 會（固定句） |
| `pace` | 是 | 目標語速 `[下限, 上限]`，單位音節/秒。成片量到的語速要落在這個範圍 | 會（Pacing） |
| `tone` | 是 | 整體語氣，一句話 | 會（Tone） |
| `arc` | 是 | `起`／`承`／`轉`／`合` 四段各一句情緒指示 | 會（Arc） |
| `englishTerms` | 否 | `{ 英文詞: 標準念法 }`。稿子裡出現的英文詞都列出來 | 會（Articulation） |
| `avoid` | 否 | 不要的講法（例如播報腔、叫賣） | 會（Avoid） |
| `voices` | 否 | 這個頻道建議試聽的音色，給人看的 | 不會 |
| `scene` | 否 | 一句話的場景（在哪裡、對哪一個人講）。寫了會多一段 `# SCENE`。見 `docs/voice-natural.md` | 會（SCENE） |
| `delivery` | 否 | `"report"`（正常報導一件事：整段說明只有一句固定的話，其他欄位都不送；AI 教學頻道 2026/11/14 起用這個，預設檔 `ai-report`）、`"chat"`（跟朋友講話版）或 `"warm-pro"`（親和專業版，AI 教學頻道的舊預設）：把固定的 Pacing／Articulation 兩句換掉。不寫就和以前一樣。見 `docs/voice-natural.md` 第八節 | 會（換掉兩句固定句） |

另外兩個頂層設定：`voice.languageCode`（有設定檔時預設送 `cmn-TW`；寫 `"off"` 以外的值會照送）與 `voice.voiceName`。

### 寫說明的規則

1. **只描述說話方式，不放任何像台詞的句子。** 引號裡的句子、對話情境（「你放下杯子說…」）會被模型念出來，本專案已經踩過。`validate` 看到說明裡有引號包住的句子會報 error。
2. 每一句說明 60 字以內。
3. `arc` 只寫「哪一段、什麼情緒」（開頭帶一點意外、轉折的地方放慢），**不引用稿子裡的字**。
4. 不寫「咬字清楚、字正腔圓」。這類字眼會把發音推向播音腔。固定句用的是「每個字都講得出來，但是像平常講話」。
5. **寫情境，不寫形容詞**（`docs/voice-natural.md`）：`persona`／`tone`／`arc` 寫「在哪裡、對哪一個朋友講、像在做什麼」，不寫清楚、專業、沉穩、克制、明快、俐落這類會導向朗讀或簡報的詞；`avoid` 只寫「哪一種節目」（播報、簡報、線上課程講師），不描述壞聲音本身。新片建議加 `delivery: "chat"` 與 `scene`（各頻道的場景句在 `voice-profiles.json` 的 `_chat`；尚未用錄音驗證）。

## 口音與用語（每支片都一樣）

送給模型的固定句（`ACCENT_TW`、`ENGLISH_STD`）：

> 台灣華語（Taiwanese Mandarin），台北土生土長的台灣人平常講話的口音。捲舌音輕輕帶過、不特別捲舌，沒有兒化音，詞尾不念輕聲。不是中國大陸的普通話，也不是播音員的標準腔。
>
> 中文和英文都要念得標準、清楚。英文單字用標準美式發音完整念出來，尾音不省略，念完自然接回中文。

稿子的用語（`validate` 會對念稿與字幕警告）：

- **禁用中國用語**：視頻→影片、短視頻→短影音、信息→資訊／訊息、軟件→軟體、硬件→硬體、網絡／互聯網→網路、服務器→伺服器、內存→記憶體、硬盤→硬碟、芯片→晶片、屏幕→螢幕、鼠標→滑鼠、打印→列印、默認→預設、激活→啟用、人工智能→人工智慧、智能手機→智慧型手機、二維碼→QR Code、質量→品質、高清→高畫質、性價比→CP 值、渠道→通路、立馬→馬上、靠譜→可靠、首席執行官→執行長、股民→投資人／散戶、利好→利多、板塊→類股、回調→回檔……完整清單在 `scripts/voice-profile.mjs` 的 `CN_TERMS`。
- **不兒化**：這兒、那兒、哪兒、一點兒、一會兒、玩兒、事兒……都改掉。
- 英文：完整單字照原樣寫、前後留半形空白（Server、YouTube）；縮寫拆字母（A I、H B M）。念法寫進 `englishTerms`。
- 稿子本身就是最穩的情緒控制：問句、短句、適量語助詞（啦、呢、喔）會把模型帶向平常講話；整齊的書面句會帶向播報腔。新聞題材也要寫成「講給朋友聽」的句子。

## 送給模型的樣子

`gemini-2.5` 系列用「導演筆記」格式（what-is-server 試聽時實測沒有被念出來的格式）：

```
以下是給配音員的說明，不要念出來，只念 TRANSCRIPT 之後的內容。

# AUDIO PROFILE
（persona）

# PERFORMANCE
Accent: （固定口音句）
Tone: （tone）
Pacing: 像平常講話的速度，大約每秒 X 到 Y 個字；有快有慢，重點前面留一口氣，句子講完才換氣。
Arc: 整篇的情緒依內容走：開頭（起）；中段（承）；轉折的地方（轉）；結尾（合）。
Articulation: 每個字都講得出來，但是像平常講話，不是朗讀。（英文固定句）（englishTerms）
Avoid: （avoid）

# TRANSCRIPT
（念稿）
```

請求另外帶 `speechConfig.languageCode: "cmn-TW"`。模型不收（回 400）時程式會拿掉再送一次，這時把 `voice.languageCode` 寫成 `"off"`，免得每次多花一次請求。

### 各段情緒做得到什麼程度（照實寫）

- **做得到的**：整篇的走向用 `Arc` 一行描述，模型自己依內容分配。這是「方向」，不是逐句控制；沒辦法保證第幾句一定是什麼情緒。
- **做不到的**：在 2.5 系列逐句插入情緒標記。行內標記容易被念出來，所以不用。
- `gemini-3.x` 系列會把說明念出來（本專案試過），所以對 3.x **只送念稿與 languageCode，不送設定檔的說明**；3.x 的行內音訊標籤還沒在本專案驗證過，目前不用。
- 每次生成後仍要用聽寫確認說明沒有被念出來（`--asr`），口音與情緒最後由人耳確認。

預設檔是起點。題材特別的片（例如股票頻道講一件讓人難過的事）用寫法二改 `tone` 和 `arc`。

## 配音前後的檢查

1. `npm run validate <slug>`：v3 有配音的片沒有 `voice.profile` 會警告（舊片不擋）；設定檔欄位不對是 error；念稿或字幕有中國用語、兒化會警告。
2. **新音色或新頻道第一次用，先試聽再整篇配音**：`NODE_USE_ENV_PROXY=1 node scripts/tts-take.mjs <slug> --audition=<名字> --upto=<幕id> --voice=<音色> [--profile=<預設檔>] [--out=out/voice-audition-v2]`（一次請求、不動正式音檔）。試聽檔交給使用者聽過、選定，才跑正式配音。
3. 成片語速要在 `pace` 範圍內。**後製加速（atempo）上限 1.08**；差更多就重配（改稿或改 `pace`），不硬加速。
4. 捲舌量測（ㄓㄔㄕ 與 ㄗㄘㄙ 的擦音重心差距）是輔助數字：差距越大越像標準普通話的捲舌。它不能代替人耳。
5. 聽寫只能確認「有念到、沒多念」，口音像不像台灣人、英文標不標準，只有人耳能判斷。

## 舊片

沒有 `voice.profile` 的片（what-is-server、tech-cowos、stock-jensen、love-stats、ai-make-video 與 v1／v2 各片）照舊用 `voice.style`，送出的請求和快取雜湊都和以前一樣，不會被動到。要重配時再補設定檔。
