# 完整影片旁白提示詞（給網頁版試聽用）

這份檔案由 `node scripts/voice-prompts.mjs` 從各片的 script.json 與 `scripts/voice-profile.mjs` 產生，不要手改；改了稿子或設定檔就重跑。沒有送任何 TTS 請求。

## sample-ai-news（十月物價新聞丟給 AI：隨便問拿到兩年前的數字）

用法：Google AI Studio 語音生成頁面，模型選 Gemini 2.5 Flash TTS、音色選 **Sulafat**，把下面整段貼進去。說話方式：親和專業（`delivery: "warm-pro"`）；念稿 19 段。

```
以下是給配音員的說明，不要念出來，只念 TRANSCRIPT 之後的內容。

# AUDIO PROFILE
在台灣公司裡負責帶新人的前輩，自己每天用 AI 工具做事，坐在同事旁邊帶他把一件事做一次。

# SCENE
辦公室的茶水間旁邊，兩個人並肩看同一台筆電，她一邊操作一邊跟剛來的同事解釋，旁邊沒有別人在聽。

# PERFORMANCE
Accent: 台灣華語（Taiwanese Mandarin），台北土生土長的台灣人平常講話的口音。捲舌音輕輕帶過、不特別捲舌，沒有兒化音，詞尾不念輕聲。不是中國大陸的普通話，也不是播音員的標準腔。
Tone: 像懂行又好相處的前輩在跟同事解釋，語氣平穩、有耐心，帶一點笑意；不嬉鬧、不裝可愛，也不是站在台上講課。
Pacing: 當面跟同事解釋事情的速度，平均大約每秒 4.3 到 4.9 個字。一句一句講完整，步驟和步驟之間自然停一下，講到數字稍微慢一點；停頓有長有短，不用每一句都一樣。
Arc: 整篇的情緒依內容走：開頭像看到同事在查這則新聞，平常地問他一句；中段邊操作邊解釋，講到數字不對的地方放慢，平靜地指出來；轉折的地方講到它也會出錯的地方，放慢、認真一點提醒；結尾語氣放鬆，問對方一句，再順口提下一次要講什麼。
Articulation: 平常講話的咬字，虛字輕輕帶過；句子講完整，句尾自然收住，不拖長、不往上飄。英文單字用標準美式發音完整念出來，念完自然接回中文。特別注意：A I（英文字母 A 和 I，分開念）、Gemini（JEM-ih-nye，三個音節）。
Avoid: 嬉鬧搞笑的綜藝口氣、誇張的驚訝、撒嬌、裝可愛、購物台叫賣、線上課程講師的口氣、播新聞的腔調。

# TRANSCRIPT
十月物價出來了，你有請 A I 抓重點嗎？

我們用 Gemini 實測，先只打一句話。

它回了一大篇，說十月是一點六九趴。

其實那是兩年前的數字，今年是二點三三趴。

這不能怪它，我們沒開搜尋，也沒給它新聞。

所以，我們換個問法。

先貼上新聞，請它只看這一段。

沒寫到的就說原文沒寫。

再告訴它你是誰，像我在台北租房、三餐外食。

最後請它分三段，確定的、還不確定的，還有跟我有關的。

送出。你看，二點三三趴，這次數字對了。

十一月會更高嗎？它放在還不確定。

台北房租漲多少？它說原文沒寫。

一樣的 A I，只是問法不一樣。

不過你會發現，官方的看法，它也算進確定的。

所以重要的數字，自己再對一下原文喔。

範本在這裡，可以截圖存起來。

你最想丟哪一則新聞給它？

下一集，兩篇新聞講的不一樣，怎麼辦？
```

## sample-talk-notes（房價是年收入的九倍多｜風格試片：觀察者筆記）

用法：Google AI Studio 語音生成頁面，模型選 Gemini 2.5 Flash TTS、音色選 **Sulafat**，把下面整段貼進去。說話方式：聊天（`delivery: "chat"`）；念稿 5 段。

```
以下是給配音員的說明，不要念出來，只念 TRANSCRIPT 之後的內容。

# AUDIO PROFILE
三十歲左右的台灣女生，下班回到家，把今天看到的一個數字講給同年紀的好朋友聽。

# SCENE
晚上在租來的小房間，窗戶開著，她坐在床邊跟好朋友講電話，旁邊沒有別人在聽。

# PERFORMANCE
Accent: 台灣華語（Taiwanese Mandarin），台北土生土長的台灣人平常講話的口音。捲舌音輕輕帶過、不特別捲舌，沒有兒化音，詞尾不念輕聲。不是中國大陸的普通話，也不是播音員的標準腔。
Tone: 小聲跟好朋友講話的口氣，像在講一件大家都知道的事；不嘆氣、不安慰人，也不說教。
Pacing: 跟朋友講話的速度，平均大約每秒 4.5 到 4.9 個字。想到哪講到哪：有的地方一口氣帶過去，有的地方想一下才接下去；停頓有長有短，逗號不一定要停。
Arc: 整篇的情緒依內容走：開頭像剛想到一件事，隨口提一句；中段講到數字想一下再說，其他地方順順帶過；轉折的地方聲音小一點，像在講自己人的事；結尾鬆下來，像抬頭看到窗外，帶一點笑意。
Articulation: 平常講話的咬字就好，虛字和語助詞輕輕帶過，不用每個字都一樣重；句尾不用每一句都收得很乾淨。英文單字用標準美式發音完整念出來，念完自然接回中文。
Avoid: 深夜電台的氣音、播新聞的腔調、朗讀文章的口氣、說教的口氣、心靈成長節目的口氣、娃娃音、撒嬌。

# TRANSCRIPT
欸，最近看到一個數字。

全台灣的房價，是家庭年收入的九倍多。

不吃不喝，也要九年多耶。

我們這一代，還在算下個月的房租。

不過今天下班的夕陽，還是很漂亮啊。
```
