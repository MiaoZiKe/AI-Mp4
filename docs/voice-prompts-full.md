# 完整影片旁白提示詞（給網頁版試聽用）

用法：Google AI Studio 語音生成頁面，模型選 Gemini 2.5 Flash TTS、音色選 **Sulafat**，把整段貼進去。

## sample-ai-news（十月物價新聞丟給 AI：隨便問拿到兩年前的數字）

```
以下是給配音員的說明，不要念出來，只念 TRANSCRIPT 之後的內容。

# AUDIO PROFILE
每天用 AI 工具做東西的台灣創作者，坐在朋友旁邊看著同一個螢幕，教對方剛學會的一招。

# SCENE
咖啡店裡兩個人並肩坐著，筆電開著，她湊過去看朋友的螢幕，一邊指一邊講。

# PERFORMANCE
Accent: 台灣華語（Taiwanese Mandarin），台北土生土長的台灣人平常講話的口音。捲舌音輕輕帶過、不特別捲舌，沒有兒化音，詞尾不念輕聲。不是中國大陸的普通話，也不是播音員的標準腔。
Tone: 像剛發現好用的東西急著跟朋友講，有點興奮、很隨興；不是在上課或錄教學。
Pacing: 跟朋友講話的速度，平均大約每秒 4.3 到 4.9 個字。想到哪講到哪：有的地方一口氣帶過去，有的地方想一下才接下去；停頓有長有短，逗號不一定要停。
Arc: 整篇的情緒依內容走：開頭像剛滑到一則新聞，轉頭問旁邊的朋友；中段邊操作邊講，看到數字不對的地方愣一下才講；轉折的地方講到它也會出錯的地方，慢下來、小聲一點提醒；結尾鬆下來，隨口問對方一句，再順口提下一次要聊什麼。
Articulation: 平常講話的咬字就好，虛字和語助詞輕輕帶過，不用每個字都一樣重；句尾不用每一句都收得很乾淨。英文單字用標準美式發音完整念出來，念完自然接回中文。特別注意：A I（英文字母 A 和 I，分開念）、Gemini（JEM-ih-nye，三個音節）。
Avoid: 購物台叫賣、線上課程講師的口氣、播新聞的腔調、一口氣講完不換氣。

# TRANSCRIPT
欸，十月物價出來了，你有叫 A I 抓重點嗎？

我們拿 Gemini 實測，只打一句話。

它回了一大篇，說十月是一點六九趴。

蛤？那是兩年前的啦，今年是二點三三趴。

也不能怪它嘛，沒開搜尋，又沒給它新聞。

所以啊，換個問法。

貼上新聞，叫它只看這一段。

沒寫到的就說原文沒寫。

然後講你是誰，像我在台北租房、三餐外食。

最後分三段，確定的、還不確定的，還有跟我有關的。

送出。你看，二點三三趴，數字對了耶。

十一月會更高嗎？它放在還不確定。

台北房租漲多少？它說原文沒寫。

一樣的 A I 欸，問法不一樣而已。

不過齁，官方的看法，它也算進確定的。

所以重要的數字，自己再對一下原文喔。

範本在這，截圖存起來。

你最想丟哪一則新聞給它？

下一集，兩篇新聞講的不一樣，怎麼辦？
```

## sample-talk-notes（房價是年收入的九倍多｜風格試片：觀察者筆記）

```
以下是給配音員的說明，不要念出來，只念 TRANSCRIPT 之後的內容。

# AUDIO PROFILE
三十歲左右的台灣女生，下班回到家，把今天看到的一個數字講給同年紀的好朋友聽。

# SCENE
晚上在租來的小房間，窗戶開著，她坐在床邊跟好朋友講電話，旁邊沒有別人在聽。

# PERFORMANCE
Accent: 台灣華語（Taiwanese Mandarin），台北土生土長的台灣人平常講話的口音。捲舌音輕輕帶過、不特別捲舌，沒有兒化音，詞尾不念輕聲。不是中國大陸的普通話，也不是播音員的標準腔。
Tone: 小聲跟好朋友講話的口氣，像在講一件大家都知道的事；不嘆氣、不安慰人，也不說教。
Pacing: 跟朋友講話的速度，平均大約每秒 4.5 到 4.9 個字。想到哪講到哪：有的地方一口氣帶過去，有的地方想一下才接下去；停頓有長有短，逗號不一定要停。
Arc: 整篇的情緒依內容走：開頭像剛想到一件事，隨口提一句；中段講到數字想一下再說，其他地方順順帶過；轉折的地方聲音小一點，像在講自己人的事；結尾鬆下來，像抬頭看到窗外，帶一點笑意。
Articulation: 平常講話的咬字就好，虛字和語助詞輕輕帶過，不用每個字都一樣重；句尾不用每一句都收得很乾淨。英文單字用標準美式發音完整念出來，念完自然接回中文。
Avoid: 深夜電台的氣音、播新聞的腔調、朗讀文章的口氣、說教的口氣、心靈成長節目的口氣、娃娃音、撒嬌。

# TRANSCRIPT
欸，最近看到一個數字。

全台灣的房價，是家庭年收入的九倍多。

不吃不喝，也要九年多耶。

我們這一代，還在算下個月的房租。

不過今天下班的夕陽，還是很漂亮啊。
```
