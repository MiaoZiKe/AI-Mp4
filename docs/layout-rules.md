# v2 版面規則：填滿畫面（2026/11/6）

使用者回饋：畫面「空空的」；不用 3D，最多 2.5D。量測腳本在 `scripts/audit/coverage/`（cov2.py 覆蓋率／主視覺框／空白帶，bands.py 空白帶 y 範圍，mask.py 遮罩檢查圖；numpy＋PIL）。

## 爆紅片構圖共通點（摘要）
- 畫面從一開始就照 9:16 設計，主體置中、撐滿寬度；背景本身就是內容（Vox 紙紋與地圖、Kurzgesagt 滿版插畫、Johnny Harris 拼貼紋理、Visual Capitalist 圖表滿寬並把註解疊在圖裡）。沒有「一張卡片浮在空背景上」。
- 字幕放中央偏下（約畫面高 60–75%），不放最底下三分之一；平台 UI 會蓋住下方約 280–320px、右側約 90–120px。
- 大字只打關鍵詞、數字、引句；每 2–4 秒換一次畫面。
- 手機圖表：標籤直接標在線上、x 軸標籤少、長條 5–7 根。
- 來源：RealEye、Studio Liddell、PremiumBeat（Vox）、Datawrapper、Harvard VCG（CHI 2020）等，多為搜尋摘要或二手，詳見研究回報。

## 我們的診斷
- 亮色 A 版 13 幕：佔用率中位數 45%、主視覺高度中位數 41%；每幕三條固定空白帶（頁首下 170–250px、卡片與字幕之間 170–270px、出處下 170px），空白列合計占安全區高 25–39%。
- 墨水量不算少，問題是全擠在 y 480–1170，背景又太乾淨。

## 縱向格線（1080×1920，安全區 x 64–1016、y 220–1700）
| 區塊 | y | 用途 |
|---|---|---|
| 頁首帶 | 220–310 | 固定 logo／膠囊 |
| 主視覺區 | 330–1250 | 主視覺＋標註 |
| 字幕區 | 1270–1560 | 中文 76px 最多 2 行、英文 30px |
| 出處帶 | 1580–1690 | 低優先，不放狀態標籤 |
| 安全區外 | 1700–1920 | 只放背景層（色帶、水印延伸） |
- 主視覺右下角（x>950 且 y>1100）不放關鍵數字。

## 尺寸下限
- 主視覺外框 ≥ 856px 寬、≥ 814px 高（鉤子／CTA 幕高 ≥ 45% 安全區，背景補足）。
- 圖表繪圖區 ≥ 856×640；軸標籤 ≥28px、資料標籤 ≥40px、重點數字 ≥96px、線寬 ≥6px、長條寬 ≥96px；類別 ≤7、折線 ≤3、註解 ≤3。
- 主視覺區內空白帶 ≤120px；安全區內 ≤160px（主視覺與字幕間距除外，但該間距 ≤140px）。

## 每幕四層（由下到上）
1. 背景層：紙紋或雜訊 3–6%（或點陣 8–12%，擇一）＋最多 2 個色塊（主色 8–14% 或深一階米色，圓角 32–48）＋大字水印 4–7%（360–560px，可出血）或細線圖示散佈 3–6 個（8–15%、64–140px，只放空白帶）二擇一。背景元素色差 <30，不搶內容。
2. 主視覺：一個，符合尺寸下限。
3. 標註層：1–3 個（引線註解、螢光筆底線、狀態標籤、數字徽章），壓在主視覺上或貼邊。
4. 字幕：字幕區。
- 主視覺＋標註墨水率 15–30%（>35% 太雜）；同時強調色 ≤3。

## 2.5D（只用 CSS transform＋perspective）
- 視差三層速度比 0.2 : 0.5 : 1.0；一幕前景位移 40–80px、背景 8–16px；ease-in-out，不回彈。
- 透視傾斜：perspective 1600–2200px，rotateX/Y ≤12°（進場 12°→0–4°），一幕只傾斜一個元素。
- 長陰影：45°、16–40px、墨色 10–18%；或硬邊位移陰影 8–12px。全片擇一。
- 卡片堆疊 2–3 張：後卡位移 16–24px、縮放 0.96／0.92、透明度 1／0.7／0.45；前卡寬 ≥856px。
- 等角長條：2D 斜切（skew 30°）三面三階明度，不轉鏡頭。
- 禁止：three.js、@remotion/three、WebGL、預渲染 3D、鏡頭繞軌、rotateY >20°。

## 五個元件怎麼填滿
- **KineticText**：關鍵詞／數字 140–200px、2–3 行、寬 900–952、y 380–1150；同詞大字水印 6% 出血；黃色螢光筆底條；角落 200–280px 輔助圖（sparkline 或圖示）；1700–1920 主色 10% 出血色帶；字幕不重複主文字。
- **LineChart**：標題 y 340–420；繪圖區 x 64–1016、y 440–1180；線寬 8–10、面積 12–18% 漸層；終點圓點＋72–96px 數字徽章；1–3 個引線註解；重點期間整高色帶；最新數值水印；x 軸標籤 ≤6。
- **UnitGrid**：10×10，格寬約 95px（圖示 70），網格約 950px 高填滿主視覺區；需放大字時改 10×9；≤30 單位時圖示 140–180px、5–6 欄；未填格 25% 描邊；框出一組＋註解；背景只加紙紋。
- **DepthStage**：前景主卡 900–952×640–820、y 360–1180、rotateX 4–8°＋長陰影；中景 2 張堆疊卡從右下露出 24px；背景大色塊面板（大 10–15%、偏移 40px）＋3–5 個細線圖示；視差 0.2/0.5/1.0、前景漂移 60px；邊緣 1–2 枚徽章可半出界。
- **BarChart**：直條（≤6 類短標籤）繪圖區 952×780、y 400–1180、條寬 110–140；橫條（長標籤或 5–7 類）每列 110–150px 填滿高度；重點條主色、其餘 35%；1 條參考線＋1 個註解；水印或底部色帶；等角版柱子從主視覺區上緣附近長到底。

## 檢查
- still（每幕 PNG／影片取每幕 60% 時間點）：佔用率 warn <55%、error <40%（鉤子／CTA warn <45%、error <35%）；墨水率 <10% 或 >35% warn；主視覺框寬 <90% 或高 <55% warn、高 <40% error；最長空白帶 >120 warn、>200 error；背景存在率（色差 6）<85% warn。
- validate：主視覺宣告尺寸、LineChart 系列/註解數、BarChart 類別數、每幕 bg 與 ≥1 annotation、禁止 3D 依賴與 rotateY >20。
- audit：每幕 30/60/90% 三點量佔用率，60% 點須達標；跨幕標準差 >15 個百分點 warn。
