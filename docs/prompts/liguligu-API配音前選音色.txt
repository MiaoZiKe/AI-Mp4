使用者 11/15 同意哩股哩股旁白改用 API 生成。但目前還不知道 11/14 參考錄音（out/voice-refs/liguligu-reference.wav）是用哪個音色生成的；CLAUDE.md 規定新音色第一次用要先給使用者試聽，試聽不花 API 額度。

最快的做法（擇一）
A. 告訴我 11/14 那段參考錄音當時在 AI Studio 選的音色名稱 → 我直接用那個音色整篇生成兩支（每支 1 次請求）。
B. 不記得的話，到 aistudio.google.com/generate-speech（模型 Gemini 2.5 Flash Preview TTS，單人模式），把下面「要貼的內容」整段貼上，依序換音色各生成一次，回我選哪一個：
   1. Charon（Informative）  2. Orus（Firm）  3. Rasalgethi（Informative）  4. Alnilam（Firm）  5. Sadaltager（Knowledgeable）
   已否決：Iapetus、Achird。
   參考錄音量到：每秒約 4.8 個音節、音高中位數約 123 Hz（偏低沉的男聲）。

選定後：script.json 寫 voice.voiceName，模型用 gemini-3.8-flash-tts（失敗才改 2.5），說明句用下面那一句；整篇一次生成、設定句被念出來的部分用逐字時間戳切掉（不切到第一個字的起音）。
