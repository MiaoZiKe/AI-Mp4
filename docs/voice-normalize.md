# 科技片配音統一：解析與固定流程（2026/11/20）

Andy 11/20：「聲音的部分第二隻明顯爆音，需要修正。另外，為何後續的旁白無法像曝光機那份一樣？…是需要調整語速、音頻等等嗎？」
第二支＝離子佈植（tech-implant）。基準＝曝光機（tech-euv）。腳本：`scripts/three/voice-normalize.py`，基準數字：`scripts/three/voice-ref-euv.json`。

量測方法（所有數字同一把尺）：音高、共振峰、諧波清晰度（HNR）用 Praat（praat-parselmouth）；停頓＝低於說話音量 38 dB、持續 ≥0.10 秒；語速＝念稿中文字數 ÷ 首字到末字的秒數（含停頓）或再扣掉停頓（扣停頓）；頻帶占比＝有聲音的地方、100Hz–11.5kHz 內各段能量占比。
舊的 `scripts/voice-measure.py` 量音高會偏高，而且起伏越大偏越多（曝光機 113.7 vs Praat 109.6；離子佈植 134.1 vs 123.9；量測檢測 124.4 vs 114.7），所以之前算出來「要降的半音數」都算多了。

## 二、離子佈植為什麼爆音

不是成片削波（成片峰值 −1.5 dBTP），是後製那一步把聲音弄壞了：

1. **降調降太多、工具不對**：`rubberband=tempo=1.25:pitch=0.77:formant=preserved`＝一次降 4.5 半音。量到的後果：70Hz 以下的能量從 −34.5 變 −15.8 dB（多了約 19 dB 的低頻轟鳴，瞬間峰值到 −12.5 dBFS）、諧波糊掉（HNR 10.3→7.7，頻譜圖上原本一條條的諧波變成一片）、F1 從 336 掉到 286 Hz（−15%）、F3 2700→2535（−6%）。「formant=preserved」在這個 ffmpeg 版本實際上沒保住共振峰。耳朵聽到的就是悶、破、每個重音「噗」一下。
2. **其實不用降那麼多**：用 Praat 量，原始只比曝光機高 2.0 半音（舊量法算成 2.9，再加上想對到舊量法的 114.6，就降了 4.5）。降完中位數 104.6 Hz，反而比曝光機低 1 半音，低的那一端到 71 Hz（曝光機 83），更悶。
3. **處理後沒有留峰值空間**：整篇最後 6 秒有 22 個取樣（換算 48kHz）頂到滿刻度，峰值 +0.02 dBFS。波形沒有被削平，量也不大，是次要原因；但後面 align 的 loudnorm 因此只能用動態壓縮把峰值壓回 −1.5。
4. **原始錄音本身高頻就少**（3–8kHz 比曝光機少 5.9 dB），降調後 8kHz 以上再少 10 dB，聽起來更悶、低頻更突出。

## 三、為什麼後面幾支不像曝光機

| 面向 | 跟曝光機差在哪 | 為什麼耳朵覺得不像 |
|---|---|---|
| 語調（最主要） | Gemini 後面幾次生成的音高起伏是 14–15.5 半音，曝光機 12.3。差在「高的地方更高」（90% 位數 176–196 Hz vs 169），低的地方差不多 | 聽起來比較戲劇化、像在強調，曝光機是平穩地講。整條平移音高修不了這個，還會把低的那端壓得太低 |
| 停頓 | 曝光機 32 次、中位數 0.15 秒、最長 0.29；後面幾支 41–52 次、中位數 0.22–0.30、最長 0.5–0.86 | 斷句多又長，節奏一頓一頓 |
| 語速 | 為了把「含停頓」拉到 4.7–4.8，整篇加速 1.20–1.30 倍，結果「扣停頓」變 5.7–6.3 字/秒，比曝光機 5.44 快 5–16% | 字講得比曝光機急，停頓卻比較長＝又趕又卡 |
| 音色 | 量測檢測用 asetrate 降調，共振峰跟著降（F3 −6.6%、F1 −6.6%）；離子佈植舊版 F1 −15%；研磨用拉高的，F3 +2% | 共振峰決定「是誰的聲音」，移動 5% 以上就像換了一個體型比較大的人 |
| 音高 | 量測檢測原始 114.7 Hz 只比基準高 0.6 半音，本來不用動，卻被降到 105.0（比基準低 0.9 半音） | 舊量法高估造成的過度修正 |
| 響度／峰值 | 研磨的原始錄音 Gemini 給的就頂滿（取樣間峰值 +2.6 dBTP、58 處超過滿刻度；波形本身沒有被削平），後製沒先降音量 | 轉檔或某些播放裝置在重音處可能破音 |

結論：要調的不只語速和音高。順序是 ① 生成當下先篩（起伏太大、太慢的直接重配）② 音高用保留共振峰的方法只修到位、同時把起伏縮回來 ③ 加速以「扣停頓語速」對基準、不靠加速去補停頓 ④ 補高頻、去低頻、留峰值空間。

## 四、固定流程（每支配音後）

```
# 0. 第一次要裝：.venv/bin/pip install praat-parselmouth
# 1. 先量原始錄音，決定「處理」還是「重配」（不寫檔）
.venv/bin/python scripts/three/voice-normalize.py <slug> --check
# 2. 處理：原始 .take-*.raw.orig.wav → .take-*.raw.wav（舊檔自動備份到 out/old-<slug>-take/），印驗收表
.venv/bin/python scripts/three/voice-normalize.py <slug>
# 3. 重切＋對齊＋檢查（不送 TTS）
bash scripts/three/make-tech.sh <slug> --dry
# 4. 剪「曝光機 12 秒＋嗶＋新片 12 秒」給 Andy 聽，通過才渲染
```

注意：`make-tech.sh --take=… --atempo=…` 會用 atempo 蓋掉 `.raw.wav`。新流程換錄音時，把新錄音放到 `.take-*.raw.orig.wav` 後跑第 2 步，make-tech 不要帶 `--take`／`--atempo`。

處理順序與參數（寫死在腳本的 `LIM`）：

| 步驟 | 做法 | 上限 |
|---|---|---|
| 1 音高 | Praat PSOLA（共振峰不動）：新音高＝基準中位數 ×（原音高 ÷ 原中位數）^k，k＝基準起伏 ÷ 原起伏 | 中位數最多移 3 半音、k 最小 0.80；差距 <0.5 半音且 k>0.93 就不動 |
| 2 變速 | ffmpeg atempo，倍數＝5.44 ÷ 原始扣停頓語速 ×1.02 | 1.25；原始比基準快就不動 |
| 3 停頓 | 0.30 秒以下不動；超過的部分留 0.5 倍；單一停頓上限 0.70 秒（從靜音中間剪、12ms 交叉淡化）。換幕停頓仍由 script.json 的 pauseAfter 決定 | — |
| 4 等化 | 70Hz 高通；21 段頻帶對基準頻譜補差 | 每段 ±6 dB |
| 5 音量 | 拉到 −16 LUFS，48kHz 下限幅在 −2 dBFS | — |

「重配」的條件（`--check` 會印）：原始音高中位數離基準超過 3 半音；要加速超過 1.25 倍才到基準語速。提醒但不擋：起伏 >15.4 半音、原始錄音峰值頂滿、高頻少超過 6 dB。重配做法：同一份念稿、同一組設定再生成一次（每支最多再 2 次，照 playbook），每次生成後先跑 `--check`，挑起伏最接近 12.3 半音、扣停頓語速 4.3–5.0 的那一次。

驗收數字（腳本自動判，任何一項 ✖ 就回傳非零、不要渲染）：

| 項目 | 範圍 |
|---|---|
| 音高中位數 | 基準 110.5 Hz ±0.6 半音（106.7–114.4） |
| 音高起伏（10–90%） | 基準 12.3 半音 −2.5～+1.5 |
| 扣停頓語速 | 基準 5.44 字/秒 −0.20～+0.25 |
| F1／F2／F3 | 和自己的原始錄音差 ≤4% |
| HNR | 比原始最多掉 1.5 dB |
| 70Hz 以下能量占比 | ≤ −27 dB |
| 峰值／超過 0.99 的取樣 | ≤ −1 dBFS／0 個 |
| 響度 | −17.5～−15 LUFS |
| 三段頻帶占比（100–300／300–3k／3–8k） | 和基準差 ≤3.5 dB |
| 最長停頓 | ≤0.76 秒 |

報告寫在 `out/<slug>-voice-normalize.json`（原始、結果、每項判定）。

## 五、離子佈植這次怎麼修（v2）

從原始錄音重做，沒有送 TTS：`.venv/bin/python scripts/three/voice-normalize.py tech-implant --tempo=1.22 --pause-ratio=0.4`
（倍數與停頓比預設多一點，是為了讓片長維持在原本附近、不超過 75 秒。）

- PSOLA：中位數 123.9→110.5 Hz（−1.98 半音）、起伏 ×0.80
- atempo 1.22；停頓超過 0.3 秒的部分留 0.4 倍（動 9 處、共 0.74 秒）
- 70Hz 高通＋等化（3kHz 以上 +3～+5.8 dB，250–800Hz −1.5～−3 dB）；−16 LUFS、限幅 −2 dBFS
- 驗收 15 項全過（數字見第一節「新處理」一欄）
- 重切＋對齊後：片長 72.1→73.43 秒（2163→2203 幀）；cue 幕內位移 −1～+4 幀、絕對位移最多 +38 幀；整篇對齊信心 0.900→0.919；成片人聲軌 `public/audio/tech-implant/voice.wav` −15.7 LUFS、真峰值 −1.5 dBTP
- 比對音檔：曝光機 12 秒＋嗶＋離子佈植 v2 12 秒（scratchpad `離子佈植配音比對_曝光機_離子佈植_v2.mp3`）
- 還差的地方：含停頓語速 4.5（曝光機 4.87），因為 script.json 每幕 `pauseAfter: 0.7`（11/16 的規則：段落停頓 0.6–0.8 秒），曝光機自己的換幕停頓最長只有 0.53 秒

限制：這些都是量測值，音色像不像、PSOLA 有沒有殘留的機械感只有人耳能判定。這份原始錄音的起伏（15.5 半音）是幾支裡最大的，縮到 12.3 後數字對上了，但重音的位置和斷句方式還是原始那一次生成的樣子；如果聽起來仍然不像，下一步是重配，不是再調後製。
