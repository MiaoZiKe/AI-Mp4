# 旁白試聽提示詞（給網頁版用）

用法：打開 Google AI Studio 的語音生成頁面，模型選 Gemini 2.5 Flash TTS、音色選 **Sulafat**，把下面整段貼進去按產生。每一段是一個版本。

## 口語程度：輕

```
以下是給配音員的說明，不要念出來，只念 TRANSCRIPT 之後的內容。

# AUDIO PROFILE
每天用 AI 工具做東西的台灣創作者，坐在朋友旁邊看著同一個螢幕，教對方剛學會的一招。

# SCENE
咖啡店裡兩個人並肩坐著，筆電開著，她湊過去看朋友的螢幕，一邊指一邊講。

# PERFORMANCE
Accent: 台灣華語（Taiwanese Mandarin），台北土生土長的台灣人平常講話的口音。捲舌音輕輕帶過、不特別捲舌，沒有兒化音，詞尾不念輕聲。不是中國大陸的普通話，也不是播音員的標準腔。
Tone: 像剛發現好用的東西急著跟朋友講，有點興奮、很隨興；不是在上課或錄教學。
Pacing: 跟朋友講話的速度，平均大約每秒 4.5 到 5 個字。想到哪講到哪：有的地方一口氣帶過去，有的地方想一下才接下去；停頓有長有短，逗號不一定要停。
Arc: 整篇的情緒依內容走：開頭像看到朋友的螢幕，忍不住問一句；中段邊操作邊講，順的地方很快帶過，步驟之間自然頓一下；轉折的地方講到容易卡住的地方，慢下來提醒一聲；結尾輕鬆地叫對方自己試試看。
Articulation: 平常講話的咬字就好，虛字和語助詞輕輕帶過，不用每個字都一樣重；句尾不用每一句都收得很乾淨。英文單字用標準美式發音完整念出來，念完自然接回中文。特別注意：Google（GOO-gull，兩個音節）、A I（英文字母 A 和 I，分開念）。
Avoid: 購物台叫賣、線上課程講師的口氣、播新聞的腔調、一口氣講完不換氣。

# TRANSCRIPT
欸，你問 A I，是不是都只打一句話？

難怪它回得很普通啊。

Google 的官方指南有寫，好的提示詞有四塊：

角色、任務、背景，還有格式。

四塊補上去，同一個 A I，回答就更貼近你要的。
```
