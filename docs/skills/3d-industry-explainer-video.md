# 3D 產業鏈科普短影片

（使用者 2026/11/14 提供的技能全文；本專案用 src/components/three/（stage three）實作，renderAt(t) 對應 Remotion 的逐幀渲染。）

全程自主完成，不向使用者提問；遇到錯誤自行除錯修正。使用者只需給「主題」，其餘參數未指定時用預設值。

## 預設參數
- 比例 9:16、1080×1920、30fps、長度約 45 秒
- 語言：繁體中文旁白；字幕中文大字＋英文小字雙語
- 風格：深色科技背景、半透明元件、金/銅色金屬、輕微 bloom、柔和環境光＋一盞主光，高階半導體廣告的工程剖面感
- 右上角固定標示「Schematic – not to scale 示意圖，非實際比例」

## 步驟
1. 研究主題：上網查證該元件/產業鏈的實際結構、關鍵名詞與運作原理，列出需要建模的物件清單（只用規則幾何體可表達的結構）。
2. 寫旁白：口語、輕鬆像跟朋友解釋，約 45 秒（約 180–220 字）。開頭 3 秒要有提問式鉤子。不得包含投資建議、個股推薦或目標價。
3. 設計分鏡：5 段左右——遠景推近建立場景 → 爆炸展開/拆解結構 → 剖面看關鍵原理（發光動畫強調）→ 新舊方案對比（用光點流速、顏色呈現差異）→ 拉遠總結。每段寫明時間、運鏡、標籤文字。
4. TTS 配音：生成中文配音並取得逐句時間戳；依實際音檔長度調整分鏡時間。
5. 建 Three.js 場景：單一 HTML，所有物件程式建模；運鏡、標籤、高亮全部由一個 renderAt(t) 函式依時間決定（確定性渲染，不依賴即時動畫）。
6. 逐格渲染：用 Playwright 逐格呼叫 renderAt(frame/30) 截圖；字幕依時間戳疊在畫面下方。
7. 合成：ffmpeg 合成畫面＋配音，輸出 <主題英文slug>_explainer.mp4。
8. 自我檢查：抽 6 張關鍵影格看：物件無穿模、標籤無遮擋、字幕不出界、旁白與畫面對齊、文字無錯字。有問題修正後重新輸出，最多重試 3 輪。
9. 交付：MP4、可在瀏覽器旋轉操作的 HTML 3D 場景（加 OrbitControls）、旁白稿文字檔。

## 品質原則
- 結構要正確優先於華麗；不確定的細節用簡化示意，不要編造。
- 鏡頭移動要緩、用 ease-in-out，避免暈眩。
- 一個畫面最多 2 個標籤同時出現。
