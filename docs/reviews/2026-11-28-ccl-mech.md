## 必改清單（會讓分數 <8 的項目）
1. s5／f760～f825（熱壓機）：活塞桿 htRod 加長到 y5.8～9.4（上端藏在油缸 hCyl 8.2～9.6 內），壓下 2.34 後桿頂仍在缸內；或改成油缸固定、桿子跟著上熱板，但桿長 ≥ 行程＋缸內留 0.5。
2. s4／f504～f648（含浸線）：鏡頭拉遠或改兩段 shot——開頭看放卷→樹脂槽，念到「烘到半乾」移到烘箱→裁刀，**「膠片」cue 前 36 幀起讓裁刀與膠片堆完整入鏡**；放卷布捲要入鏡且在轉。
3. s4（含浸線）：導輥、浸輥、擠壓輥加 rotate（擠壓輥兩支反向、線速度與布面流速一致）；擠壓輥加兩側軸承座＋側板（或調壓螺桿），讓它看起來是一對輥而不是兩團黑塊；輥輪加左右側板機架。
4. s6／f825～f963（蝕刻）：輸送滾輪加 rotate、板子沿 x 慢慢前進；銅改成從進料端往後「一條掃過去」被吃掉（分 6～8 段依序隱藏或用 wipe），先在要留的線路上蓋一層乾膜（藍綠色），蝕刻後撕掉露出銅線；做好的板加到 ≥8 條走線（含轉角、扇出）、≥12 個銲墊、≥6 個過孔，至少一顆有接腳的晶片，接近 s1 主機板的密度。
5. s3／f400～f470（玻纖布）：紗改成連續的扁平截面（扁橢圓或扁平 box 沿曲線細分，接縫不留斷點）；「一根紗＝很多根玻璃絲」的散開尾端移到畫面中央偏右、放大到 ≥ 畫面寬 1/4，標籤不得壓住它（念到「玻璃絲」時鏡頭可推近該處）。
6. s7、s8／f963～f1377（損耗）：光點大小改成沿路連續縮小（同一條 path 上依位置插值大小，或分 ≥8 段），一般材料那道到終點約剩起點的 1/3，低損耗那道微幅縮小；伺服器補前面板把手、通風孔網格、托盤螺絲；送／收晶片加接腳並整顆入鏡。
7. s2／f213～f372（夾心爆炸）：鏡頭距離由 28 拉到約 36、仰角提高到約 22，讓整片板與右邊的實體夾心餅乾（kCookie）同時入鏡；爆炸時三張名牌逐一出現（上銅箔→膠片：玻纖布＋樹脂→下銅箔）。
8. s9／f1377～f1520（供應商）：鏡頭推近或降低 look y，讓展示台上緣到 y≈360 以內（上方空帶 ≤120 px）。
9. s10／f1521～f1803（下一集）：鏡頭拉遠到兩捲完整入鏡；玻纖布捲本體加織紋貼圖（同 s3 的經緯格），兩捲端面加一圈圈捲層環（tube，像 tech-bt 的 grRing），拉出的布片整片入鏡。

## 可改（不擋 8 分，但建議）
1. s1／f0～f213：主機板走線貼圖提高對比（亮銅色或金色細線）；晶片與記憶體四邊加接腳或底下露出錫球；念到「主機板又是什麼做的」時鏡頭壓低看板邊，露出銅／布層。
2. s5／f800：流膠加寬到 0.3～0.4 並用亮琥珀色，壓下後 6～10 幀從四邊擠出；控制箱與機台之間加油管、機台後方加油壓動力單元（油箱＋馬達）。
3. s7／f963～f1176：下三分之一空地，可先放一塊灰色低透明度的「待換材料」板佔位，或鏡頭在 s7 先對準泥巴道、s8 再拉開。
4. s6／f870：噴霧光點放大（size 0.09 → 0.14）並加扇形噴霧錐，讓半尺寸也看得見藥水。
5. 三台機台（含浸線、熱壓機、蝕刻線）至少一台做一次爆炸分解（例如熱壓機：上熱板、疊料、下熱板依序分開再合回），符合第 17 條。
