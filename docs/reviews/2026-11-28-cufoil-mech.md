# 初審 r0

判定：**總分 5.6 / 10、元件細節 5.0 / 10，兩項都未達 8 分，退回修正後複審**。
依據：commit 68e0123（3-12 銅箔與玻纖布，無聲版、未配音，片長 1917 幀）。審查期間工作區的 gen-model.mjs／genscript.py 仍在變動（例如 s10 右邊又改回主機板版本），本審以 68e0123 渲染出的 86 張半尺寸關鍵格為準，程式行為對照 `git show 68e0123:videos/tech-cufoil/gen-model.mjs`／`genscript.py`。
抽格：f2～f1913 共 86 格（含每幕起點與各 cue 前後），縮圖拼觸表看全片，再裁 3D 窗（半尺寸 y60～540）看細節，放大 f309、f969、f1756、f1479。幕起點與 cue 取自 timeline.json。動態由連續靜格與動作設定推論，推論處標「（推論）」。
量法：3D 窗＝頁首下緣到 2D 卡上緣（原尺寸約 y120～1070，高約 950 px）；佔比＝主物體上下範圍 ÷ 3D 窗高。
