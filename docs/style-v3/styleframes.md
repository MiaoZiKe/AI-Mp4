# 風格樣張：what-is-server（2026/11/12）

給使用者選方向用。兩個方向各 3 張關鍵幀（1080×1920），都是靜態圖，還沒寫正式元件。

- 對照圖：`out/what-is-server/styleframes-compare.png`（左 A、右 B）
- 單張：`out/what-is-server/styleframes/A-1.png`…`A-3.png`、`B-1.png`…`B-3.png`
- 挑的三鏡：s01 鉤子、s05「Server」名詞出現、s10「那萬一，廚房出事了呢？」（轉）
- 圖檔都在 `out/`，不 commit。重做：`python3 scripts/styleframes/make_assets.py && python3 scripts/styleframes/build.py`

## 兩個方向

| | A 桌面紙拼貼 | B 實拍照片大字報 |
|---|---|---|
| 一句話 | 像有人把剪好的紙片擺在桌上講給你聽 | 真實照片鋪滿，上面壓大字和螢光筆 |
| 底 | 米色紙板；轉折幕換深綠切割墊 | 照片壓成近黑藍雙色調 |
| 物件 | 色紙疊出來的機櫃與出餐口、剪下來的照片（白邊）、撕邊紙條、紙膠帶 | 手機、機櫃、廚房的真實照片 |
| 字 | 字寫在紙條上，重點用芥末黃麥克筆 | 大字直接壓在照片上，重點用螢光黃筆觸；轉折用橘色 |
| 字幕 | 白色撕邊紙條，中文 72px、英文 30px | 無底板，中文 70px 加陰影、英文 29px |
| 感覺 | 親切、小知識 | 專業、紀實 |

## 和分鏡不一樣的地方

- A 的機櫃、出餐口原本規劃用 AI 生成的剪紙插畫。生不出來，樣張改用「色紙一層層疊」加「剪下來的照片」。看起來比預期好，沒有落回扁平圖示，但這是三鏡的結果，雲、鎖、信封還沒試。
- B-3 分鏡寫的是「空無一人的出餐口」照片，資料集裡找不到，改用掛著鍋具的廚房。
- B-1 的手機照片被轉正、四周用鏡射補邊；左邊那塊灰色是原圖的鍵盤一角。

## 正式製作成本估計

| | A 桌面紙拼貼 | B 實拍照片大字報 |
|---|---|---|
| 要準備的圖 | 本機紙材約 25–30 個 PNG（腳本產生）；色紙疊的物件 5 樣（機櫃、出餐口已有；雲、鎖、信封待做）；照片 2 張（手機、廚房，已有） | 照片 7 張：已有 4 張（手機、機櫃、機房走道、廚房）；還缺鐵捲門、三支手機、天空 |
| AI 生圖 | 不需要。若之後 OpenAI 有餘額，可把物件換成插畫（7 張，低畫質約 US$0.1–0.5，牌價未查證） | 不需要 |
| 新元件 | PaperStage、Cutout、TapeLabel、PaperCaption、手機螢幕，約 2–3 個工作天 | PhotoStage、BigType、MarkerSwipe、SplitPhoto、手機螢幕，約 2 個工作天 |
| 渲染 | 可行性報告實測紙片進場 118–122 ms／幀；67 秒約 2010 幀，估 4 分鐘上下 | Ken Burns 101–120 ms／幀，估 3.5–4 分鐘 |
| 主要風險 | 還沒做的物件（雲、鎖）可能做得像圖示；直向全景鏡（手機大、廚房小）還沒打樣；同屏紙片多時落影要先烤好 | 缺的 3 張照片不一定找得到無人、無招牌的；授權沒對過原文；深色調等於換掉頻道的米白色；同一張照片要撐好幾鏡，容易單調 |

## 自己檢查的結果

- 6 張都開圖看過：沒有缺字方框，文字沒有溢出，頁首、字幕、出處都在安全區（上下 220、左右 64）內。
- 縮到手機寬度（約 540px）看：大字與中文字幕都清楚；英文副字幕和出處字偏小但讀得出來。
- 已知瑕疵：A-3 的服務鈴有一半被紅紙條蓋住；A-1 的出處標籤壓在手機邊上；B-1 手機螢幕下半用漸層蓋掉讓位給字幕。
- 沒有在實體手機上看過，只在縮圖上判斷。

## 建議

選 A。它直接對上「親切的小知識介紹」，三鏡看起來是同一個世界（同一張桌子），而且素材幾乎全部自己做得出來，不卡額度和授權。B 的單張衝擊力比較強（B-2 的 SERVER 最像專業頻道），但整支 23 鏡靠 7 張照片撐，缺圖和授權兩個問題都還沒解。折衷做法：A 為主，s13「約 6 小時」和 s20「放在哪」兩鏡借 B 的機房照片，印成貼在桌上的照片。
